## 0. 设计前提：拍照不是新系统，是元机制的第二人称

核心循环的元机制是"看—对—合"：

| 谁 | 看 | 对 | 合 |
|----|----|----|----|
| 园主（漏窗/框景） | 园林替玩家取好景 | 走到对位角度 | 景致拼合点亮 |
| 玩家（取景匣） | 玩家主动举匣取景 | 构图与诗卡/线索对位 | 照片成片，诗卡/图鉴点亮 |

**Rationale**：不新增交互动词，教学成本为零；漏窗解谜在先，拍照任务在后，玩家天然迁移。
**风险**：如果拍照判定做得像"小游戏绑奖"，就退化成清单打卡。判定反馈必须落在"这张照片本身好看"上（落款、印章、诗题入画），而不是只给完成度数字。

## 1. 取景匣（核心道具）

- **purpose**：让"观察园林"从被动浏览变成主动构图，支撑全部取景类任务。
- **player experience goal**：举起取景匣的瞬间，玩家从"逛园的人"变成"造景的人"。
- **inputs**：玩家位置、朝向、变焦档位（两档：标准/望远 [PLACEHOLDER]）。
- **outputs**：一张照片 = 构图元素集合（哪些目标物在框内、占比、相对位置）+ 机位数据。
- **判定原理**：**构图元素集合匹配**，不做图像识别。每张诗卡/线索卡声明 2–4 个必需元素（如"亭 + 水面倒影 + 远处塔尖"），全部在框内且各元素占比超过阈值即成片。阈值与元素数按难度分级。[PLACEHOLDER · 需纸面原型定标]
- **edge cases**：
  - 站对位置但构图歪 → 不判失败，判"景未成"，取景框内未凑齐的元素显示淡墨轮廓提示（提示三档可关）。
  - 乱拍（框内无任何目标）→ 成一张"空片"，进相册不进任务，无惩罚、无提示音——让玩家自己察觉。
  - 手机端与 PC 端判定同一套机位数据，与操作方式无关。
- **failure states**：玩家连续 3 次"景未成"后弃拍 → 触发该诗卡的引导NPC递进提示（最多到"指出方位"级，不直接标点，违反 Pillar 2）。

## 2. 寻景诗卡（诗 → 景拍照）

- **purpose**：把古诗从"考核"变成"寻宝"，服务 Pillar 3（知识是奖励不是门票）。
- **player experience goal**："这句诗写的原来就是这个角度"——文学与空间的对上号的瞬间。
- **inputs**：诗句上半联或意境卡（如"近水远山皆有情"）。
- **outputs**：照片 + 诗句合成的"诗卡"入诗卷；诗卷可翻阅、可分享。
- **玩法流**：得卡（任务链/漏窗解谜奖励）→ 玩家在园中寻景 → 举匣对位 → 成片时诗句下半联以题跋形式"写"进照片 → 附一句 30 字内的白话意境注。
- **素材示例**（均为实园实名，文案需考据）：
  - 沧浪亭 · "清风明月本无价，近水远山皆有情" → 沿复廊取景水面与假山。
  - 拙政园 · 与谁同坐轩 · "与谁同坐？明月清风我" → 扇形轩取景。
  - 网师园 · 月到风来亭 · 取"月到天心、风来水面"之景。
- **edge cases**：
  - 一句诗对应多个候选机位 → 主判定机位 1 个 + 可接受机位白名单（考据定）。
  - 玩家先找到景再拿到卡 → 反向触发也算完成，奖励相同（"游大于刷"）。
  - 夜景诗（月到风来亭）→ 引入园内时段系统（晨/午/暮/夜），同机位不同时段成不同诗卡——为长线回访埋钩子。
- **failure states**：成片率低于 40% [PLACEHOLDER · playtest 定义] → 判定阈值重标；玩家成片后 5 秒内跳过题跋动画 → 动画太长或无信息量，删。

## 3. 古树寻访（植）

- **purpose**：用真实名木承载"植物图鉴 + 人文故事"双内容，填补"植"任务族。
- **player experience goal**："这棵树比这园子还老"——时间尺度带来的敬畏感。
- **inputs**：线索卡（叶形剪影 / 树皮纹理 / 一句与树相关的诗签或园主轶事）。
- **outputs**：古树图鉴条目（树名、树龄、四季形态）+ 一段 50 字内的人文故事 + 照片入"园谱"。
- **玩法流**：得线索卡 → 循线索寻树（线索难度递进：剪影 → 特写 → 方位诗签）→ 触摸互动（像素手抚过树干，年轮涟漪扩散）→ 拍照定格 → 图鉴点亮。
- **素材原则**：**只用可考据的真实古树名木**。候选方向：拙政园文徵明手植紫藤（"文藤"）等；每棵树的树名、树龄、故事一律需实勘/文献核对后才进文案，禁止编造。[PLACEHOLDER · 素材考据清单待建]
- **edge cases**：
  - 落叶树冬季辨识难 → 图鉴按四季分四格，同树不同季回访可重复拍照，集齐四格得"四时"徽记——这是最强的回访钩子，优先做。
  - 树太小找不到 → 线索卡自带"距离热感"（离得越近卡片边缘墨色越浓），不用地图标点。
- **failure states**：玩家集卡后不寻树直接查攻略 → 说明线索卡自足性不足，考据期用眼动/口语协议测试线索可读性。

## 4. 取景匣支撑的衍生任务（同匣多用，按开发优先级排序）

| 任务 | 玩法 | 优先级 | Rationale |
|------|------|--------|-----------|
| 漏窗内的画 | 框住漏窗对位，窗内景致拼合（=瞬间循环的拍照版，兼做教学） | P0 | 教学即玩法 |
| 四时同景 | 同一机位四个季节各拍一张，拼成四季屏 | P1 | 复用机位数据，回访钩子 |
| 剪影对位 | 给建筑/湖石剪影，找到实景角度拍下 | P1 | 素材成本低，验证构图系统 |
| 生肖/瑞兽寻影 | 屋脊走兽、湖石纹样里"认"出形象并拍摄 | P2 | 人文向软任务，可忽略不惩罚 |

## 6. Playtest 失败信号（先定义坏，再开测）

- **A 信号**：玩家平均每张诗卡尝试 > 4 次才成片 → 判定太苛。
- **B 信号**：玩家全部任务靠提示通关且表示"没找到东西的乐趣" → 提示系统越权。
- **C 信号**：玩家拍完不存不看相册 → 照片奖励层无价值，重做落款/诗卷的"好看"。
