## 1. 核心两本

### 刘敦桢 主编《苏州古典园林》
中国建筑工业出版社，1979 年初版（后有再版）

**性质**：苏州园林研究的奠基性实测报告——总论（叠山、理水、建筑、花木、装修分章）+ 十余座园林的逐一分论，附大量实测平面图与图版。

**喂给游戏的模块**：

| 游戏模块 | 用书中的什么 | 对应文档 |
|---------|-------------|---------|
| 关卡白模 | 各园**实测平面图**（动线、庭院尺寸、建筑方位）——这就是关卡底图，不用自己画 | 全部章节 |
| 窗二"纹样匹配"谜题 | **花窗/漏窗图版**——冰裂纹、如意纹、海棠纹等纹样逐一核对，纸面原型里的纹样假设以此为准 | 首章素材·窗二 |
| 古树图鉴 | **花木篇**——树名、位置、品种的官方记录，替代"编一棵"的风险 | 任务设计·古树寻访 |
| "一园一性格" | 各园分论——每园的空间性格、沿革、特色要素，逐园档案的事实源 | 主线设计·六艺转译表 |
| 数艺尺度谜题 | 理水/叠山章的尺度与比例记录 | 主线设计·数 Lv2 |

### 陈从周《说园》
同济大学出版社，1984 年初版（2017 等再版）；另有《园林谈丛》（上海文化出版社，1980）

**性质**：五篇系列演讲文字，中国园林美学的现代经典。它不给图，给**语言和判断**。

**喂给游戏的模块**：

| 游戏模块 | 用书中的什么 | 说明 |
|---------|-------------|------|
| 三层核心循环的理论背书 | **"静观 / 动观"**——园可静观（坐看一景）亦可动观（游廊移步换景）。我们的瞬间循环（停步取景）与单局循环（动线任务链）正是这对概念的机制化 | 主线设计·宏观 |
| "一园一性格"的审美依据 | "园之佳者如诗之绝句，词之小令"——各有性格，忌雷同 | Pillar 4 |
| 网师园机制主题 | **"小中见大"**——书中对网师园以小胜大的分析，直接定死数艺尺度谜题的设计依据 | 六艺转译表 |
| 跨园借景长线 | 借景论述——"借者：园虽别内外，得景则无拘远近" | 核心循环 |
| **现役人物的台词文体母本**（顾惟清／沈砚秋／阿槿／乔瓷／乔老叟） | 全书语言风格：短句、口语中带文言、判断句下得干脆——「不是你找景，是你走到它愿意给你看的位置」这个语气基准就出自这一路。⚠️ **原写作「师父信件与扫叶叟」——该二人挂在已废止的师父线上，已改** | 全部台词 |
| 书艺内容源 | 书中论楹联、匾额、题咏与园景互成——集字修匾的取材库 | 六艺·书 |

| 《中国古典园林史》 | 周维权，清华大学出版社 | 历史背景、各园年代断代（结算钤印小字的事实源） |

## 3. 使用纪律（三条，红线）

1. **书是 1979 年的，园是 2026 年的**。《苏州古典园林》实测图可作为关卡白模底图，但植物、修缮改动必须实勘更新——实测图管布局，不管现状。
2. **文案只化用，不照抄**。现役人物的语言学《说园》的路数，但原文引用须核对版本页码、标注出处；游戏文案直接整段搬原句既涉版权，也丢了自己的声音。
3. **两本分工不越界**：空间事实问刘敦桢（图说了算），审美与语言问陈从周（他说了算）。别拿《说园》定窗纹，也别拿实测图定台词。
