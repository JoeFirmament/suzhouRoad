# 姑苏九园 · 统一像素视觉系统定案

> 定案日期：2026-09-29  
> 目标：**从标题、Intro、人物谱、世界地图、Home 到园林近景，始终让玩家感觉自己身处同一个低饱和 2.5D 像素游戏。**

## 1. 像素风不是滤镜

统一风格不能依赖最后给图片加“马赛克”滤镜。它必须同时约束：

- 色板；
- 像素密度；
- 构图与透视；
- UI 尺寸网格；
- 边框、阴影和动效；
- 文字与图片的分工；
- 资产导出与浏览器缩放方式。

中文正文不强制使用低分辨率点阵字。宋体承担叙事可读性，像素感由图像、4px 网格、硬边框、阶梯动效和无圆角界面共同建立。

## 2. 唯一色源

颜色以 `Game/assets/palette/palette.json` 为唯一色源。新增颜色必须先登记，不能在单个页面随意发明。

玩家界面的主色关系：

| 功能 | 色值 | 用法 |
|---|---:|---|
| 碑墨 | `#171512` | 最深背景 |
| 焦墨 | `#2b2824` | 面板与深色建筑 |
| 宣纸 | `#f2ead6` | 主文字与高光 |
| 淡墨 | `#a39d90` | 次文字、锁定状态 |
| 金棕 | `#c8a04b` | 可交互、章节、已掌握 |
| 印泥深红 | `#8f271d` | 主按钮、当前目标、重要选择 |
| 水深 | `#6fa89e` | 水面、城市水路与空间关系 |
| 深潭 | `#2a514c` | 深绿背景与水下阴影 |

朱色只能承担点睛和操作反馈，不能大面积铺满。园林植物不使用高饱和荧光绿。

## 3. 4px UI 网格

- 所有玩家界面以 4px 为最小视觉单位；
- 主要间距优先使用 8、12、16、24、32px；
- 边框以 1px/2px 为主，关键焦点为 2px；
- 投影使用 4px 或 8px 的硬边位移，不使用模糊浮层阴影；
- 按钮、卡片、对话框一律直角，不使用现代 App 式大圆角；
- 触屏操作区域可以放大，但外形仍服从直角与整数网格。

## 4. 三种像素密度

### 世界层

- 信息密度低，角色和地点是符号；
- 《蘇城全圖》的河道与街巷骨架优先可读；
- 不在地图上堆写实小建筑。

### 园林层

- 角色、路径、建筑轮廓与 POI 可辨；
- 一屏能判断“园如何组织”；
- 采用统一 2.5D 投影和整数倍率缩放。

### 近景层

- 像素密度最高，用于水、廊、窗、山石和前后遮挡；
- 角色必须真实经过栏杆、柱、树影的前后层；
- 谜题判定由语义位置与数据完成，不从背景图片猜测。

三层可以拥有不同细节密度，但角色比例、色板和光线方向不能突然换一套游戏。

## 5. 标题、Intro 与人物谱

- 标题背景可使用地图或场景像素资产，不使用写实照片直接铺底；
- 开场人物行动使用低分辨率 Canvas 精灵逐帧绘制：书生入城、府学相遇、送纸、开谱与入园；
- Intro 转场使用 2–4 阶的阶梯式淡变，不做柔滑电影模糊；
- 人物介绍最终应使用统一尺寸的像素半身像或动作小像；
- 半身像先画动作和轮廓，再补服饰，不制作光滑日系立绘；
- 人物谱锁定项用淡墨处理，不能只靠降低透明度到不可读。

## 6. 角色与场景资产

### 玩家角色母版（已定案）

- 完整人物原画：`Game/assets/characters/scholar-cute-v1.png`；
- 四向行走精灵：`Game/assets/characters/scholar-player-sprites-v1.png`，固定为 4 行 × 3 列、单格 362 × 362；
- 行序：正面、向左、向右、背面；列序：站立、左步、右步；
- 黑色儒巾、米白长衫、灰绿色缘饰、深赭红腰带、地图与空白园谱是不可随场景漂移的身份特征；
- 原画用于标题、学籍和重要叙事；精灵用于地图、园林与近景移动。二者必须保持同一人物，而不是按页面重新生成角色。

- 原始像素资产以低分辨率绘制，浏览器只做整数倍放大；
- 禁止对像素资产做双线性平滑；
- 同一角色必须共用固定头身比、肤色、服装主色和朝向规则；
- 角色至少包含站立、四向行走、观察/交互三个动作组；
- 场景分地面、墙/建筑、中景物件、角色、前景遮挡五层；
- 阴影使用有限色阶和块面，不使用大半径高斯模糊。

## 7. 动效与反馈

- 移动帧、按钮反馈、提示出现均采用 `steps()` 或离散帧；
- 水波和树影可以持续运动，但幅度低、周期错开；
- 对话切换不使用弹簧、缩放或卡片漂浮；
- 重要奖励只允许一次朱印、题签落位或园谱补页，不使用手游式粒子爆发；
- `prefers-reduced-motion` 下取消所有非必要转场。

## 9. 新页面验收清单

新页面或新场景进入主分支前必须逐项通过：

- 是否只使用登记色板？
- 关键间距是否落在 4px 网格？
- 是否出现无理由圆角、模糊阴影或玻璃拟态？
- 位图是否 `image-rendering: pixelated`？
- 放大倍率是否尽可能为整数？
- 角色比例是否与沧浪亭样板一致？
- 朱色是否只用于当前目标和关键反馈？
- 桌面与手机是否仍像同一款游戏？
- 去掉页面标题后，玩家能否仅凭 UI 和色板认出《姑苏九园》？

任一问题回答“否”，该页面仍是功能原型，不能视为正式游戏画面。
