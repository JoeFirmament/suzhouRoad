## 0. 一句话

**案上最显眼的位置，供着一片干枯的芭蕉叶**：紫檀小托衬着，一枚玉件压着，叶子的裂口被人一次次用薄纸托裱过——**一看就知道，这是这间屋子里最要紧的东西。**

**一只老鼠从案脚的书堆里窜出来，猫扑上去追。追到案上，老鼠钻进了叶子底下——那是案上唯一一处有缝可躲的地方。猫一爪按下去。**

**府学先生顾惟清冲进来，跪在案前，把碎片一片片收起来。手在抖。二十年来，他第一次不用引经据典——因为他说不出话。**

那片叶子上有字。**主人一直知道有字。** 用明矾水写的，干了无痕，**遇湿才显**；每显一次，叶子就坏一点，所以他读得很省，读得很慢。

**那不是一片"写着字的叶子"。那是一封信——「九封信」的第一封。** 二十年前，一个人离开苏州，把话写在了这片叶子上，留给了他。写的人、等的信、走的人，全在这首诗中：

> **病里昏昏不记春，**
> **竹梆敲过巷西邻。**
> **淡的一碗留君吃，**
> **多花那碗我自斟。**

一首写**糖粥**的诗。**而这首诗里藏着一句只有一个人听得懂的话——"淡的一碗""多花那碗"。**

**破译它的人，是那个八岁的小姑娘。** 乔禾看见"竹梆"两个字，脸就白了：**"那是我家的担子。"** 她跑回家去问爷爷——**而爷爷记得那碗粥。**

## 1. 它在结构里的位置（先解决"和既有暗线打架"）

### 1.1 现状：项目里已经有一条没启用的暗线

《主线与六艺系统设计》B2 节写的是**「师父的九封信」**——每补全一页《九园图》，画轴夹层浮出一封信，讲师父与一位故人的旧事；终章第九封信指向落款空位。

**但该文档自带声明**：「画师弟子／师父九封信／90 分钟单园与师承互斥**尚未纳入新定案**」，当前以《游戏形态与核心玩法设计定案》《任务设计系统定案》为准。

**换句话说**：这条暗线现在是**空位**。而"信从夹层里浮出来"这个意象，恰好是它的弱点——**它太方便了**：信会自己出现，玩家不需要做任何事。

### 1.2 本线的处置：**信叶合一**（D 案 · 大 Q 2026-09-30 拍板）

| 案 | 做法 | 评价 |
|---|---|---|
| A 替换 | 废掉「九封信」，全用蕉叶 | 丢掉"每章一封信"的节奏器，可惜 |
| B 并行 | 两条暗线各走各的 | 玩家要追两条线，序章埋两个谜，**过载** |
| C 合并（v0.2 旧案） | 把"信"降格为"叶"，只留一片 | 载体更实，但**把"九"这个数字丢了**——而"九"是本作骨架 |
| **D 信叶合一 ★本轮启用** | **九封信 = 同一作者的九封"不同载体的信札"**，散在苏州各处；**芭蕉叶是其中的第一封** | 保住"每章一封信"的节奏器，同时保住"信要自己去找"的难度 |

**骨架**：

```text
原案（历史草案）：九页 → 九封信（每章自动从画轴夹层浮出）  → 终章落款
                    ↑ 弱点：信会自己出来，玩家什么都不用做
本稿 D 案：        九页 → 九封信（散在苏州，一封封找、一封封读懂）→ 终章落款
                    ↑ 修复：信要找、要读得懂、要有人帮你认
```

**关键差异**：原案的驱动力是"信里提到了什么"（信息驱动）；本稿的驱动力是**"我还不知道他写了什么——而且我不知道还有八封"**（缺失驱动）。

> **一句话说服**：一份没读完的东西，比九封写好的信更让人放不下。

### 1.3 合规依据（**必须写明，否则会被当成"复活废止设定"打回**）

《任务设计系统定案》§废止 明确列过：**"画师弟子与'师父九封信'作为主角身份前提"——已废止**。
但《游戏形态与核心玩法设计定案》同时留了口子：

> 「旧文档中"师父九封信"**可转化为府学师长、同窗或园林故人的信札**，但**不再作为玩家身份的前置**。」

**本线走的正是这条路，逐条对齐**：

| 废止项 | 本稿的处置 |
|---|---|
| ❌ "玩家是画师弟子" | **不采用**。玩家身份仍是府学学子（现行定案） |
| ❌ "九封信作为主角身份前提" | **不采用**。九封信不是玩家自带的遗物，而是**散在苏州、需要去找的信札** |
| ❌ "信从画轴夹层自动浮出" | **弃用**（这正是原案最大的弱点） |
| ✅ "转化为府学师长、同窗或园林故人的信札" | **采用**。第一封（蕉叶）是写给**府学师长顾惟清**的 |

> **一句话**：九封信不是玩家的身世，是**这座城里的九段关系**——玩家一封封找，一点点拼出"我的老师是个什么样的人"。

### 2.3 写作纪律（硬规矩，越界即废）

| # | 纪律 | 为什么 |
|---|---|---|
| 1 | **顾惟清一句台词都没有** | 他全场只有一句不引经据典的机会——**这一场连那句都不给**。全序章唯一一次沉默，才有分量 |
| 2 | **玩家不能问、不能选、不能上前** | 这是"撞见"，不是"对话"。一给选项，玩家就会觉得这是任务起点 |
| 3 | **"珍重"必须在前 3 拍之内看懂，不靠任何人解释** | 用对比说话：**满案的东西都随手搁着，只有它被摆正、被托着、被压着、被裱过。** 玩家一眼就该明白这东西有多重 |
| 4 | **主人不需要"发现"有字——他一直知道** | 悬疑不在"有没有字"，在"**谁写的、写了什么、为什么写成看不见的**"。角色若表现得像第一次知道，本场失败 |
| 5 | **不惩罚猫** | 顾惟清没打猫、没赶猫——**因为从猫的立场看，它在干它该干的事**（抓偷书的鼠）。他的怒无处可发，这比骂猫更沉 |
| 6 | **不解释叶子、不解释人、不给提示条** | 悬疑的全部资本就是"信息不足" |
| 7 | **玩家拿不到叶子** | 它被收走。但**案脚那一小片没被捡干净**——后续可拾，是本线的物理起点 |
| 8 | **第 7 拍是玩家唯一一次看见那上面的字** | 只一瞥、随即洇没。**看得见"有笔痕"，看不见内容**——这一瞥之后，它就永远碎了 |

> **给工程的一句话**：这场戏的所有演出都靠**动作与声音**，不靠台词与 UI。若能做成"玩家自己走到门口才触发"，比强制播片更好。

## 3. 悬疑的三层

| 层 | 玩家的问题 | 玩家什么时候有答案 |
|---|---|---|
| **第一层 · 表面** | 这东西显然极贵重——满案杂物里只有它是"供"着的。**可一片枯叶子，凭什么？** | **不答**——这正是钩子 |
| **第二层 · 追问** | 上面写的是什么？谁写的？为什么要写成看不见的？ | 留园章：学到"蕉叶可以写字"，且听到那句"写在不算数的地方" |
| **第三层 · 真相** | 写字的人是谁？他在哪？ | **留园章末解一半——"是我老师"**；他在哪，跨章放出 |

**设计要点**：
1. 三层不能在同一章给完。第一层给情绪，第二层给方法，第三层给意义。
2. **第一层的力度全在"对比"**：一间堆满书与杂物的屋子，只有一片叶子被摆正、被托着、被压着、被裱过。**不需要任何人说"这很重要"，案面自己会说。**

## 4. 那片叶子：实物设定

### 4.1 器物与形制

| 项 | 设定 | 说明 |
|---|---|---|
| 承托 | **一件精美的器物**（紫檀小托／旧端石小几／宋瓷小盘），**独占案上最正的位置** | 用户原话"一看就知道对主人十分重要"——这句话必须靠**陈设姿态**实现，不靠台词 |
| 对比 | 案上其余物件（笔墨纸砚书）**全是随手搁的** | 一片叶子是全屋唯一"摆正"的东西。**这个对比就是全场最好的台词** |
| 叶子 | 一片**干枯的黄芭蕉叶**，约一掌长 | 芭蕉叶大而厚，是最像"纸"的叶 |
| 托裱 | **叶缘的裂口处裱着一层层薄纸，纸已发黄** | 关键细节：**它被抢救过很多次**。玩家看到的不是一片完整的叶子，是一件**修补过多年的旧物**——这直接说明主人守了它多久 |
| 压物 | 叶上压一枚**小玉件**（或笔山） | 干叶会翘，必须压着——**"压着才不敢动它"** |
| 匣 | 案边有一只**旧木匣**，匣盖敞开，内衬褪色旧锦 | 匣是**装书的**，最终却用来装这片叶子。这个错位本身就是一句话 |

### 4.2 字：为什么看不见（**本线最关键的机制**）

> **前提（大 Q 修正，必须先立住）**：**主人一直知道叶子上有字。**
> 所以这不是"发现谜"，是**"守护谜"**——他知道字在哪、什么条件下能看见、能看见多少，他读得很省，读得很慢。
> 角色若有半分"咦，这上面怎么有字"的反应，本场即废。

**考据结论（已核，必须遵守）**：

| 原始想法 | 判定 | 处置 |
|---|---|---|
| 字迹极淡、肉眼几乎看不出 | ❌ **不成立**——干叶上的墨迹本来就看得很清 | **弃用** |
| 逆光才能辨认 | ❌ **方向反了**——墨层不透光，逆光只会让字更显 | **弃用** |
| 沾水/受潮才显形（以墨书写） | ❌ **不成立**——水不会让干墨显形，只会洇墨、发霉 | **弃用** |
| **改用明矾水书写（矾书）** | ✅ **有据** | **采用 ★** |

**采信的设定**：

> 那片叶子上的字，是**用明矾水写的**。干了以后全无痕迹——**对外人来说，就是一片什么都没有的枯叶**。
> 只有在**受潮**的时候，被浸到的那一块才会浮出淡褐的笔痕；**湿气一散，字又消失**。
> 而**主人记得那些字都在哪一块**——他不需要看，他只等一个雨天。

**考据支撑（有据）**：矾书是真实的古代隐写术——《建炎以来系年要录》载「枢密院矾书」、《金史》载「赍矾书告急」、清康熙五十四年有「矾书案」。**明矾水写字、遇湿显形**在化学与史料上均成立。

> ⚠️ **需标注的一步**：史料中矾书多用于**军事与密信**，**"用于赠友"属本作演绎**，须在知识条目中标"演绎"。此外禁用两条常见伪知识：**米汤密写**（存世案例全是近代地下党，非古代）、**醋／果汁密写**（查不到任何古代出处）。

### 4.3 二十年与"读一次少一次"

**考据结论（有据）**：干枯的蕉叶**极脆**（贝叶经文献明载"最轻微触碰即碎"），且墨／矾层附着在叶**表面**而非纤维内，一摩即失。**"每读一次就损一点"——成立。**

于是主人二十年来的日子是这样的：

```text
每年梅雨季 / 偶尔的雨天 / 一次哈气
        ↓
   叶上浮出几个字
        ↓
   他读一小块，然后字消失
        ↓
   而叶子比上次更软、更霉、边缘更脆
        ↓
   于是下一次，他更不敢读
        ↓
二十年后，只剩靠边的一小块还读得出
```

> **最关键的一句设定**：**他不敢一次读完。因为读完，就没了。**
> 这不是悬念的装饰，这是整条线的情感引擎。

### 4.4 字的内容（**已定稿 · 大 Q 2026-09-30**）

**拍板结论**：叶上写的是一首**关于糖粥的寄语诗**——二十年前那个人临走前留下的、**一段两人共食糖粥的回忆**（其中一碗，是给病中的顾惟清的）。

**"没写完"仍是本线题眼，只是换了位置**：诗的正文写完了，**诗后那半句告别没写完**（最后一道笔画拖出叶边）。**"没写完"从"整封信"缩小到"最后半句"**，反而更准、更狠。

| 项 | 定稿 |
|---|---|
| 体裁 | 七言四句 + 落款（落款被水洇，读不全） |
| 内容 | 写的是一碗**糖粥**：某年顾惟清病中，那个人从巷西的糖粥担买了两碗——**淡的一碗（不加糖）给病人，多花的那碗（桂花加双份）自己喝** |
| 唯一性线索 | **「两碗 + 不用糖 + 桂花双份」的组合**（规则见 §4.6.3）——全苏州当年只有这一个人这么点 |
| 未完成处 | 诗后原还有半句，**笔画拖出叶边，断了** |
| 全文 | 见 §4.6 |

> **为什么"糖粥"是最好的载体**：它不是风雅之物，是**市井之物**。本作的主题是"知识活在生活里，不在书里"——那么一封最要紧的信，写在**最不像信纸的东西**上、说的是**一碗粥**，比任何"雅事"都更贴题。

## 4.6 叶上那首诗（定稿）

### 4.6.1 全文

```text
        病里昏昏不记春，
        竹梆敲过巷西邻。
        淡的一碗留君吃，
        多花那碗我自斟。
                            〔落款：被水洇，仅余一竖一捺，认不出姓〕
                            〔诗后半句：笔画拖出叶边，断了〕
```

### 4.6.2 逐句注

| 句 | 字面 | 真实信息 |
|---|---|---|
| 病里昏昏不记春 | 你病着，昏昏沉沉，连时节都记不清 | **顾惟清当年大病过一场**——诗里唯一提到"人"的地方 |
| 竹梆敲过巷西邻 | 卖糖粥的竹梆声，从巷子西头响过来 | **指明是挑担的糖粥**（＝乔老叟的担子）＋方位"巷西" |
| 淡的一碗留君吃 | 不加糖的那碗，留给你 | **病中的顾惟清忌甜、不吃糖** |
| 多花那碗我自斟 | 桂花加双份的那碗，我自己喝 | **"多花"＝桂花加倍**——唯一性线索在这里 |
| 〔落款〕 | — | 被水洇掉。**玩家读不到署名**（悬疑保留） |
| 〔后半句〕 | — | 断在"明年"二字之后——**"明年"什么？** |

### 4.6.3 唯一性线索的规则（**这条必须守住，否则推理崩**）

> **线索不是"不加糖"，是"两碗 + 不加糖 + 桂花双份"这三件事的组合。**

| 单项 | 是否唯一 | 说明 |
|---|---|---|
| 一碗不要糖 | ❌ 不唯一 | 不吃糖的人多得很 |
| 桂花多加 | ⚠️ 少见但不唯一 | 加钱多要一勺桂花，偶尔有人干 |
| **两碗：一碗无糖 + 一碗双份桂花** | ✅ **唯一** | **二十年里，只有这一个人这么点过** |

**为什么它经得起推敲**：糖粥担是**赊账生意**——老主顾按节算钱，**乔老叟凭"点法"认人，不是凭脸**。**一个人的口味，比他的脸更难忘。** 所以这条线索在设定内是硬的，不是巧合。

> ⚠️ **反例警戒**：**不许**写成"因为诗里写了某人的名号，所以就是他"——那是数据库检索，不是推理。
> 玩家要得到的，是一个**"别人记得他"**的事实：**"他是那个'多花一碗'的人。"**

### 4.6.4 考据注（本诗）

| 项 | 判定 | 处置 |
|---|---|---|
| 平仄格律 | ⚠️ **不合格律**（真／侵通押，属口语体） | **有意为之**：这位先生不端着，"打油体"合人物。**不入正文诗词集**，只当他本人的随手题赠 |
| 竹梆招徕 | ✅ 有据（姑苏吆喝非遗；竹梆为糖粥担标志声） | 可用——**乔禾认的就是这个声音** |
| 桂花入糖粥 | ✅ 有据（糖桂花为传统浇头之一） | 可用；"加钱多花"属演绎，需标注 |
| 「红云盖白雪」 | ✅ 有据（赤豆沙盖白粥的形容） | 可作视觉注脚——与本作"朱砂红压宣纸白"同源 |
| "不吃糖"作忌口 | ✅ 常识性可采 | 无需特别标注 |

## 4.5 猫与鼠（这一场的肇事者）

> 大 Q 指定：**加入猫追赶老鼠、踩碎芭蕉叶的桥段**。这个改动比我原稿好——**猫有了职责，鼠有了动机，灾难才有因果**。

### 4.5.1 各自的立场

| 角色 | 它在干什么 | 在这场戏里的功能 |
|---|---|---|
| **鼠** | 来偷书的 | 从案脚的**书堆里**窜出来——它不是闯入者，是这间屋子的常客 |
| **猫** | 府学养来防鼠护书的 | 它在履行职责。**它把鼠逼上了案；为了按住那只鼠，它按碎了一片叶子** |

### 4.5.2 讽刺的闭环

> **猫是书匣的卫士。它毁掉的，正是书匣里最珍贵的东西。**

而主人**没有惩罚猫**——不是宽宏，是**他心里清楚：猫做的是它该做的事**。这个"不迁怒"比骂一顿重得多，也是他教养的一部分。

### 4.5.3 设定建议

| 项 | 建议 |
|---|---|
| 猫的归属 | 府学的猫（防鼠护书用），无正式名字；学生私下怎么叫它，待定 |
| 猫是否被罚 | **没有**。他没骂、没打、没赶。他只是把它抱下案，然后跪下收叶子 |
| 猫的后续 | 升级为**系列级"灾难制造者"**：后续章节可以反复出现——**每次都在干它该干的事，每次都在毁东西** |
| 鼠的后续 | **鼠必须活下来并逃走**。它是这场事故里唯一"按本分行事、却毫无牵连"的一方——**这份不公平本身就是戏** |
| 场景细节 | 书匣里可放**芸香／皂角末**（府学防虫五法，有据）——**主人已经尽力在防了，还是没防住**。这一笔让"为什么"不落在"疏忽"，落在"命" |

### 4.5.4 写作禁令

| 禁令 | 理由 |
|---|---|
| 不写"猫心想……"这类拟人内心戏 | 本作从不进动物视角 |
| 不做猫的主观镜头 | **镜头始终是人眼**——玩家和主人一样，只能看见结果 |
| 不给鼠加喜感演出 | 鼠的存在只有一个用途：解释猫为什么冲上案。**它不搞笑** |
| 不把猫写成"反派" | 它没有恶意。**这一场没有一个角色有恶意，叶子还是碎了**——这才是本场最刺痛的地方 |

### 4.5.5 可用考据

- **沈起凤（吴县人、曾任训导）《谐铎·讨猫檄》**：写"为防鼠而养的猫，反被鼠咬鼻子"——"养猫不捕鼠"的牢骚。与本场形成有趣互文（**作氛围参考，不得真人入戏**；网传"汪起凤"是误写，勿沿用）。
- **藏书虫鼠之患是普遍记载**——序章剧本 PRO-09 已经出现过"扉页藏印**被虫蛀去了一半**"，此处是**同一座院子的回响**：这屋子里的鼠，玩家其实早就见过一次了。

## 5. 主人是谁：为什么是顾惟清

**结论：主人 = 顾惟清（序章那位引经据典的府学先生）。不新造人。**

| # | 理由 | 说明 |
|---|---|---|
| 1 | **他的声纹就是伏笔** | 一个只会引经据典的人，是因为**自己有一句话，二十年前没说完**。他的"借别人的话"不是学究气，是**失语**——本线给声纹表补上了动机 |
| 2 | **反差最大** | 全序章最克制的人，唯一一次失态。玩家不需要任何解释就知道"这东西有多重" |
| 3 | **与乔老叟天然同场** | 乔老叟是**府学杂役**兼卖糖粥——他给府学的先生们送粥。顾惟清是他的老主顾。**"一个人二十年前订粥、后来不订了"，只有卖粥的记得**——见 §7 |

**风险与对策**：把一个事务性 NPC 升级为暗线核心，会让他在后续章节承担更多戏份。
→ **对策**：本线**不增加他的出场频率**，只增加他**每次出场的分量**。他依然可以是个偶尔出现、话很少的人——只是现在，玩家知道为什么了。

## 6. 知己是谁：**「主角的老师」**（大 Q 2026-09-30 拍板）

### 6.1 身份（**已定**）

**结论：写字的那个人，就是主角自己的老师。**

这是本线**最重要的一次身份合并**——它把两件事变成了一件事：

```text
玩家以为在做的事：  替顾惟清，找一个二十年前的故人
玩家实际在做的事：  找自己的老师——那个带自己开蒙的人
```

| 项 | 设定 |
|---|---|
| 姓名 | **陆蘅**（大 Q 2026-09-30 拍板） |
| 身份 | **主角来苏州之前的那位先生**（家塾／私塾老师；**不是画师**——避开已废止的"画师弟子"设定） |
| 与顾惟清的关系 | **二十年前的知己**。两人在苏州相识，交情极深 |
| 为什么离开 | 二十年前离开苏州。**他再也没有回来——他从没食言，是没来得及**（见 §6.2） |
| 与玩家的关系 | **正是他，让玩家来苏州府学读书** |
| 玩家手上的实物 | 玩家随身带着**老师写给他的一封信**（九封中的第九封，见 §6.4）——**不构成"身份前提"，只是随身之物** |

**命名（已定）**：**陆蘅**（大 Q 2026-09-30 拍板；另两候选「周澹」「徐照」作废）。

> **⚠️ 名字只在设计层存在。** 本稿正文、台词样本、任务文本**一律继续记作「那位先生」**——**在玩家知道名字之前，我们也不给他名字**。
> 这不是遗漏，是设计：**一个直到最后才知道名字的人，和一排从来没人叫得出名字的树，是同一件事**（与《府学六杏·状元果与白果》§7.1「无名对无名」咬合）。

> **为什么"老师"是最好的答案**：本作主角是府学学子，而**"老师"是人人都有的关系**——不需要特殊身世（画师弟子），一句"我老师"就够了。
> 玩家一直以为自己在替别人找故人，最后发现**找的是自己的老师**——**这个反转不需要任何新设定，只需要玩家自己把两件事连起来。**

### 6.1.1 这一合并为什么值钱（三条）

| # | 收益 | 说明 |
|---|---|---|
| 1 | **"找人"变成了"认人"** | 玩家不必认识那位先生的脸——**只要认得他的字、他的习惯、他喝粥的口味**。"认"比"找"更符合本作"知识活在生活里"的主题 |
| 2 | **旧账一次结清** | "画师弟子／师父九封信"被废止的根因是"**不该用师父给玩家特殊身世**"。本稿不给他任何身世：**老师就是老师，谁都有一个**。这条线从此合规 |
| 3 | **情感落点从"遗憾"变成"原来是他"** | 若知己只是陌生故人，玩家是旁观者；一旦是**自己的老师**，玩家就是当事人——**那片叶子上的字，是写给玩家的老师的朋友的** |

### 6.2 他在哪？——**已定案：A′「他活着回来了，死在你到苏州的前一年」** · 大 Q 授权我判断 → 我拍板 A′（2026-09-30）

**结论：他是已故的。但不是"离开之后不久就死"，而是——**
**他二十年前离开苏州，在外乡又活了二十年；晚年病重回苏州养病，住在城南；死在玩家到苏州之前。他从没食言——是没来得及。**

#### 6.2.0 为什么不是"二十年前就死"（**A 案有一处硬伤，我必须说清**）

大 Q 上一轮拍板 **A「已故」**，方向我完全同意。但 A 案的**具体死期**（「离开苏州之后不久」）经不起推敲：

| 硬伤 | 说明 |
|---|---|
| **八封信写不出来** | 他是**二十年前**就死了，那后面八封信只能是**他走之前写好的**——**一个二十年前的人，怎么可能预先留下八封散落在九园各处的信？** |
| **而且这会把"来不及"变成"有预谋"** | 若他预先写好八封，那不是"没来得及"，是"安排妥当了"。**整条线最珍重的那口气，当场泄掉。** |
| **"遗物"也就无从谈起** | 遗物是**身后留下的东西**。人还没走就先留八封，那是**遗嘱**，不是遗物。 |

> **所以：方向（已故）不动，死期（不久）改掉。** 这就是 A′。

#### 6.2.1 A′ 的完整时间轴（**一表定死**）

| 时间 | 事件 |
|---|---|
| **约二十年前（1870 前后）** | **离别那天**。在顾惟清的厅堂里，案上有一片芭蕉叶——他拿起来，蘸墨写下那首诗（§4.6）。**这是顾惟清此生收到的唯一一件。** 此后二十年，音信全无 |
| **此后二十年** | 他**在外乡活着**：教书、写字、过日子。**他写了很多东西，但一封都没有寄回苏州。** 不是赌气——**他想"等能体面地回去了，一并交给他"** |
| **约 1888–1889** | **病重，回苏州养病。** 住在**城南**——**离顾惟清只隔几条街。他没有去找他。** 理由：**一个落魄的人，不肯让故人看见自己这个样子** |
| **1889 冬 ~ 1890 初** | **病故。**（⚠️ 具体年月留白，不进台词） |
| **玩家到苏州** | **不满一年之后。** |

**四样东西同时保住：**

| 保住了什么 | 怎么保住的 |
|---|---|
| ✅ **八封信有着落** | 他活了二十年，才写得出来。**每一封都是他真的活过那一天的证据** |
| ✅ **"来不及"成立，而且更准** | 他来得及写、来得及教、来得及安排——**唯独没来得及见他一面** |
| ✅ **痛感从"扑空"升级为"差一点"** | 原 A 案是"注定扑空"；A′ 是**"早来一年就能见到"**。**参与感完全不同** |
| ✅ **沧浪亭 Day1 那句不用删** | 见 §6.2.2 |

**A′ 最狠的一层（这一层是新长出来的）：**

> **玩家来苏州，是老师临死前安排的。**
> **玩家以为老师在托付他读书——其实老师在把自己送回苏州。回到那个他没脸回去的地方。**
>
> **玩家不是老师派来的信使。玩家是老师寄回苏州的最后一封信。**

#### 6.2.2 沧浪亭 Day1 那句：**不用改了，只改时态**

原句（《首章入园一日完整剧本·沧浪亭Day1》**已归档 `archive/`** ／书肆周先生验纸）：

> 「画这卷子的人……**就在城里养病。腿脚不便，脾气不小。**」

**v0.4 时我判它"与已故直接冲突"。A′ 之后，冲突自动消解——因为他确实回来养过病。**
**只需把时态推过去一个冬天：**

> 「画这卷子的人？**前两年还在城南养病，腿脚不便，脾气不小。去岁冬天，人就没了。**」

**这一句一改，两颗钉子同时钉下：**
1. **"他回来过"**——玩家会想：他回来了？什么时候？住哪儿？
2. **"他死了"**——**而这句话出现在 CH1，玩家当时完全没有在意**（那时他还不知道自己在找谁）

> **这就是本线埋在最早、最不显眼的那一处伏笔。** 一个书肆老板，随口说出了一整条暗线的谜底——**玩家要到倒数第二座园才会想起来。**
> ✅ **原 §6.2.1 的 A／B／C 三案作废**，改为此版。

#### 6.2.3 那九封信的归属（**由此自动理顺**）

| 件 | 收信人 | 顾惟清知道吗 |
|---|---|---|
| **第一封 · 芭蕉叶** | **顾惟清**（离别那天当面写的、当面给的） | **知道。守了二十年。** |
| 第二～八封 | 学生、故人、各处（散落九园） | **不知道** |
| **第九封** | **玩家**（老师临终前写的，把玩家指来苏州） | 不知道 |

> **终章的画面**：玩家把一路上收来的那几件，**摊在顾惟清面前**；而顾惟清手里，**只有一片二十年前的叶子。**
> **他一直是这条线上收信最少的那个人。**

**这一案为什么最沉（三条）**

1. **它把"寻找"变成"追溯"。** 玩家不是在找一个可能还活着的人，是在**拼一个刚走不久的人**——这恰是本作命题（"知识活在生活里，不在书里"）的**人身版本**：人也不在了，只有他做过的事、走过的路、写下的字还在。
2. **它让顾惟清那二十年变成一个无解的动作。** 他每读一次那片叶子，"读一次少一次"（§4.3）——**而这个动作的收信人，在他上一次读完之后的某个冬天，没了。** 这才是"惺惺相惜"最狠的写法：**两个人都没有错，只是时间不给。**
3. **它兑现了"不写完"这个习惯的代价。** 陆蘅写东西从来不写最后一句（§6.4）。**他的人生，也没写完。**

**代价（我必须说清）**

- **"寻找"失去"重逢"的高潮。** 终章"补上那半句"（§8）**不可能交付给收信人**——这既是本线最克制的一笔，也是最大的风险。
- ⚠️ 因此 §8 推进表原"**反转：他改名回城、病中不肯认人**"**作废**。
- **A′ 的替代反转**：反转不再是"他其实在城里"，而是——**"他回来过，就住在城南，隔了几条街；而顾惟清一直在等他先开口。"**
  > 玩家知道真相的那一刻，**不是见到了人，是发现"这场等待原本只差几条街"。**
  > **它不需要任何新场景、任何新人物，只需要玩家把两个时间点对上。** 与《府学六杏》§4.3「一笔算不平的账」是同一个动词：**对时间**。

### 6.3 "寻找"的驱动方式（不要做成寻人启事）

玩家不是在"找一个叫某某的人"，而是在**找"写字的人"**。三个可用的抓手：

1. **叶子的字迹**——认字迹（阿槿的版本功夫能用上）
2. **叶子的内容**——字里提到的地点、物件、句子
3. **生活记忆**——**卖粥的记得他的口味**（见 §7）

### 6.4 玩家怎么"认"出是自己老师（**认人机制 · 关键**）

**不能靠 NPC 说出来**（"那就是你老师"——这是最偷懒的写法）。玩家必须**自己认出来**。

**机制：一条"没写完"的习惯。**

| 环节 | 内容 |
|---|---|
| **设** | 老师**写东西从来不写完最后一句**——写到"明年……"就搁笔。他不信"话要说完" |
| **立** | 玩家到苏州时，带着**老师写给他的一封信**（第九封）。这封信的最后一句话，**也是断的**（当时玩家只当老师忘了） |
| **破** | 叶上诗断在"明年"，玩家手上那封信也断在最后——**同一个"不写完"的习惯** → 玩家自己合上：**这是我老师** |

**玩家手上那封信（第九封）设定**：

| 项 | 设定 |
|---|---|
| 内容 | 交代他来苏州府学读书的事；末尾一句断在半途 |
| 是否构成"身份前提" | **否**。它不揭示任何特殊身世——**任何学子都会带一封老师的信** |
| 在哪里 | 随身（书箱里），可随时重读——**不弹窗、不提示、不计数** |
| 什么时候才有意义 | **只有在玩家读过叶上那首诗之后**才"忽然有意义"——在那之前，它只是一封信 |

> **一句设计纪律**：**认人靠习惯，不靠名字。** 名字可以留到终章才揭；而"他不写完"这个习惯，玩家从第一封信上就该见过一次——**只是当时不懂。**
>
> **落地待办**：序章 PRO-09《本书的来处》（书箱）需加一件——「**老师的一封信**」，与旧书、课页同场，flag `home-teacher-letter-known`。**不加提示、不加重音**，就压在书箱夹层里。

## 7. 破译链：乔禾 → 乔老叟 → 主角的老师 ★★

> 这是大 Q 明确要求回答的部分（2026-09-30）。**四个节点，各在不同层级**，不是重复；而它们的**终点是同一个答案——主角的老师**。

**破译链一眼图**：

```text
①  叶子显形（留园章）        玩家学会"遇湿显字"，读出那首诗
            ↓
②  乔禾认出"竹梆"             "那是我家的担子。" —— 说完就跑回家
            ↓
③  乔老叟认领"点法"           "一碗不要糖，一碗桂花加双份。二十年，没人这么点过。"
            ↓
④  玩家自己对上              叶上断在"明年"，手上老师那封信也断在最后 —— 是我老师
            ↓
⑤  确认                      他二十年前离开苏州，临走把这片叶子留给了顾惟清
```

**这条链的设计意义**：**本案没有一句"揭示台词"**。五步里，NPC 只提供**素材**（一个声音、一个点法），**判断由玩家自己做**——这才符合本作"知识活在生活里，不在台词里"的命题。

### 7.1 机制层：**"找"的能力，是乔禾线给的**

留园章（《一支粥的路线》）里，玩家是通过**替乔禾送粥**才进园、才在书斋学到"蕉叶可写字"这件事的。

```text
乔禾线（送粥入园）→ 学到"叶上可以写字" → 回头才读懂序章那片叶子
```

**换言之**：序章的悬疑，**只有走完乔禾线的人才能解开**。这是"线性必要条件"最经济的用法——**不是卡关，是卡理解**。

### 7.2 能力层：**乔禾是"活地图"，不是"任务发布器"**

乔禾认全城的门、院、巷，也认得全城的**门房、船夫、花匠、伙夫**——她的"认识"来自跟着糖粥担走街串巷。

**用法（重要，避免她变成线索机器）**：

| 该做 | 不该做 |
|---|---|
| 她只说**"哪里有人"**，不说**"答案是什么"** | 不让她解释剧情 |
| 她的信息来自**具体的经历**（"西边第三间，下雨要漏"） | 不给"任务提示"式对白 |
| 她**可能记错**（八岁小孩的记忆） | 不做成百科 |

> **一句设计纪律**：**乔禾只提供"去哪儿"，玩家自己去。** 她永远不给结论。

### 7.3 情感层（节点②③）：**卖粥的一家，是唯一还记得那个人的人** ★★

**这是本线最重的一条咬合，也是大 Q 本轮指定的破译入口。**

#### 节点② · 乔禾认出"竹梆"（她只认声音，不给答案）

玩家读出诗后，**是乔禾先反应过来的**——她不是回答玩家的问题，她是**自己听见了自家的声音**：

> **乔禾**（盯着那两个字）：「竹梆？……那是我家的。」
> （她没解释，转身就跑。）
> **沈砚秋**：「她跑什么？」（玩家只能自己跟上去）

**设计要点**：她**不给结论**，只给一次**辨认**——**"那是我家的"**。这是全链唯一由小孩提供的信息，而它恰好是别人给不了的（**只有她长在那只担子边上**）。

#### 节点③ · 乔老叟认领"点法"（他记得粥，不记得名字）

玩家追到糖粥担，把诗里的那句念给乔老叟听。**他一开始没听懂**——因为他不识字，也不关心诗。他只听懂了**"点法"**：

> **乔老叟**（手上的勺停了）：「……一碗不要糖？」
> **乔老叟**：「一碗桂花，加双份？」
> **乔老叟**：「**二十年了。没人这么点过。**」

**然后他说出那个人的样子**——但**不说名字**，因为他本来也不知道：

> **乔老叟**：「那位先生，是赊账的。教书先生——按节算钱，我认得。」
> **乔老叟**：「一回要两碗。一碗留给自己，一碗……给个病人。」
> **乔老叟**：「后来他就不来了。**他没说去哪儿，我也没问。**」

| 为什么这条最有力量 | 说明 |
|---|---|
| **它把"找人"从推理变成记忆** | 玩家不靠猜谜，靠找到一个"**还记得他口味的人**" |
| **它让乔老叟从"画外音"变成有戏的人** | 他只闻其声的次角身份，在此获得分量——**他不是背景音，他是唯一没忘的人** |
| **它完全符合本作主题** | "知识存在于生活里，不在书里"——**一片叶子上看不见的字，先由一个卖粥的记着** |
| **它反衬顾惟清** | 顾惟清守着那片叶子读了二十年读不懂；卖粥的**什么都没守，却记得清清楚楚**——**读书人不如卖粥人记得清**，这一句就够 |
| **它靠的是"点法"不是"名字"** | 全链没有一次数据库式检索（**"找叫某某的人"**），只有**"找那个'多花一碗'的人"** |

#### 节点④ · 玩家自己对上（**关键，不许由 NPC 完成**）

**这一步绝不能有提示条，绝不能有 NPC 说"那就是你老师"。**

玩家手上有一封信（§6.4，老师写给他的，随书箱带来）。当"不写完"这个习惯被对上——

> **（玩家打开书箱里那封信。信的最后一句，也是断的。）**

**镜头只给一个细节**：叶上那首诗断在"**明年**"；信上那句话断在最后两个字。**两处断口，是同一种笔画。**
**没有任何文字提示、没有任何音效强调。**——玩家自己合上：**这是我老师。**

> **一句设计纪律**：**认人靠习惯，不靠名字。**（§6.4）

#### 节点⑤ · 结构位置与推进密度

| 项 | 设定 |
|---|---|
| 放在哪 | **留园章之后**（玩家已完成乔禾线、已信任这只担子）——**⚠️ 措辞修正（2026-09-30）**：这是暗线的**第一次「破译」**，**不是第一次「推进」**。第一次推进（**「发展」**）在更早——**去退思园的水路上**（§8.1）。两级分工见 §8.1 |
| 推完留什么 | 玩家知道了"**写信的人是我老师**"，但**不知道他在哪、不知道他为什么走、不知道他为什么写成看不见的** |
| 下一个钩子 | 诗后的"**明年**"——那是唯一一个时间词 |
| 不许做的 | **不许在第②③节点里出现顾惟清的名字**（留园章内不得提前并线）；**不许让乔老叟说出"老师"二字** |

### 8.1 「水元素线索」是什么？（**✅ 已定案 A · 大 Q 2026-09-30 拍板**）

> **定案 A：水里映着一棵树。** 人在船上，**先看见水里**那棵树，抬头才发现岸上是一棵**银杏**。
> 落地规格见本节末 **§8.1.1**。

**大 Q 原话**：「放开，**退思园的水路上遇到某个水元素的线索，才发展这条暗线**。」

拆成两件事：
1. **绊放开**（已确认）：植物线的"绊"不锁死退思园，**任何一座有老银杏的园都可以绊**（《府学六杏》§1.5）。
2. **"发展"挂在水路上**：本暗线的第一次真正推进，**不在园里，在去退思园的船上**。

**为什么这个方向是对的（三条）**

- **它把"水"变成媒介。** 去同里必走水路（城外约四十里）。**船上是一个没有任务、没有 UI、动不了的时段**——正是"悬疑在生活边上"最该发生的地方。
- **它与本线最关键的机制同源。** 叶上的字是**矾书**：**干时无痕，遇湿显形**（§4.2）。**本线全部的秘密都建立在"水"上。** 让玩家第一次在水上遇见它，是机制层面的对位，不是巧合。
- **退思园本身就是"贴水"园。** 项目既有记载：退思园**贴水建筑群 + 倒影机位**（`tile-lexicon-nine-gardens.md` §9）。**水、倒影，是这座园的本体。**

**四个候选（✅ 已圈 A，2026-09-30）**

| 案 | "水元素线索"是什么 | 好在哪 | 风险 |
|---|---|---|---|
| **A ✅ 已定案** | **水里映着一棵树**——人在船上，**先看见水里**那棵树，抬头才发现岸上是棵**银杏** | **先看见"像"，后看见"实"**——直接兑现《府学六杏》§4.1「名实层」；而"倒影"本身就是上下颠倒的"名" | 需要美术做水面倒影（退思园本来就有倒影机位，可复用） |
| B ❌ 未取 | **水面上漂着一片叶子** | 叶 → 信的媒介直接对上；与序章那片碎叶呼应 | 略直白，容易退化成"捡道具" |
| C ❌ 未取 | **湿了的船板上浮出几道痕**（遇水显形的第一次"演示"） | 直接把矾书规则教给玩家，后面读叶才不突兀 | **太像教学**，违反"不发提示"的纪律 |
| D ❌ 未取 | **水里映出一个人影**（船上只有玩家，水里却有第二个影子） | 悬疑感最强 | 偏志怪，破坏本作写实调性 |

**取证与纪律（无论选哪案）**

- **不许出现任何提示条、高亮、音效。** 玩家看过就看过了。
- **不许在船上说话。** 主角在船上不说话；船家至多说一句**与线索无关**的闲话（苏州船家腔）。
  > **〔v0.5 增补〕船家可以是乔瓷。** 她跑这条水路的散活（《拙政园章·三堵墙与一个翻墙的人》§4.5），**同一段水路，玩家坐船，她跑腿**。
  > **但她不许说话**——本节纪律对她也适用。**这场船上，她只做一件事：撑船。**（⚠️ 待大 Q 拍板，见《拙政园章》§14-6）
- **✅ 已核（2026-09-30）**：1890 年苏州城→同里的水路实际走法、里程、时长、船资与出城水关，见《姑苏九园-水路考据·府学到拙政园与去同里》**§2**。**含新铁律：1890 年去同里无轮船**（1907 年才有），只能航船／木帆船。

#### 8.1.1 落地规格（A 案 · 定案）

**画面与镜头（全段约 25–40 秒，玩家不可操作）**

| 拍 | 画面 | 说明 |
|---|---|---|
| 1 | 船行水上。镜头给**水面**——水里有一棵树的倒影，枝叶完整 | **先给"像"**。此时镜头**不许带到岸** |
| 2 | 倒影随水纹轻轻晃、碎、又合上 | 水动，像在动。**玩家会以为在看一棵树** |
| 3 | 镜头缓慢上摇，落到岸上——**同一棵树**，是**银杏** | **后给"实"** |
| 4 | 镜头停住。船继续走，树出画 | **不给第二眼** |

**时序铁律**：**先水后岸，不可倒置。** 一旦先照岸上的树，"名实层"的题就散了。

**玩家侧**：全程**不可操作**（船不转向、不能下船、不能暂停看）。**不许生成"看过了"的记录**——它不进 knowledge、不进园谱、不给 flag。

**禁令（与本节纪律同源）**

- 不许任何提示条、高亮框、音效强调、字幕解释；
- 不许主角说话；不许船家（若为乔瓷）就此事说一个字；
- 不许把倒影做成"照见的真相"之类的隐喻说明——**它只是水里有一棵树。**

**接口**：本条与《姑苏九园-府学六杏·状元果与白果》**§4.1「名实层」**同源；**银杏是退思园那棵比园子老的树的前哨**，但**本段不许点名银杏、不许提老树**——只是"岸上那棵"。

**未决项**

1. **水面倒影的美术实现**（真实倒影 vs 程序镜像）——需与像素管线一并定；退思园既有倒影机位可复用，见 `tile-lexicon-nine-gardens.md` §9。
2. **玩家是否可能"没看见"**：本段无操作，故必然看见；但**看不见也不补放**（若做过场跳过，就真的跳过）——待定。

> **推进两级（2026-09-30 口径统一，解决 §7.3 节点⑤ 与本节的冲突）**
>
> | 级 | 在哪 | 给什么 |
> |---|---|---|
> | **① 发展** | **去退思园的水路上**（本节 §8.1） | **只给"像"，不给字**——水里映着的那棵树 |
> | **② 破译** | **留园章之后**（§7.3 四节点） | **读出内容**——遇湿显字 → 乔禾认竹梆 → 乔老叟认点法 → 对上"不写完" |
>
> **顺序依赖**：「破译」必须晚于留园章，因为「叶上可以写字」这件事是在留园的乔禾线里学到的（§7.1）。而「发展」放在去退思园的水路上，**恰好也在留园之后**（九园自由顺序中退思园在留园之后）——两级不冲突。

---

**推进密度纪律**：

- **不能每园都推**——每推一次要隔一到两园，否则玩家会把暗线当主线追，反而失去"悬疑在生活边上"的感觉；
- **暗线永远不占主线任务位**——它只在主线完成后的"回响"时段露面。

## 9. 台词样本（已过五声声纹）

> 依据：《连续序章与府学初到流程定案》**v1.4** §6（**六人六声**：顾惟清引经据典／沈砚秋诙谐／阿槿掺曲／玩家莽稳／乔禾报数／**乔瓷说路程与代价**）

**顾惟清（本场唯一一次不引经据典）**——留给离开前的那一眼：

> 「……那片叶子，你看不清的。」
> （说完就走。**这是他全序章最长的一句**，而它什么都没解释。）

**顾惟清（事后被追问时，他恢复引经据典）**：

> 「『往者不可谏。』——不是不可谏，是没处谏。」

**乔禾（报数，4–12 字）**——她见过叶子后：

> 「那片叶子，我数过。碎成九片。」
> （**她数得比谁都准——因为她只数，不问。**）

**乔禾（破译链节点②——她认出自家的声音）**：

> 「竹梆？……那是我家的。」
> （**她没有解释。她跑了。**）

**乔老叟（节点③——他记得粥，不记得名字 · 吆喝腔，三字一顿）**：

> 「一碗不要糖——」（勺子停在半空）
> 「一碗桂花——加双份？」
> 「二十年了。没人——这么点过。」
> 「那位先生，赊账的。教书先生——按节算钱，我认得。」

**玩家（节点④——玩家自己合上。这一格没有一句台词）**：

> 〔打开书箱，取出老师那封信。信末一句，也断在半途。〕
> （**没有对白、没有旁白、没有音效强调。镜头只给两处断口相同的笔画。**）

**沈砚秋（诙谐，但他这次不抖包袱）**：

> 「你问先生那片叶子？……我问过一回。他没答，我就不问了。」

**玩家（稳档）**：

> 「我不问。我先看看那九片在哪。」

## 12. 风险 · 我的批判

| 风险 | 我的判断 |
|---|---|
| **玩家可能不懂主人为什么发火** | "珍重"已改为**明示**（对比陈设 + 托裱痕迹 + 纪律 3）。第一层悬疑不再是"这重要吗"，而是"**凭什么重要**"。若玩家看完仍无感，问题一定出在**对比没做够**，不是信息给少了 |
| **猫鼠追逐抢了叶子的戏** | 真实风险。对策：追逐全程**不超过 3 拍**，且**不给猫鼠任何特写、不做慢镜**——混乱越短、越含糊，叶子碎得越突然。**主角永远是被踩碎的那片叶子，不是追老鼠的猫** |
| **暗线过重，压过明线** | 真实风险。对策：§8 的推进密度纪律——**每推一次隔一到两园**，且**永不占主线任务位** |
| **"二十年不相认"容易写崩** | 若处理成苦情戏，整条线就毁了。**必须靠"两个体面人的僵持"，不靠"惨"** |
| **顾惟清被过度使用** | 本线不增加他的出场频率，只增加每次出场的分量。**他依然是那个话很少的人** |
| **那片叶子会成为"可囤积道具"** | **禁止**。它不进道具栏、不带计数、不能给任何 NPC 看（除极少数指定时刻）。它只躺在箱笼里 |
| **考据最容易翻车的一处** | **"赠友用矾书"是演绎**。文本中不出现"矾"字，只说"看不见的字"——**知识条目标注即可，不让角色解释原理** |
| **"唯一性线索"容易写成巧合** | 真实风险。守住 §4.6.3：线索是**三件事的组合**，不是单一嗜好；且**乔老叟凭"点法"认人**在赊账生意里是职业本能，不是神机妙算 |
| **乔禾变成"人形提示器"** | 她只做一件事——**认出"竹梆"**（她家的声音）。**不解释、不推理、不给方向**，说完就跑。一旦她开口分析诗句，本线立刻失败 |
| **玩家跳过了序章埋点、没拿到老师那封信** | 对策：§6.4 的认人抓手做**双保险**——① 老师那封信（若曾拾取）；② 若无，则由「书箱观察文字」永久可读替代。**任何情况下都不许改成 NPC 直接说破** |
| **〔v0.5 新增〕A′ 的"差一点"容易被写成"狗血"** | A′ 的核心是**"他回来过，住得不远，没见上"**。**一旦写成"他天天在城门口等顾惟清"或"他其实去看过他一眼"，立刻降格。** 硬约束：**全作只给两个客观事实——① 他回来养过病（书肆一句）；② 他死了（同一句）。中间的一切不许补。** |
| **〔v0.5 新增〕"死人"容易把全作变苦** | 本作基调是**诙谐 + 克制**。**暗线可以沉，但必须有东西托住**：托住它的是**乔老叟那一碗粥**（他记得"不要糖、桂花双份"）——**一个死人留下的味道，活在一个卖粥的老头手上。** 这是我们唯一的"活气"，**不许删** |

## 13. 验收（玩家到「解三层」那一章末，应能自己说出）

1. 序章那片叶子怎么了？——**被一只猫踩碎了（猫是去追偷书的鼠），而那位先生一句话都没说。**
2. 叶子上的字为什么看不见？——**用看不见的墨写的。写的人不想让它一次就被读完。**
3. 你怎么知道上面真有字？——**因为我在留园学会了在叶子上写字。**
4. 那首诗写的是什么？——**一碗糖粥：一碗不加糖的，一碗桂花加双份的。**
5. 你怎么知道那是谁的粥？——**乔禾先听出来的——"竹梆是我家的"。卖粥的老头记得那碗是怎么点的。**
6. 那个写字的人是谁？——**是我老师。他写东西从来不写完——我手上那封信也是这样断的。**
7. 那片叶子是几封信里的第几封？——**第一封。还有八封。**
8. 最后那半句话是什么？——**（由玩家自己填。游戏不给标准答案。）**
