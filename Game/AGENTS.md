# 姑苏九园项目制作约定

适用于 `Game/` 下的剧本、园林场景、美术、地图编辑器与任务设计。

在新增或修改园林故事线、人物任务、建筑布局、花窗、铺地、匾额、植物或可玩场景前，先按 [`gusu-whitebox/RAG_GAME_PRODUCTION_WORKFLOW.md`](gusu-whitebox/RAG_GAME_PRODUCTION_WORKFLOW.md) 判断是否需要本地园林知识检索。涉及具体园林史实、固定构件／遗存、空间关系、图版位置、时期或园艺养护时，应查资料并问反证；**常见且合理的园林小品布置（如在庭院中摆放一盆兰花）不要求先证明其曾在某园某处作为历史陈设**，除非文案主动作出这种具体史实主张。若向量检索服务不可用，可检索 `SuzhouClassicGardenRag/Project/converted/` 源文，但须如实标记为源文检索，不得声称已查询向量库。

推荐在仓库根目录运行 `conda run -n MinerU python Game/tools/query_garden_rag.py '园林＋院落＋构件的问题'`；此入口只检索本地文字向量，不调用外部 DeepSeek。不要因某个向量命中或高分就直接定稿。

RAG 回答、相似度、OCR 图注与生成图都只是候选。进入剧本或正式场景前，人工核原书图版/实景照片、部位与视向、游戏所选清末时段和图片使用权；不同园林的同类冰裂/海棠纹可以同属一个纹样家族，具体窗、铺地、匾额实例不可跨园挪用。记录证据等级与未决问题；未核位置或年代的内容留在编辑器研究卡，不作唯一谜底或“历史复原”。

玩法由人物/物件逐步触发：让玩家走、看、绕、对、回望和试错，避免导游式说明卡。不得为谜题给古迹凭空增加刻字或秘纹；可将虚构线索放在可移走纸片等道具上。保持已定各章主线、六艺幂等奖励与叙事基调。具体九园纹样差异及留园 CH3-06 原型见 [`姑苏九园-纹样线索与实景图案制作标准.md`](姑苏九园-纹样线索与实景图案制作标准.md)。

构图小游戏先让玩家看完整原例，再操作与原例所讨论关系直接对应的道具或路线。书例、原创练习画与实际园林史实三者必须分别标注；不拿无关园景裁切去冒充画论练习，也不以程序阈值宣称唯一审美答案。跨园候选、书目来源、实际操作和证据边界见 [`构图小游戏系列设计`](gusu-whitebox/COMPOSITION_GAME_SERIES_DESIGN.md)。谢子静《宋代折枝花鸟画的构图程式》所给的是文字归纳（用户 PDF 无插图），应据其程式让玩家操作枝势、花簇及留白，不冒称程序画面为论文原图。

**研究镜头不等于游戏关卡。** 一张图即使已能走、已进统一编辑器，也不能因此计入章节完成。正式场景须说明它在剧本里的独有作用：是谁或什么物件使玩家进入、玩家在此作了什么有后果的行动、它怎样改变下一幕；没有人物/物件事件的纯走廊，优先并入相邻幕或删去，不用多切一屏填时长。研究切片可留供相机、比例、碰撞校准，但必须与正式章流和玩家旧草稿隔离。

所有可玩场景遵循同一套 2.5D 像素美术与表达：粉墙黛瓦、灰石、克制植物色与烟雨江南的柔和空气感；雨意不等于每幕都下雨。角色、墙瓦、植物、铺地和前景遮挡必须在相同的逻辑像素密度、镜头和光照语法下并排验收，不能用平滑绘画、白模和粗颗粒像素画轮流充当正式底图。分幕制作与晋级标准见 [`gusu-whitebox/GAME_ART_DIRECTION_STANDARD.md`](gusu-whitebox/GAME_ART_DIRECTION_STANDARD.md)。

铺地是空间与游戏线索，**每幕都要审视铺地的多样性和衔接**，不得将同一块灰石板纹理铺满九园。按实际部位辨别石板、弹石／弹街石、砖街、卵石与花街铺地等工艺；路线、庭院与转角可有不同节奏，但不设强制种类数，不为凑数虚构纹样。花街尤其先从本地向量库召回具体园林图版，再核原图、位置、视向、时期、授权，最后原创像素化。图版只写“留园”而未给院落时，不得把该纹样钉到入口、小庭或作为唯一正确谜底。每个铺地实例必须记录 `gardenId`、`site`、`material`、`motifFamily`、`instanceId`、`sourceMd`、`figureOrPage`、`periodStatus`、`rightsStatus`、`sceneId`、`gameplayRole` 和未核项。具体先例见 [`gusu-whitebox/LIUYUAN_PAVING_RESEARCH.md`](gusu-whitebox/LIUYUAN_PAVING_RESEARCH.md)。

每次交付写明：本次实际查询方式、可追溯来源、用于哪一幕/哪张底图、未核项目与测试结果。不要把源书扫描图、RAG 缩略图或仅供研究的 AI 图复制进公开游戏资源。
