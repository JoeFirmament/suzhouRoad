# 姑苏九园 · 1890 口径总表

> **v1.0（2026-10-20）** · 用途：凡引自当代资料的**树龄／名称／编号／器物／地名／数字／引文**，写进剧本或场景前，先查这张表；表里没有的，先补一条再动笔。
> **判据一句话**：**这个说法，1890 年的人嘴里有没有？**
> 本表是《未完成清单》C-1 的交付物，也是"同类错误不再犯第四次"的执行件。

**本次查询方式**：本表是**项目内既有考据成果的汇总、换算与裁决**，未新调用向量库或外部检索。每一行保留其原报告出处；凡原报告标"存疑／未核"的，本表不得升格为"已核"。

**1890 是什么**：1890（光绪十六年）是**制作口径**，不是玩家界面上的年份。玩家只看到"清末"；内部章节能放进一条自洽的连续时间线（见《时间设定与史实边界》）。

## 0. 四档判定与换算规则

| 档 | 含义 | 处理 |
|---|---|---|
| ✅ **可直接用** | 1890 已存在，且当时就是这么叫／这么算 | 可进台词、画面、道具 |
| 🟡 **改写后可用** | 事实成立，但**措辞、数字或精确度**是当代的 | 改写成年内人能说的说法，或只作制作参数 |
| ❌ **禁用** | 后出构件、后出名称、现代编号／术语／统计 | 不进正文；必要时只进「今按」 |
| **今按** | 1840 年后学人的原句与定名 | **唯一容器**：宋体小字、标出处、玩家动作之后（《剧本文件规范》§2.6） |

**换算规则**

1. **树龄**：`1890 树龄 ≈ 挂牌树龄 −（挂牌参照年 − 1890）`。参照年不详时按 2022 计（减 132），结果一律写"约"。
   例：挂牌 800 年 → 1890 约 668 岁 → 文中写"**约七百岁**"，不写 800。
2. **数字**：现状测绘（长度、扇数、株数、面积）可作**制作参数**，**不进角色台词**，除非有同期记载。
3. **名称**：以 1890 当时的园名、斋名、匾文为准；后世改名只进今按或干脆不提。
4. **器物**：1950 年后修复／新建／移建的一律排除；1949 年前但年代不明的标"存疑"。
5. **引文**：1840 年后学人原句只进今按；转述不加引号、不署名冒充古人。
6. **未核不写死**：原报告写"两说并存"的，台词里不给唯一答案，或改用"一说是……"。

## 12. 维护规则

1. **新增条目必须带来源与参照年**；只有"某网站说"的，标【待核】。
2. 树龄、编号、名称、器物**四类**最容易出事，写前先在本表检索。
3. 剧本/场景交付时，贴一句：**已按本表核对，涉及 N-/T-/B-/D-/O-/P-/Q-/W- 哪些条**。
4. 本表与《时间设定与史实边界》分工：**边界**管"哪些年份能用"，**本表**管"这个说法能不能进 1890"。
5. **机械自检**：`cd Game/gusu-whitebox && npm run verify:1890`。脚本只扫**台词行**（`L/O/S` 行内码后的正文），不扫考据块与今按，因此不会误伤红线说明。
   - 本表交付当天，它当场抓到一处真错：**CH4-06 `O04` 让玩家说"比我们那棵连理杏还粗"**——1890 的树没有名字。已改为"**比我们学里那棵空心的还粗**"（用形态认树，符合 v0.2 设计）。

> 本表自检：所有条目均出自项目内既有考据报告与剧本头部说明；未新增史实断言；凡原报告标"存疑／未核"者，本表保持同等级，未擅自升格。
