## 2. 数据纪律（对照《城市三图考据》C 线）

- **只标 9 个核实站点**：拙政园苏博（6）、石路（2）、养育巷（1）、相门（1）、察院场（4）、三元坊（4）、南园北路（5）、同里（4），其余站点一律不画——宁缺毋假。
- **九园八站**：狮子林与拙政园共用"拙政园苏博"站（考据表注明站西南即狮子林），UI 用一个朱环，不另画。
- **线路走向为拓扑示意（八向线），非测绘**——画面底部信息条已永久注明"拓扑示意非测绘·站点以官网为准"。
- **3/7/8/11 号线只画浅色虚线上下文**（未逐站核实，不标徽章不给站名）；1/2/4/5/6 五条主线用色块徽章标线路号。
- **线路用色为游戏色板分配，非官方标志色**——官方线路色已于 2026-09-28 考据入档（见《城市三图考据》C 线："官方线路标志色"节，1 草绿/2 大红/3 深黄或橙存疑/4 湖蓝/5 品红/6 浅蓝/7 浅紫/8 橄榄绿/11 香槟）。默认维持色板分配色（限色纪律）；若裁决现代层 UI 脱板用官方色，需用户拍板，届时 3 号线色以车站实勘为准。

## 3. 相对地理依据

站间相对方位全部来自考据表"步行大概方位"列 + 干将路（1 号线东西轴）/人民路（4 号线南北轴）的城市轴事实。石路站在城墙外西北（阊门外）、同里在 4 号线南端，与《蘇城全圖》底本的城池方位互证。

- 本图 = 现代层"出行规划"界面：玩家点园名 → 高亮对应朱环站 → 乘车转场动画。
