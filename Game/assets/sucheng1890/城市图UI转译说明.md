## 3. 美术原则（用户定调：粉墙黛瓦、人家尽枕河）

1. **河道为骨**：三横四直画成河道（青双线），不画成街巷——苏州是水城，水陆双棋盘。
2. **枕河人家**：小屋沿河**连排成组**（3-6 连排、组间留巷），黛瓦(inkHeavy 3×2)+墙基线(ink 3×1)，粉墙即纸底留白。
3. **桥**：河×街交叉必置桥（inkHeavy 桥面+纸色石阶缝），呼应"红栏三百九十桥"。
4. **田圃留白**：城内大块留白+稀疏叶色点=清末城内真实存在的田圃荒地（底本"仁邑一圖""荒基地"注记）——留白即考据。
5. **零文字入图**：图内不画一个字，地名全部进 UI 层。

## 5. v0.3 九园点位（2026-09-27 上稿）

### 5.1 方法论（重要）

底本为手绘石印示意图，**局部歪斜严重、无全局线性坐标**（实测：阊门画于西墙中部、page1 纵向压缩不均、同版两印各自变形）。故点位采用「地标相对位+史地方位」理性化落点，与 v0.2 门位处理方式一致：

- 骨架环内坐标换算：`nx = 0.075 + 0.85·X`（X=城内自西墙 0→1），`ny = 0.205 + 0.695·Y`（Y=自北墙 0→1）
- 实锤标注的园以底本可读标注为证，落点按其与门/塔/巷的相对位换算，不照抄歪斜的原始图面坐标
- 证据分级：**A=底本标注实锤 / B=底本巷名锚定 / C=地理补标（底本未检出）/ D=图外**
