# 留园冠云峰前院 · 研究图 v1

- 生成方式：内置 ImageGen 文本生成（非照片编辑），原始输出 1536 × 1024，已复制为同名 PNG。
- 参考依据：[苏州市园林局《留园》](https://ylj.suzhou.gov.cn/szsylj/sjyc/201905/b7c0f2058c75498c9ecbacf234e25b08.shtml)及其冠云峰照片：瘦长多孔峰体、峰前浣云沼、后方瓦顶赏石建筑。
- 提示词要点：晚清苏州园林 2.5D RPG 像素游戏地面；一处较小的前景水沼，瘦长多孔的太湖石独立立于沼后，黑瓦木构在远侧，前方与两侧留可行走石路；低饱和灰绿、石灰与木褐，不画现代人、导览牌或桥。
- 未获照片像素作为模型输入；这是按文字及人工观察生成的视觉候选，不是实景临摹或 1890 年复原。
- 待校对：峰体孔洞与照片剪影不完全吻合；水岸曲线、左右通道、后方厅堂立面和植栽位置均无测绘依据。不得以图像推断真实门洞。编辑器几何只是玩法草案。
- 后续核查确认本稿缺少南侧林泉耆硕之馆的围合，北端冠云楼也被画成单层厅堂；已由 v2 研究图取代，仅留历史草稿和误差对照。
