# 姑苏九园 · 纹样线索与实景图案制作标准

> 2026-10-04 制作提案。适用于九园的花窗、铺地、匾额/题刻及其组合；**不改写各章已有主线结局、六艺奖励与已定年代边界**。本地 RAG/向量库用于发现资料，不能替代原图、实景位置与年代核验。

## 1. 两层身份：家族可以相同，实例不能串园

冰裂纹、海棠纹、回纹等是跨园共享的纹样**家族**。游戏资产必须再绑定一个**实例**：`园林 + 建筑/院落 + 立面或铺地分区 + 视向 + 图版/实景来源 + 年代状态 + 图像权利 + 游戏用途`。同是海棠纹，可以同类辨认，绝不可把拙政园海棠春坞的铺地贴到艺圃某段路上，或把耦园鹤寿亭的双窗移到留园。匾额尤须核原字、同一时期的悬挂位置和读字方向；“名字在后世存在”不等于清末场景可出现。

资料层级：① RAG 召回标题/图注只是线索；② 人工看原图、上下文与图版号；③ 平面或方位实景复核具体部位；④ 核故事时段；⑤ 审授权；⑥ 制作原创像素资产并按脚点、遮挡、碰撞实测。缺 ③/④ 时可写探索提案，不可做解谜的唯一正确答案；缺 ⑤ 时不可将原图/扫描件发进游戏。

## 2. 谜题不是数纹样，而是读“纹样—位置—人”

一条合格线索至少有三层：人物为何需要辨认（借书、送物、寻路、对句）→ 玩家在可走空间亲看两个以上候选 → 纹样的具体差异与视角、铺地或匾额共同排除错误。错误选择应给新的空间信息，允许回走；不得用“答错海棠纹名称”惩罚玩家。进阶难度由**同族不同实例**、遮挡与视向、跨媒介比对、历史层反证产生，不靠把图案画得更小。

可复用的是交互动词 `看、绕、踏、对、拓、辨字、再看`；不可复用的是窗数、笔画、铺地坐标、匾额原字和谜底。刻字、贴纸等剧情痕迹只可放在可移走的虚构道具上，不在真实古迹上凭空增加“秘刻”。线索永远有光照/字幕/放大层的无障碍替代，不能只有色差或像素级暗纹。

跨园回响可让玩家注意“同是冰裂/海棠，纹路的疏密、材质和安放之处不同”，园谱记录具体实例而不授予“某纹属于某园”的排他知识。

## 4. 首个可实施原型：CH3-06「窗里还有一窗」

此段作为 CH3-06 的可选加深，**未接现有试玩和主线 flag**。乔禾只说“那边看见蕉叶的窗，不一定就能走到蕉叶”；她要把粥桶送回，不会停下来讲园林知识。玩家在鹤所/石林候选切片先看见第一重方门、第二重带芯花窗、后方蕉叶，试走直线会被真实墙体挡住；绕晚翠峰走到另一侧，再回看发现同一片叶被另一重框住。若拿到寒士写在可移走纸片上的半幅纹样，只有从正确机位看，纸片空白与窗格负形才相合，提示的是“回身向廊”，不是书斋门坐标。错机位可回走，窗不能穿、石不能穿；字幕写“近处这扇不是门”，不弹“你找到了鹤所”的知识卡。

库中另有更精确的第二层：石林小院“洞天一碧”小屋中央八角窗、东西两侧六角窗；东见竹、西见蕉（《图说·门窗》图 5-47/5-56）。玩家若只认“六角”会遇到**两个都对的候选**，须再观察窗后的植物并从中央八角窗校方位；同类形状不等于同一实例。两张图版已看原图，现场位置及清末存貌仍待核，故这一步也只记为候选，不覆盖现有剧本路线。

已做一张[三窗辨影独立研究页](gusu-whitebox/liuyuan-window-study.html)：在窗前铺地四向行走、分别观察、在可移走的纸角记窗，含误选反馈及触屏按钮；不使用原书扫描图，不写 CH3 存档。研究底图与可走地面、三个窗前脚点现已进[几何编辑器](gusu-whitebox/geometry-editor.html?scene=liuyuan-dongtian-three-windows-study-v1)，试玩页可读同场景草稿。画面、窗距和通路仍为游戏化拼合，未有实测；浏览器画面与触屏实走尚未验收，不能当正式关卡。

候选台词：乔禾：“我从这头看得见那片叶，提着桶却走不到。”／沈砚秋：“原来窗里还隔着窗。” 第二句只在玩家自己绕路并回看后出现。正确书斋仍由纸页声和院落收束辨出，不由花窗一步直达。若查明故事时段这道窗不存在，就把玩法撤成原有绕峰/听纸声，不为了谜题虚构古建。

铺地进阶仅在某片路面的位置得到证实后追加：同族冰裂纹中，对照一张纸上残缺的接缝轮廓找出**特定铺地实例**；线索藏于纸的负形/接缝，纸是虚构且可移走的道具，原铺地不新增暗号。现有研究图将细卵石误画成大石板，不能作答案图或碰撞依据。

## 5. 图案生产与验收

每个正式实例建一张卡：`motifFamily`、`instanceId`、`gardenId`、`site`、`viewDirection`、`period`、`sourceFigure`、`photoRights`、`sprite`、`tile/occlusionOwner`、`puzzleRole`、`scriptRef`、`verifiedBy`。审核顺序为：原书图版与实景 → 人工像素转译 → 以人物身高测纹样可读度 → Tile/碰撞/遮挡由实物落脚线重标 → 含错误路线的键盘与触屏试走 → 剧本台词不泄谜底。RAG 图与生成图均只能进入私有制作端，版权未清不得打包发布。

当前第一张[留园石林纹样像素研究图](research-art/liuyuan-stone-forest-pattern-research-v2-pixel.png)仅演示门、窗、蕉、石和脚下铺地共同构成线索的画面层次；它没有解决实景坐标，不能替换现有石林场景。其生成方式、来源和失败点见同名 `.prompt.md`。研究图单独存于 `research-art/`，不参与正式资源清单。
