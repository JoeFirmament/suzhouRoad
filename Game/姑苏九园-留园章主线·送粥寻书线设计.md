## 1. 一句话

**乔老叟的糖粥担进不了留园那条窄夹弄，玩家替他提桶进去——出来的路上，桶里多了一片写了字的芭蕉叶。**

三条线不是三个任务，是**一条链**：

```text
线①送粥   乔老叟腿脚不便 → 乔禾送不动 → 玩家替送 → 得准入
线③寻人   粥要送到花房 → 花匠给线索 → 玉兰是"笔树" → 猜出书斋 → 找到寒士
线②传信   寒士有话要带出去 → 园里没纸、出入受查 → 蕉叶代纸 → 空桶带出
```

**闭环点**：糖粥担既是「进园的凭证」，也是「出园的信道」——同一个物件，承载准入与传信两件事。

## 2. 为什么是留园（选园论证）

| 需求（来自三条线） | 留园满足情况 | 证据等级 |
|---|---|---|
| 有**可考的书斋**（线③要找的屋子） | 东部的读书建筑群：**还读我书斋**、**汲古得修绠**、**五峰仙馆**、**揖峰轩**（刘恕书房） | **有据**（繁复但真实） |
| 有**芭蕉**（线②的纸） | 官方描述东部「竹石倚墙，**芭蕉映窗**」；揖峰轩北墙花窗对景天井内芭蕉 | **有据**（描述性） |
| 有**玉兰**（线③的线索） | 园内植玉兰；玉兰在明清园林的定式位置是「宜种厅事前，对列数株」（文震亨《长物志》） | **有据（通则）／园内株位待核** |
| 1890 年**进得去**（线①的前提） | 旧稿转引潘钟瑞《香禅日记》光绪十二年（1886）重阳「开行至留园……啜茗于还读书斋……乃出园。返舟」，但尚未核到日记原页或可靠校勘本；且半园亦有“还读书斋”一名，须排除同名混淆。情节可暂作游戏演绎，不以这条转引独自证明留园当年开放与茶饮服务 | **待核原文，不列 A** |
| 门外**容得下糖粥担**（线①的场景） | 园址在**阊门外下塘花步里**；「**留园之后即为花埠**」，故留园别称「花埠小筑／华步小筑」。门口即花市集散区，挑担小贩到门外完全合理 | **有据（地理）** |
| 园内**有事在发生**（线①的收纳方） | **光绪十四—十七年（1888—1891）**建义庄、增辟东园西园（冠云峰、林泉耆硕之馆、**南花房／北花房**、十景花坞）——**1890 年的留园是一个大工地**，有工匠、有花匠、有管事 | **有据** |
| 担子**进不去**（线①的矛盾） | 留园大门「小得不像一处名园该有的样子……进去更是一条**又窄又长的夹弄**，光线昏暗，转弯多得像迷宫」（造园上的欲扬先抑） | **有据（描述性）** |

**结论**：留园是唯一同时满足「有书斋 + 有芭蕉 + 有玉兰 + 进得去 + 门口容得下担子 + 园内正在施工」的园。选它，三条线全部落在真实锚点上，不靠虚构补位。

**与既有功课的关系**：《任务设计系统定案》§12 已给留园定了园性「空间收放」与课业**《暗处借光》**（穿过窄廊庭院，用明暗与声音判断空间节奏，乐/数）。本主线**不覆盖它**——两者并行：

| 线 | 类型 | 功能 |
|---|---|---|
| **《一支粥的路线》** | 课业（章节骨架，强制） | 解决「怎么进园、进来找谁、怎么把话带出去」 |
| 《暗处借光》 | 课业（园性） | 解决「留园为什么先收后放」 |
| 送粥线的隐线 | 请托（非强制） | 糖粥担的固定路线可延伸出城市侧的小请托 |

## 3. 线① 送粥入园 —— 「凭什么让你进」

### 3.1 真实锚点

- 卖糖粥者**敲竹梆**「笃笃笃」，**有固定的叫卖路线**，各自有一批**相熟的老主顾**（民俗记载，有据）。
- 留园门外即**花市／花埠**，小贩到门外有据；**但小贩入园送物无直接史料**——本作按「提桶进、担子留守门外」处理，**规避史料缺口**。

### 3.2 人物动机（不是「为了教玩家」）

- **乔老叟**：常年挑担，腿脚有旧伤；今天要走留园这一趟，担子进不了那条夹弄，他进去一趟得歇两回。
- **乔禾**：八岁，提得动一小桶，但提不动一路；且她认得路，却压不住场（门房不认她）。
- **玩家**：府学学子，有身份、有力气、脸生但站得住——**正好补上爷孙俩的缺口**。

> **关键**：玩家不是"被派去跑腿"，是**这条街今天人手不够**。任务的第一动机是生活，不是课业。

### 3.3 六节拍

| 节拍 | 内容 |
|---|---|
| **1 遇见** | 府学后门／巷口，乔老叟靠在墙上揉腿，竹梆挂在担头没敲。乔禾蹲着数桶里的碗。 |
| **2 生疑** | 粥是给留园的，可留园在阊门外——**一个卖糖粥的怎么会有园里的主顾？** |
| **3 循迹** | 跟着乔禾走。她报数报得比路牌准；一路上交代「担子停在花埠，人从边上小门进」。 |
| **4 行动** | 提桶走到园门。**门房拦人**：私园，闲人免进。报上来意，验过桶，被指往**侧面夹弄**。 |
| **5 领悟** | 穿窄夹弄进园——玩家第一次体会留园的「欲扬先抑」：**园子不是从大门开始的，是从夹弄开始的**。 |
| **6 回响** | 粥送到花房 → 园谱/地图上**留园点亮**（世界新连接）；糖粥担成为可再利用的「进园凭证」。 |

### 3.4 门房的拦与放（准入机制）

| 状态 | 玩家看到的 |
|---|---|
| `locked` | 门房不看你，只说：「送货的走那边。」（不给理由、不骂人、不拦死——**留一条边门**） |
| `clue` | 乔老叟提过一句「你去说是花房订的」。玩家带着这句话再去。 |
| `active` | 门房验桶：「花房的？……进去别乱走。」**放行**。 |
| `complete` | 门房认得人了：往后玩家自己来，点个头就进。 |

**设计要点**：准入靠**一个社会关系**（老主顾），不靠钥匙、不靠打怪、不靠付钱。这直接兑现《任务设计系统定案》§1「因为一个人……必须亲自走进去看一眼」。

### 3.5 禁区

- 不做「门口挂着价目牌／收门票」——**那是宣统以后的事，1890 年不成立**。
- 不让门房说教（不解释留园历史、不科普私家园林制度）。
- 不出现「任务标记在门房头上」。

## 4. 线③ 玉兰寻书斋 —— 「哪一间是书房」

### 4.1 真实锚点（这是本线最硬的部分）

**玉兰的别名是「木笔」，因为花苞像毛笔尖——原文有据，三条独立出处**：

> 唐·陈藏器《本草拾遗》：辛夷「初发如笔头，**北人呼为木笔**。」
> 宋·寇宗奭《本草衍义》：辛夷「其花未开时，苞上有毛，**尖长如笔，故取象而名**。」
> 明·李时珍《本草纲目·辛夷》：「苞长半寸，而**尖锐俨如笔头**……亦有白色者，**人呼为玉兰**。」

**第二条锚点——玉兰长在哪里是有规矩的**：

> 明文震亨《长物志》：「玉兰，**宜种厅事前**。对列数株，花时如玉圃琼林，最称绝胜。」

→ **玉兰对植的院子，是要紧的屋子。**这条比"像笔"更强：它把植物位置变成了空间线索。

**考据红线（必须遵守）**：

| 项 | 红线 |
|---|---|
| 「木笔」原义 | 指**紫花辛夷**；白玉兰明代才固定叫「玉兰」。晚清人混称可接受，但台词里须当**俗间泛称**用，不能当植物学定论。 |
| 「笔树」 | 属**角色的大胆说法**，不是古籍名词。文本中可以由人物说出口，**但不能当作典故引用**。 |
| 更好的雅号 | 玉兰在晚明的通行雅号是**「玉树」**（李渔「世无玉树，请以此花当之」；上接《世说新语》「芝兰玉树」）。若需要题额级典故，用「玉树」比「木笔」更稳。 |
| 匾额文字 | 见 §7 红线表——**「还我读书处」是解放后的称谓，1890 年必须写「还读我书斋」**。 |

### 4.2 推理链（保留大 Q 的"大胆猜想"，但给它两条腿）

单靠「花像笔 → 这是书房」推理太弱。设计成**两条线索 + 允许猜错**：

```text
线索 A（植物）  花房花匠指着玉兰说：那花苞像笔头，我们这儿管它叫笔树
                 → 有笔树的地方，是写字的地方？
线索 B（题额）  某个院门上有匾，字看不懂（篆书/用典），但看得出是"读书"的意思
                 → 两条合起来，才敢推门
```

**允许猜错（重要）**：留园东部有四处读书类建筑，玩家第一眼分不清——

| 候选 | 匾额 | 出典 | 猜错的反馈 |
|---|---|---|---|
| **还读我书斋** ★正解 | 陶渊明《读山海经》「既耕亦已种，**时还读我书**」 | 有据 | — |
| 汲古得修绠 | 韩愈《秋怀》「归愚识夷涂，**汲古得修绠**」 | 有据 | 推门见书架，人在外头晒书：「看书的在隔壁。」 |
| 五峰仙馆 | 李白五老峰／得文徵明停云馆藏石（**两说并存**） | 存疑 | 推门是大厅，空旷无人，脚步声很响 |
| 揖峰轩 | 朱熹「前揖庐山，一峰独秀」／米芾拜石（**两说**） | 存疑 | 有石有窗，是看石的地方，不是读书的地方 |

**错误也要给信息**（《任务设计系统定案》§9.1）：每推错一扇门，返回一条空间信息（这间是待客的／晒书的／看石的），逐步收窄。

### 4.3 六节拍

| 节拍 | 内容 |
|---|---|
| **1 遇见** | 花房里，花匠正给盆兰换土。他脚边就是一株玉兰。 |
| **2 生疑** | 玩家问"园里有没有一位天天来看书的人"，花匠只说"书斋里那位"，**不说在哪一间**。 |
| **3 循迹** | 花匠随口一句：「那花苞像笔头，我们都叫它**笔树**。」——线索引向"写字的地方"。 |
| **4 行动** | 在东部庭院间走，比对**玉兰位置**（厅事前）与**匾额字义**，逐间排除。 |
| **5 领悟** | 推对那扇门：**匾上是陶渊明的一句诗**，屋里有人在抄书。 |
| **6 回响** | 人物关系建立；同时玩家学会一种「以命名读空间」的看法（可挂靠书/礼的成长）。 |

### 4.4 禁区

- 不要做成"找到三个线索拼图"的清单任务；
- 不要让人物直接说出"玉兰=木笔"这条知识——**让玩家自己从花苞形状看出来**，人物只提供"我们管它叫笔树"这句土话；
- 四个候选院落的匾额必须是**真匾额**，不得为谜题生造。

## 5. 线② 蕉叶传信 —— 「为什么要写在会枯的东西上」

### 5.1 真实锚点

**怀素以蕉叶代纸——最早出处明确，可直接引用**：

> 唐·陆羽《僧怀素传》：「**贫无纸可书，尝于故里种芭蕉万余株，以供挥洒。书不足，乃漆一盘书之，又漆一方板，书之再三，盘、板皆穿。**」

**考据红线（三处必须守）**：

| 项 | 红线 |
|---|---|
| 「绿天庵」 | 宋·陶谷《清异录》原文是「号其所曰**绿天**，庵曰**种纸**」——**是两个名字**；「绿天庵」是后世合成叫法。**匾额若要写，写「种纸」最有味**。 |
| 《宣和书谱》 | 该书怀素条**只有「秃笔成冢」，没有芭蕉记载**。**禁止**引用《宣和书谱》说芭蕉。 |
| 「漆盘漆板」 | 与种蕉取叶**同出陆羽一传、原文并列**，可放心用。 |

### 5.2 谜题核心

**一个反常问题**：园里不缺纸，为什么要用芭蕉叶写字？

答案必须来自**处境**，不能来自"好玩"：

- 园里的事，都在管事眼皮底下；**一张纸带出去要过手**。
- 但**一桶粥不会有人翻**——糖粥担是唯一被允许天天进出的东西。
- 蕉叶写成字，**叶子枯了字就没了**——这不是缺陷，这是设计。

### 5.3 玩法三步

| 步 | 动作 | 玩家学到 |
|---|---|---|
| 1 | 在院中取一片芭蕉叶（要挑新叶，老叶写不上） | 叶子不是道具，是**当天的纸** |
| 2 | 用**漆过的木板**托着写（陆羽的漆板，园里正好有块废漆板）——**直接写叶子会渗、会破** | 工具决定信息能活多久 |
| 3 | 写好的叶子**插进空粥桶夹层**，随担子出园 | 信息的通道，是人每天走的那条路 |

**时效机制（本线的"惊喜"）**：蕉叶上的字**当天有效**，隔日枯黄不可辨。→ 玩家若贪心、去绕远路，回来字没了。**这不是惩罚，是让"及时"变成一次真实的判断。**

### 5.4 信息内容（待拍板，见 §9）

三个候选，均可与既有钩子咬合：

| 案 | 内容 | 咬合 |
|---|---|---|
| **A** | 寒士在园中抄到一段**旧园记**，其中有句子与府学所藏本不同——一个**异文** | 接阿槿的版本功夫（序章 D-17「第三回照着前两回的错抄」） |
| **B** | 园内一批旧书／碑拓**即将流散**，寒士想让人知道，但不愿声张 | 接后续「旧影」任务 |
| **C** | 一句话口信，托玩家找城南一个手艺人的下落 | 直接复用序章 D-18 阿槿的「乐桥帘匠」钩子 |

> **本稿倾向 A**：它把"写字"这件事本身变成内容——**写在蕉叶上的字，和抄在纸上的字，哪一个更算数？** 这正是全书"知识"主题的一个具体提问。

### 5.5 禁区

- 不做「蕉叶写字小游戏」的连击/评分；
- 不让蕉叶成为可囤积的道具；
- 不给"信息内容"配解密答案——**玩家带回去的是原句，不是结论**。

## 6. 三线咬合图

```text
        乔老叟腿伤 · 担子进不了夹弄
                  │
          【线①】玩家提桶进园
                  │  门房：送货的走那边
                  ▼
        花房（留园正在扩建，1888—1891）
                  │  花匠：「那花苞像笔头，我们叫它笔树」
                  ▼
          【线③】玉兰位置 × 匾额字义 → 逐间排除
                  │
            推对那扇门：还读我书斋
                  │  屋里有人在抄书
                  ▼
          【线②】寒士有话带不出去 → 蕉叶代纸
                  │  漆板托着写；插进空粥桶
                  ▼
              担子出园 → 花埠 → 府学
                  │
      【回响】留园点亮 · 糖粥担成为常设通道 · 府学案上多一片枯叶
```

**物件的一生**：一只粥桶 → 进城、进园、装粥、装消息、出园。**同一个道具承担准入与传信两件事**，这是本线最经济的一处设计。

## 7. 台词样本（已过五声声纹）

> 声纹依据：《连续序章与府学初到流程定案》**v1.4** §6（**六人六声**：顾惟清引经据典 / 沈砚秋诙谐 / 阿槿掺曲 / 玩家莽稳两档 / 乔禾报数 / **乔瓷说路程与代价**）

**乔老叟**（吆喝腔，三字一顿，只闻其声）：
> 「阿禾——桶，提稳。」

**乔禾**（报数，4–12 字）：
> 「进小门，十七步，转弯。」
> 「我不敢进。那个人问我几岁。」（八岁儿童有人管、有怕心——**不是无所不能的小大人**）

**花匠**（行内人，只认活不认话）：
> 「别踩那条线。刚培的土。」

**寒士**（说话有旧意但不仿古，句长偏长但不掉书袋）：
> 「园里的纸，出了这道门就算数。园里的话，出了这道门就不算数——所以得写在不算数的地方。」

**玩家（莽档）**：
> 「我把叶子塞怀里带走。」→ 花匠：「那你等着看它烂。」

**玩家（稳档）**：
> 「挑新叶。写完了就走，不绕路。」

### 8.5 与悬疑暗线《一片蕉叶二十年》的接口 ★★

本条线是暗线**第一次「破译」的入口**（**口径已统一**：第一次「发展」在去退思园的水路上，见《悬疑暗线》§8.1）——玩家在留园学到的"蕉叶可以写字"，是回头读懂序章那片叶子的**唯一钥匙**。**逐场实现见《剧本-CH3留园》CH3-11 ~ CH3-13（章末暗线承接段）。**

| 层级 | 落点 | 说明 |
|---|---|---|
| **机制层** | 线②蕉叶传信 | 玩家第一次知道"叶上原来可以写字"。**没走完留园章的人，永远读不懂序章那片叶子**——"线性必要条件"最经济的用法：不是卡关，是卡理解 |
| **解谜层②** | 出园后，乔禾认出"竹梆" | 叶上诗显形后，**乔禾先听出来："那是我家的。"** 说完就跑——**全链唯一由小孩提供的信息** |
| **解谜层③** | 追到糖粥担，乔老叟认领点法 | **"一碗不要糖，一碗桂花加双份。二十年了，没人这么点过。"** 暗线在此第一次有了"人"的轮廓 |
| **解谜层④** | 收尾：玩家自己对上 | 叶上诗断在"明年"，**手上老师那封信也断在最后**——玩家自己认出：**那是我老师**。**无提示、无旁白、无 NPC 说破** |
| **台词钩** | 寒士那句「写在不算数的地方」 | 它正是那片叶子的注脚——**写字的人也知道，这话不该留在纸上** |

**红线**：
- 留园章园内**不得**出现顾惟清的名字、不得出现那片叶子、**不得出现"老师"二字**；
- 暗线的**破译全部发生在出园之后**（乔禾跑回家 → 追到糖粥担）；园内只允许一次侧面擦过（即寒士那句），其余留白——**玩家应该自己把两件事连起来，而不是被提示**；
- **乔老叟不给名字、不给结论**，只说"点法"与"赊账"（见暗线文档 §7.3）；
- 玩家**必须自己完成最后一步**（对照"不写完"的习惯）。任何 NPC 说出"那是你老师"的写法——**本线即废**。

**新增状态键（本轮）**：`ly-poem-read`（叶上诗显形）→ `ly-qiaohe-heard`（乔禾认出竹梆）→ `ly-porridge-clue`（乔老叟认领点法）→ `ly-teacher-recognized`（玩家自己对上）。

## 10. 风险与红线汇总

| 风险 | 处理 |
|---|---|
| 「骆驼担」名称与形制多见于民国记述，1890 是否已用**存疑** | 文本中**只说「粥担」**，或让担子本身出现而不命名；**不写"骆驼担"三字** |
| 「还我读书处」是解放后称谓 | 1890 一律写 **「还读我书斋」**；若要提旧称，用刘恕时的 **「还读馆」** |
| 五峰仙馆命名**两说并存** | 台词中**不给唯一出处**；若必须提，说"一说是……" |
| 小贩入园送物**无直接史料** | 处理为"担子停在门外花埠，人提桶走侧门夹弄"——**规避**而非编造 |
| 「木笔」植物学歧义 | 作**俗间泛称**用，不作定论；题额级典故优先用 **「玉树」** |
| 《宣和书谱》芭蕉记载系讹传 | **禁止引用**；怀素典只用陆羽《僧怀素传》 |
| 玉兰是否为留园 1890 实植**待核** | 生产前补一条园志/植物志来源卡；未核前场景可植，但**不做"百年古玉兰"之类台词** |
