# 沧浪亭 Tile 词表（P1 设计稿 · 只定名词，不落 tile）

> v1.1（2026-09-28）· 承《像素化管线指南》§2.1/§2.3、《生产排程》P1、《沧浪亭考据三表》
> 纪律：本文件只写名词、参照、证据、机制关联——**不画定稿**（落 tile 是 P2，闸门=纸面测试数据）。
> 每个构件必须能在**刘敦桢实测图或实景照片**中指认；指认不到 → [待考据核]，不入图。

> 规格：16px tile；人物 16×24；五层 = 地/墙/中景/顶/物件（白模 render 已是此结构）。
