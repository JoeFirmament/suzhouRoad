# 六艺：按玩家实际操作对应奖励

2026-10-12，用户确认。用于九园的小游戏、可选探索事件与剧情高潮设计。本文是当前奖励口径；旧文“六艺不是数值加成”不再否定六艺属性增长。具体数值与各关发放条件需逐项实现，不代表下表六类玩法均已上线。

> 奖励按实际操作对应：护画走位偏“御”，题叶临写偏“书”，瞄准投掷偏“射”，节奏操作偏“乐”，推演机关偏“数”，处理人物关系偏“礼”。

| 六艺 | 对应操作 | 设计关注点 | 现有属性键 |
| --- | --- | --- | --- |
| 御 | 护画走位、控制移动与时机 | 玩家实际控制和应变，不因普通走路就发奖 | `yu` |
| 书 | 题叶、临写、辨字 | 观察与书写行为，不因读完说明就发奖 | `shu` |
| 射 | 瞄准、投掷、对准目标 | 判断位置和时机 | `she` |
| 乐 | 节奏、听辨、应和 | 实际听辨或节奏操作 | `yue` |
| 数 | 推演、机关、组合关系 | 理解规则并验证推断 | `shuMath` |
| 礼 | 处理人物关系、理解处境与分寸 | 有后果的选择与行动，不是选最客气的台词 | `li` |

“偏”是设计判断，不能只凭小游戏题材贴标签；按玩家实际完成的核心操作决定主要奖励，不强迫一关凑齐六艺。

## 收获与探索

- 参与可选小游戏可获得六艺属性成长，也可发现画册页、人物往事、道具或线索。收藏和人物信息应继续带动探索。
- NPC 服务故事线，有自己的需要和处境，不排队发小游戏或充当通行检查。
- 主线避免新增拦路问答；看窗、看池等探索行为不作机械开门打卡。可选小游戏允许绕过，不因失败堵住主线。
- “Boss 战斗”可承担剧情高潮，但必须由人物矛盾与前面的探索铺垫；不把固定六轮练习自动视为 Boss 战。
- 首次满足结算条件发放成长，同一奖励用稳定任务 ID 去重；重复挑战不无限刷属性。显示具体获得哪一艺和数值。
- 正式游戏、隔离试玩和不写存档的独立练习分清。展示规则不等于实际发奖；没有完成/达标，不因打开游戏就发奖。

## 与留园当前实现的关系

护画与题叶分别对应御、书；其余例子是后续设计方向。此前门房六折护画与故事联系薄弱，需要继续重整，奖励接入不能替代剧情和趣味验收。花房猫拨画稿的完整事件尚未定案，不在此认定为已实现。

此文记录用户确认的游戏规则，不是历史六艺活动的考据结论。具体园林、构件与历史活动仍按本地 RAG 制作流程核证。地面、可走区域、碰撞和遮挡按用户分工留待最终编辑。
