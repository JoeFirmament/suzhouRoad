# 姑苏九园 · 像素化管线指南（平江图 + 九园）

> 版本 v1.0（2026-09-26）· 承接《平台与技术栈定案》《参考文献与使用指南》
> 核心纪律：Pillar 5「像素是转译，不是滤镜」；每条事实先考据再进图。

## 0. 一句话总纲

**平江图和九园是两种活，不要用同一套方法处理：**

- 平江图 = **数据活为主 + 一张道具画**。它的价值是"古城地图的骨架来源"，画只是外壳。
- 九园 = **逐园构件词表 + 批量生产**。它的价值是"一园一性格的视觉落实"，画就是谜题本身的一半。

更底层的纪律：**结构数据、像素画、地名文字三层永远分离**——
水系街巷坐标存数据（Tiled / JSON），构件画成 tile，所有文字用真字体渲染叠加。
文字永远不画进像素（伪汉字是 AI 生图的最大事故源，真人手绘同样容易翻车）。

## 1. 平江图线：一份扫描，两条出路

### 1.1 先拿底稿（考据前置）

- 目标物：宋《平江图》碑，南宋绍定二年（1229）刻，现存苏州文庙（苏州碑刻博物馆）。年代与馆藏位置以《清末苏州与平江图考据.md》核对结果为准。
- **公版资源**：碑图为宋代文物、照片属事实性复制，维基共享资源（Wikimedia Commons）有高清扫描可合法使用——考据 agent 的第一项任务就是找到可下载的最高分辨率版本。
- 备用：碑刻博物馆官网图、出版影印本扫描（注明版本）。

### 1.2 用途 A：世界结构底图（数据活，不产生"像素画"）

> **修订（2026-09-26，见《姑苏九园-城市地图底本裁决》）**：可玩清末层的底本改用**清代城图**（同治府志城图/光绪舆图等，考据 agent 检索中）；平江图矢量化降为**辅助校验层**（水陆骨架对照），其道具画用途（§1.3）不变。~~现代层地图 UI = 自绘地铁线网图~~（**2026-09-30：随"现代玩家"线一并删除，不存在现代层**）。

1. **矢量化**：从高清图提取三层骨架——水系（优先级最高，"三横四直"待考据核对）、街巷（次之）、桥梁城门坊门（点状标注）。
2. **进 Tiled**：矢量骨架作为参考底图层垫在地图最底下，游戏街道/河道 tile 沿骨架铺设。
3. **验收标准**：游戏内任意一条河的走向，能和碑图对上；坊巷名逐条对照考据文档中有据条目，对不上的删名不造名。
4. **分工**：这步是纯数字化工作，可以外包给考据 agent（产出 SVG/JSON 骨架），设计侧只做验收。

### 1.3 用途 B：拓片道具画（画活，全游戏唯一一件"文物复刻"）

书坊卖的《平江图》拓片 = 全图道具 + 标题画面素材。规格与规则：

| 项 | 规格 |
|----|------|
| 尺寸 | 240×240 px（游戏内道具展示），可放大做标题背景 |
| 色板 | **仅 3 色**：宣纸底 / 墨黑线 / 朱印（全图唯一红色，延续点睛纪律） |
| 风格 | 线稿拓片风：阴刻线转白线（或墨线），**不做透视、不做光影** |

**转译符号语法（保留碑图自己的语言，不发明新符号）：**

- 河道 = 双细线（碑图水系画法）
- 城墙 = 雉堞重复单元（一个 8px 单元循环）
- 桥 = 短横杠跨河
- 坊门/城门 = 门形符号
- 山/塔 = 皴点与层叠三角

**红线**：碑图上的榜书地名（"乐桥""吴县"等）**不画进像素**——像素上只留符号，地名用真字体另行叠加；拓片道具上可以留白斑驳（拓片质感），但斑驳用噪点镂空，不用假字填充。

## 2. 九园线：构件词表法（防"九次重画"）

### 2.1 先写词表，后动笔

每园动笔前必须先填一张词表，**3-5 个必画真实构件 + 1 个机制构件**。机制构件直接对应 Pillar 4「一园一性格」的谜题核心——画它不是装饰，是判定 UI 的一部分。

| 园 | 机制主题 | 必画构件（示例，[待考据核] 项禁入图） |
|----|---------|--------------------------------------|
| 沧浪亭 | 水界·复廊 | 复廊双廊、漏窗群、面水轩 [端位待裁决]、观鱼处屏门《沧浪亭记》刻石 |
| 拙政园 | 借景 | 梧竹幽居四圆洞门、北寺塔借景机位（跨园联动锚点）、听雨轩 |
| 网师园 | 小中见大 | 月到风来亭、彩霞池尺度对比组（近亭远山） |
| 狮子林 | 假山迷宫 | 湖石假山洞道（光绪中叶废园状态单列） |
| 留园 | 空间收放 | 鹤所漏窗排（五幅画）、入口窄廊-明瑟楼收放序列 |
| 耦园 | 成双 | 东西花园对称布局、载酒堂 [名称待核] |
| 艺圃 | 质朴 | 延光阁水榭 [待核]、极简墙面（最少构件园，留白最多） |
| 环秀山庄 | 叠山 | 湖石大假山立体拼合（谜题即山体本身） |
| 退思园 | 贴水 | 贴水建筑群、倒影机位（1885-87 新建成期状态单列） |

词表来源纪律：每个构件必须能在**刘敦桢实测图或实景照片**中指认；指认不到的进 [待考据核]，不入图。

### 2.2 色板纪律（锁死，防色漂）

- **全局色板 24-32 色锁死**：宣纸底、白墙灰阶、青水阶、墨灰阶、木色阶 + 朱红点睛。存成锁色板文件（.gpl / .ASE），Aseprite 全程锁定索引色。
- **每园 accent ≤ 8 色**：在全局之上，只给该园性格色（如狮子林石绿、退思园水青）。换园不换全局，只换 accent。
- 检验：任何一张成图截图整体取色，落在色板内的像素占比应为 100%。

### 2.3 tile 规格（白模已备好接口）

- **16px tile 全项目定死**，人物 16×24 或 16×32。
- **五层结构**：地 / 墙 / 中景 / 顶 / 物件——白模 `gusu-whitebox/src/render/` 已经是这五层，换装 = 按层替换绘制代码，逻辑零改动。
- 物件层放"机制构件"（漏窗、洞门、借景机位），它们同时是交互判定锚点——**画和谜题共用同一份数据**。

### 2.4 生产顺序（这是防返工的关键）

1. **沧浪亭 tile 词表定型**（估 15-20 个 tile + 3-4 个机制物件）：全项目唯一一次"从零发明画法"。
2. 验收过关 → **词表冻结为项目规范**。
3. 其余八园**只允许复用 + 新增**：新增 tile 需登记进词表并注明属园；跨园通用构件（白墙、瓦顶、水）禁止重复造。
4. 特殊状态单列变体：狮子林废园（荒草覆瓦 = 通用瓦顶 + 草 overlay）、退思园新园（木色更亮、无包浆）——用变体色板，不另起炉灶。

### 2.5 验收（Pillar 5 落地判据）

- **并排对照**：成图与实景照片/刘敦桢实测图并排放，构件可识别 → 过；认不出 → 重画。
- **AI 工具边界**（本项目的第四轮概念图已验证此边界）：
  - ✅ 可用：概念定调、大形参考、色板情绪板（已完成的那四轮就是）。
  - ❌ 不可用：直接产出 tile 资产——伪汉字、构件张冠李戴、逐像素不可控。
  - 折中路径：AI 出大形 → 人工在 Aseprite 里按词表重绘 → 逐 tile 对照验收。重绘时 AI 图只是垫底的草。
- **机制验收**：机制构件在白模里能否完成它对应的谜题判定（漏窗能对位、洞门能框景）——画完进白模跑一遍才算过。

## 3. 里程碑

| 阶段 | 内容 | 产出 | 分工 |
|------|------|------|------|
| M1 | 平江图公版扫描获取 + 矢量化 | SVG/JSON 水系街巷骨架 | 考据 agent 可外包 |
| M2 | 沧浪亭构件词表 + 全局/园色板 + tile 词表 | 15-20 tile + 3-4 机制物件 | 设计侧主刀 |
| M3 | 白模换装实测 | gusu-whitebox 渲染层替换，机制构件过判定 | 设计+程序 |
| M4 | 九园批量 + 平江图拓片道具 | 八园 tile 集 + 拓片画 | 词表冻结后平行 |

## 4. 风险三张牌

1. **词表未定型就批量 = 重画九次**。M2 没过验收，M4 一个 tile 都不许开。
2. **色板不锁 = 色漂**。第二座园子开始色温悄悄跑偏，第九座已经不像同一个游戏——锁色板文件从 M2 起强制。
3. **文字画进像素 = 伪字事故**。匾额、诗卡、榜书一律真字体渲染；匾额文字要出"刻字感"用字体特效层，不用手画笔画。
