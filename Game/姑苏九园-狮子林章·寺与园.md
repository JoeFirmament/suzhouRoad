# 姑苏九园 · 狮子林章《寺与园》

> v0.1（2026-09-30）· 承接大 Q 史实纠错「退思园不是庵庙，狮子林之前是庙」而新建
> 一句话：**这地方本来是庙。园那一半塌了，庙那一半还开着——两棵同源的银杏，被分在了两边。**
> 上位依据：《任务设计系统定案》§12 狮子林行（园性＝假山迷宫，候选任务《山中同路》，数/御）——**本线与其并行，不覆盖**；《游戏形态与核心玩法设计定案》§3.2 园林即谜题、§3.3 知识是奖励
> 考据依据：《姑苏九园-狮子林考据报告》（寺园沿革／古银杏／九园寺观属性逐园判定／寺庙植物／清末废园与入园方式）
> **本文只锁设计，不替代逐项考据**；凡带年代、书名、树种处均标证据等级。

## 0. 一句话与由来

**狮子林不是"一座后来变成庙的园"，而是"一座本来就是庙的园"。**
元至正二年（1342），天如禅师惟则的弟子们凑钱买地建屋奉养其师——**园，是寺的后花园。**

**本线要玩家看的就是这件事：一块地，两种身份，两棵树。**

> **由来**：本稿 v0.2 曾把"这块地原有一座庵堂"安在退思园上，被大 Q 当场指出——**违反史实**。考据确认：退思园地块**从来是私宅**，无任何宗教建筑记载；而**狮子林本当是寺**。于是这条逻辑从退思园剥离，落到它真正的主人身上，独立成章。

## 1. 两章的分工（与退思园线不撞车）

两章都在讲"一块地被分成两半"，但**分的东西不同**：

| | **退思园《树比园老》** | **狮子林《寺与园》** |
|---|---|---|
| 分界线 | **宅 / 园**（同一主人，两种规矩） | **寺 / 园**（两个主人，两种身份） |
| 两棵树的关系 | **一对**（雌雄，同一时代） | **同源**（都是寺的时候种的，差 250 岁） |
| 问题出在 | **不能结果**（生理） | **各归其主**（身份） |
| 玩家看到 | 一堵墙，两棵相望 | 一道界，一棵留在庙里、一棵进了人家 |
| 关键词 | **宅是给别人看的，树是给自己留的** | **分家的时候，人只算地，不算树** |

**再加府学文庙那棵「连理杏」**（600 年，树干空心、腹中长出朴树与楸树、合抱一体）——**

> **→ 该节点已独立成文档**：《姑苏九园-府学六杏·状元果与白果》v0.1（**第 0 层 · Home 线，不占九园名额**）。它同时是主角"银杏＝庙里的树"这条**常识的播种点**，亦即退思园线与本线的**共同前提**。三棵树的三种关系由该文档 §8 统一裁定。

**三棵树，三种关系，正是本作讲人际的三句寓言：**

| 树 | 关系 | 说的是谁 |
|---|---|---|
| 府学 · **连理杏** | **合抱** | 本来在一起的样子（序章的天真） |
| 退思园 · 两棵银杏 | **相望** | 被墙隔开、够不着（顾惟清与老师） |
| 狮子林 · 两棵银杏 | **分家** | 同一处出来的，各归其主（师与徒、知己与故人） |

| 年 | 事 | 置信度 |

> 园侧时称**涉园**或"黄氏园"，寺侧叫**画禅寺**。
> **主角在里面走了整整一章，都不知道这地方后来叫什么名字。**

## 3. 空间：一半活着，一半死了

1890 年走进去，看到的是**一个院落里两种时间**：

| | **寺侧（前）· 画禅寺** | **园侧（后）· 涉园** |
|---|---|---|
| 状态 | **活着**——有人念经、有人扫地、破败但仍在运转 | **死了**——断垣荒草，**唯假山依旧** |
| 声音 | 木鱼、钟磬、扫帚 | 风过假山孔洞的呜声 |
| 人 | 一两个老僧（**推断，不具名、不编造住持**） | **无人** |
| 树 | **一株逾五百年的银杏**（在其大殿附近，属寺） | **一株约二百五十岁的银杏**（在问梅阁东侧，属园） |

**这一章的核心画面就是这个**：**同一道墙的两边，一边还在敲钟，一边长满了草。**

### 3.1 进入方式（有据，不靠钥匙也不靠打怪）

- 考据：清末**寺观类是最"可以随便进"的一类**（对香客开放，且有园林景致可游）；私园则平时门禁森严。
- **所以主角是从寺门进的。** 进香的门，不是游园的门——**这个园子已经不算园子了，它只剩庙那一半还开着。**
- 顺势可用《清嘉录》「看花局」风俗作背景注（春时名园开放、看园人收"扫花钱"），但**狮子林园侧已荒废，不在开放之列**——**主角能进去，纯粹因为它是庙。**
- 若要接乔老叟线：**送粥/送供品到寺里**是天然理由（寺里有僧人，需要香客供养）。**「寺与园」和「一支粥的路线」可以共用同一只桶。**

## 4. 谜面：两棵树，差两百五十年

**玩法素材（全部有据，取自《苏州市古树名木志》）**：

| 树 | 位置 | 挂牌树龄 | **1890 年时** |
|---|---|---|---|
| 银杏 A | **园外·原狮林寺大殿附近**（今住宅区，原织锦厂），高 18 米、周径 4 米 | **640 岁** | **约 500 岁**——已是参天古木，**树龄与建寺（1342）几乎同步** |
| 银杏 B | **园内·问梅阁东侧** | **390 岁** | **约 250 岁** |

**谜面（一句话可成立）**：
> **同一座院子，外面那棵比里面那棵老了一倍。**
> 而**园子里这棵，偏偏是银杏**——苏州私园向来**不爱种银杏**（"白果"不讨口采）。

**主角为什么会在意**：
他是**府学学子**——**府学文庙的大成殿前就立着六株银杏**（含南宋的「寿杏」、腹中长出朴树与楸树的「连理杏」）。**他从小在银杏底下长大**，「银杏＝庙里的树」是他的身体记忆，不是听来的道理。

> 所以他在这里看见的是**两件同时不对劲的事**：
> ① **一座私家园子里，长着庙里的树；**
> ② **园外那棵，比园里这棵老一倍。**

**观看方式（沿用"移步成景"，不给箭头）**：园外那棵**从园内接驾桥向扇亭方向可望见**（考据原文）——**看得见，隔着界。** 无需任何提示文字，**玩家多站一会儿就会看见。**

## 5. 真相：分家的时候，人只算地，不算树

**1679 年前后，园林部分卖给了张家。寺和园从这天起就是两家了。**

而**两棵银杏都是"寺园还是一家"的时候种下的**：
- 园外那棵约种于 1390 年前后（明洪武），**寺刚建不到五十年**；
- 园内那棵约种于 1640 年前后（明末），**寺园尚未分家**。

> **换句话说：园里那棵，也是寺的树。**
> **分家的时候，地按亩算、按契算，谁也没想到树也要分。** 它就这么留在了别人家的院子里，**继续按寺里的规矩长。**

**这就是本线的答案，一句话**：
> **这不是"人家的园子里种了一棵庙里的树"——这是"庙里的树，被留在了人家的园子里"。**

### 5.1 情感层（本线的重量所在）

园侧如今**荒了**——亭台塌了，**只有假山还在**（1860 兵火，"唯假山依旧"）。
寺侧**还开着**——破败，但有钟声。

**一棵树跟着的庙还活着，另一棵树跟着的园死了。**
而它们**本来是同一个地方长出来的。**

> **这一章要玩家自己合上的那一句**：
> **分家分得掉地契，分不掉根。**

## 6. 思想核心：指柏轩与「庭前柏树子」

狮子林的厅堂**全以禅门公案命名**——立雪堂、卧云室、指柏轩、问梅阁（**禅寺只立法堂、不设佛殿**，与元代禅林制度吻合，有据）。

其中**指柏轩**出典是赵州从谂那段最有名的公案：

> 学人问：**「如何是祖师西来意？」**
> 师答：**「庭前柏树子。」**

**——一个无法回答的问题，被用院里一棵树回答了。**

> **这不正是《姑苏九园》的祖训吗？**
> **答案不在书里，在院子里那棵树上。**
>
> 本作反复在说的"园林即谜题"，**狮子林这一章是它最正统的出处**——不是我们发明的玩法，是禅宗一千年前就这么干了。

**用法（纪律）**：
- **由顾惟清念出这五个字**，念完就走，**不解释**（公案一旦解释就废了）；
- **全章只此一句引文**，不许再加别的典故；
- **不许把它讲成知识点**——玩家懂就懂，不懂也不影响通关。

## 7. 与《山中同路》的分工（同一园，两条线并行）

《任务设计系统定案》§12 已定狮子林 **园性＝假山迷宫、候选任务《山中同路》（数/御）**。本线**不覆盖它**，两条并行且互相咬合：

| | 《山中同路》（已有） | 《寺与园》（本线） |
|---|---|---|
| 玩什么 | **在假山的上、中、下层洞道里，靠光、声、坐标重建路线** | **在寺与园之间，靠两棵树的岁数差读出一段分家史** |
| 六艺 | 数 / 御 | 书 / 数 |
| 收获 | 看似绕远的路可能在立体中回到同一处 | 同一处出来的东西，可能各归其主 |

**咬合点（很好用）**：
> **假山迷宫是"荒废的那一半"里唯一还立着的东西**（1860 之后"唯假山依旧"）。
> **玩家在迷宫里绕了半天，从洞道钻出来——出口正对着寺的墙，墙那边有钟声。**
> **"我在一座死掉的园子里迷了路，出口却是活的庙。"**

## 8. 与悬疑暗线的接口

**同构，不硬拉剧情**（与退思园线同一纪律）：

| 狮子林 | 暗线 |
|---|---|
| 寺与园**分家**（1679） | 顾惟清与老师**分开** |
| **一道界，两个身份** | **两个人，都在等对方先开口** |
| 两棵树**同源**，各归其主 | 两个人**同门**，各归其路 |
| 一棵树**跟着的庙还活着** | **有个人还活着，只是不肯认** |

**红线**：
- 本章**不得**出现顾惟清的名字、那片叶子、九封信；
- **"等对方先开口"的意思不许被说出来**——玩家自己会想起来；
- 狮子林章只负责**把"分家"这件事演清楚**，剩下的交给玩家。

## 9. 台词样本（过五声声纹）

**主角（观察文字，不搞笑）**：
> `园里那棵银杏，比墙外那棵细一圈。`

**主角（稳档）**：
> 「这两棵，是一处长的么？」

**主角（莽档）**：
> 「这么高的墙，谁砌的？拆了算了。」

**画禅寺老僧（新次角 · 建议声纹：公案腔——问什么答什么，答的却不是问题）**：
> 「你问树。树在院里。」
> 「外头那棵？不归我管。」
> （**与"守碑老先生"的碑文腔区分**：老先生是**不接话**，老僧是**接得很顺、答得很偏**。）

**沈砚秋（诙谐，但这次不抖包袱）**：
> 「寺归寺，园归园。中间那道墙，比两边的房子都结实。」

**乔禾（报数，4–12 字）**：
> 「外面那棵，五百。」
> 「里头那棵，一半。」
> （**她只报数，不问缘由。**）

**顾惟清（若在场 · 引经据典，全章仅此一句）**：
> 「庭前柏树子。」
> （说完就走——**公案不解释**。）

**以上两个新次角（老僧）为建议声纹，启用前需先落人物卡——与《一片蕉叶二十年》次角同规。**

| **「画师倪云林巧堆狮子林」** | 苏州民谚／《履园丛话》所载**民间传说**，非史实。「倪瓒参与造园」是后世附会；倪瓒 1373 年画《狮子林图》这件事成立，**但画作学界普遍认定为旧摹本**。**要用，必须标"民间流传"** |
| **「寺园分家时，谁也没想到树也要分」** | 本线**文学表达**，非史料。属"读法"不属"史实" |
| 前榉后朴出现在狮子林 | **禁止**——前榉后朴是**民居/私宅**的科举习俗，**寺庙园林不采用**（文献以否定形式确认） |

### ❌ 禁用

| 内容 | 为什么 |
|---|---|
| **「狮子林之前是庙」的笼统说法** | 不准确——**它不是"后来变成庙"，而是"本来就是庙"**。准确说法：**「狮子林本是禅寺，园是寺的后花园」** |
| 「乾隆六游狮子林」 | 实为**五**游（第一次南巡 1751 未到） |
| 「圣恩寺是建园时的原名」 | 圣恩寺是**明万历十七年（1589）后**的名字 |
| 「画禅寺是民间俗称」 | 是**乾隆御赐的正式寺名**，且赐的是**寺庙部分** |
| 「园内有一棵 600 年的银杏」 | 园内挂牌 **390 年**；640 岁那棵在**园外**原寺区 |
| 「苏州报恩寺有 1300 年唐杏」 | 那是**安徽寿县**报恩寺，不是苏州北塔报恩寺 |
| 「留园前身是寺」 | 留园一直是私家园林；舍宅为寺的是**它旁边徐家的「西园」**（今西园寺） |
| 具体人名「黄熙／黄轩／黄兴祖／黄兴仁」 | 各来源混用，**游戏内只写「黄氏」** |
| 「1890 年的私园进不去」这句写死 | 须留口子：苏州有「看花局」开放传统，留园同光年间曾登《申报》卖票七十文 |

## 12. 风险 · 我的批判

| 风险 | 判断 |
|---|---|
| **⚠️ 我又给一座园编了前身** | **这一章存在的理由就是上次编错了。** 铁律：**凡涉及"这块地从前是什么"，只写考据报告 §4.2 判定为「✅ 是」的三园**（沧浪亭／狮子林／环秀山庄）；**退思园、网师园、耦园、留园一律不得虚构** |
| **"两棵树岁数差"太像退思园那条** | 真实风险。区分点：**退思园是"够不着"（生理），狮子林是"各归其主"（身份）**；一个问"为什么不能结果"，一个问"为什么一棵在墙里一棵在墙外"。**若玩家读出重复，砍 B 案，只留 A 案** |
| **滑成佛教科普** | 守住：**公案只出一句、不解释**；老僧不弘法、不说教；本章的宗教**只体现在钟声、匾额和一棵树上** |
| **"分家"写成悲情** | 禁止。**不写离别、不写眼泪**——只写**地契与树**。重量在"人只算地"这句平淡里 |
| **1890 年"狮子林"这名字的坑** | 全章**不许叫它狮子林**（人物口中须说"涉园""画禅寺""黄家那个园子"）。名字只在**章末知识条**出现 |
| **与既有《山中同路》打架** | 已做分工表（§7）；咬合点是"迷宫出口对着寺墙"。**若工程上只能做一条，留《山中同路》，本线退为背景叙事** |
| **主题偏沉，与诙谐基调冲突** | 与退思园线同一处理：**插科打诨只放在主角莽档和乔禾嘴里**，叙事不抖包袱 |

## 13. 验收（玩家走完本线，应能自己说出）

1. 这地方本来是干什么的？——**是庙。园子本来是庙的后院。**
2. 为什么园里会有一棵银杏？——**因为园子原来是庙的。银杏是庙里的树。**
3. 外面那棵为什么比里面老一倍？——**因为它们都是庙还完整的时候种的，后来寺和园分了家，两棵树被分到了两边。**
4. 你怎么知道的？——**我数了岁数，也认了匾额。指柏轩那三个字，是问树的意思。**
5. 这地方后来叫什么？——**（章末知识条）狮子林。**

> **本章不回答、也不应回答"两个分开的人后来怎么了"** —— 那是暗线的问题。
