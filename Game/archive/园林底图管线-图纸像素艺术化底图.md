# 园林底图管线：图纸 → 像素 → 艺术化 → 可游走底图

> 2026-09-28 定稿。每座园林的底图一律走这四步，禁止跳步（跳过图纸直接拍布局 = 自由创作，不收）。

## 四步定义

| 步 | 做什么 | 产物 | 质量闸 |
|---|---|---|---|
| ① 图纸 | 拿到该园可信平面（总平面图/测绘图/多源文字平面互证） | 图纸文件或《XX园平面考据》文档 | 每个建筑有出处；标注 A/B/C 证据级 |
| ② 像素化 | 按平面比例落 tile（1 tile=1m），建筑/山/水/路语义化 | `buildXXGarden()` 地图数据 | 比例与图纸一致；BFS 全 POI 可达 |
| ③ 艺术化 | tile painter 出图（32 色板锁色、漏窗/屋顶/山体积），多轮自迭代 | 引擎渲染层 + 静态验收图 | 用户验收风格基调 |
| ④ 底图 | 接入引擎：碰撞、取景点、出生点 | `#garden` 可游走模式 | 无头 Chrome 截图 + node 仿真双验证 |

## 工程落点（白模 gusu-whitebox）

- ② `src/data/mapgen.ts` → `buildCanglangGarden()`（100×57 tile，含 `buildings[]` 屋顶清单）
- ③ **2.5D 渲染（2026-09-28 定稿方向）** `src/render/garden25d.ts`：用户裁决「纯俯视不够园林，3渲2/2.5D」——逻辑层仍是 2D tile（碰撞/BFS 不变），渲染层按行 painter's algorithm 出斜视：粉墙立面+瓦帽、漏窗墙上开窗、假山石体积（跳块防卵石阵）、古树干冠、建筑坡屋顶/攒尖+吻脊宝顶、玩家按行插值遮挡。ground 整图缓存 + strips[ty] 行条带（上溢 48px）。
- ④ `src/main.ts` MODE 判定（`#garden` 或 `garden.html`）+ `garden.html` 入口
- 截图钩子：`garden.html#x29y20` 直落 tile 坐标；验证命令见 memory 2026-09-28
