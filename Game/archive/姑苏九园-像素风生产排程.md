## P0：现在就动（四件，全部零依赖）

### P0-1 全局色板 32 色定稿（最优先，其他一切的输入）
- 从四轮概念图取色收敛：宣纸底 / 白墙灰阶 / 青水阶 / 墨灰阶 / 木色阶 / 朱红点睛。
- 产出：`palette.gpl` + `.ase` 锁色文件 + 一张 32 色对照卡（每色标用途）。
- 验收：四轮概念图截图在色板内重映射后观感不塌。

### P0-2 平江图拓片转译第一版（240×240，三色）
- 底稿：LOC 清末拓片（assets/pingjiang/，1858-69 拓制——**道具画的是"清末玩家看到的那张"，实物同代**）。
- 流程：脚本降采样+二值化出预览稿 → 人工按符号语法重绘（河=双线/墙=雉堞/桥=短杠/坊门=门形/山塔=皴点层叠）。
- 三色 = 宣纸底 / 墨黑 / 朱印；原拓破损（中洞、边裂）转译为岁月肌理。
- 验收：与碑图并排，符号语法一致；无任何画进去的文字。

### P0-3 《蘇城全圖》城图 UI 转译（约 320×240，红黑双色）
- 底稿：assets/sucheng1890/ 渲染 PNG（5424×4761）。
- **白捡的风格gift：石印图本来就是红黑双色**——纸底/墨黑线/朱红标注，天然合规限色。
- 用途：清末层玩家的"城图"界面/道具（区别于宋拓片：这是"当代的图"，两件道具并置本身就是时代对照）。
- 流程：只转译**骨架层**（城墙、六门、河道、主干街巷、名园点位），巷级细节舍弃——这是 UI 图不是档案复刻。
