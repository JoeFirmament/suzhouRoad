## 0. 一句话定位

**园林是谜题，古城是呼吸——古城层不承载第二个核心玩法，它负责三件事：给入园提供"问题"、给出园提供"消化"、给长线提供"活着的感觉"。**

一句话 fun 校验：如果玩家在城市里做的事删掉后园林照样能玩，古城层就失败了；如果玩家离开园林后主动想"明天去书坊查查那句诗"，古城层就成立了。

## 1. 宏观结构：两层循环

```
古城（枢纽层）                    园林（谜题层·核心）
─────────────                    ─────────────
接线索 / 补给 / 委托赚钱   ──带问题入园──▶   漏窗对位 / 诗卡寻景 / 古树寻访
住店存档 / 梦境回放 / 查证  ◀──带产出回城──   出园结算 / 园谱钤印 / 六艺+银钱
```

- **Session 刻度从"一次游园"变成"一天"**：①入城接线索 → ②补给 → ③入园解谜 → ④出园住店。一天正好对应原设计"60–90 分钟单局"，结构不用重写，只是把存档点从"庭院分段"升级为"住店过夜"。
- **存档有叙事皮**：住店 = 过夜 = 梦境回放当天所得之景 = 暗线下一封信浮出的时刻。存档不是菜单按钮，是客栈掌柜一句"客官安歇"。
- **时间成为系统**：过夜推进天数。部分内容绑定时段——评弹昆曲只在固定日子有场、码头夜航只在天晴的晚上开、某些园林机位只有清晨/黄昏的光才"对得上"（为四时同景机制预留刻度）。[PLACEHOLDER：一天 = 现实 20–40 分钟，待测]

## 2. 功能场所设计表

每个场所回答四件事：玩家来做什么（动词）、对接哪门六艺、产出什么、红线是什么。

| 场所 | 玩家动词 | 六艺对接 | 产出 | 红线 |
|------|---------|---------|------|------|
| **客栈** | 存档、过夜、梦境回放 | — | 进度存档 + 信件钩子 + 时段推进 | 不做"旅馆恢复 HP"——没有血条，睡觉只推进时间 |
| **书坊/书肆** | 查诗卡出处、抄录园志、买地图拓片 | 书 | 诗卡下半联的"考据版"（答对的诗以题跋入册）、机位提示、古城地图 | 查证要花钱花时间——知识不能免费刷；但答错不惩罚（Pillar 3） |
| **笔墨庄/杂货铺** | 买灯（夜航/夜园必需）、买颜料（补画卷色）、买纸（多存一张照片） | 数 | 谜题型道具，不是数值道具 | 禁止卖"加成装备"——道具必须解锁新互动，不放大旧数值 |
| **茶馆** | 听闲话、接委托、师承对谈 | 礼 | 委托任务源、NPC 人情网 | 对话可跳过但跳过会漏线索——信息差是奖励不是惩罚 |
| **评弹馆/昆曲馆** | 听曲、对词、循声记谱 | 乐 | 曲词里藏诗卡来源（弹词开篇唱的就是某园某景）、乐艺升级曲谱 | 不做节奏小游戏强制关——听不完可以走，但完整听完给"声"的收藏 |
| **码头/船行** | 雇船、夜航、水上机位 | 御 | 城内快速移动 + 御艺水上机位（网师园、耦园水门） | 船资是银钱 sink 之一；夜航受限时段制造稀缺感 |
| **药铺/医馆** | 探病、送药、打听旧事 | 礼/人情 | 师父旧识、暗线线索、NPC 关系 | 见 §3：不做伤病系统，药是社交道具不是消耗品 |

**医院 → 药铺的替换建议**：古城语境里"医院"出戏，清代有药铺（雷允上、沐泰山这类老字号考据后可用）。功能照你说的保留——但药的角色定为**社交货币**：探病送药开对话线，比"治疗"有味道得多，也贴"人情"这个苏州气质。

## 3. 经济系统 v2：推翻"不设货币"，重建轻经济 ❌ **已废止（2026-09-30）**

> ⚠️ **本节整节作废，不得据以写作或实现。** 《任务设计系统定案》§8 已定：**本阶段不使用金钱、通用经验值、道具稀有度和每日任务作为奖励**；本作不设货币经济（《主线与六艺系统设计》§A 同）。以下内容仅作历史存档。

**摊牌**：上一版定了"不设货币、能力门闭环"。古城层一来，商店/船资/抄书费全都要花钱——**这条推翻，重设轻经济**。但红线不变：钱是"参与古城生活的润滑剂"，不是"变强的燃料"。

### Sources（钱从哪来）

| 来源 | 形式 | 防通胀闸门 |
|------|------|-----------|
| 出园钤印酬金 | 每园一次性，数额固定 | 封顶：九园共九笔 |
| 委托任务 | 固定脚本数量，全游戏委托总量封顶 | **不可重复接**——同一委托完成即消失，无刷点 |
| 卖"应景画" | 把拍到的景卖给求画 NPC（一次性脚本） | 每景只卖一次 |

**没有可重复 source 是底线。** 玩家缺钱时答案是"去做还没做过的委托"，不是"重复做一件事"——钱和六艺同构：产出不可刷。

### Sinks（钱到哪去）

| 去处 | 定价 rationale [皆 PLACEHOLDER] |
|------|------|
| 住宿（推进一天） | 日常固定开销，是"时间成本"的货币化 |
| 抄书/买园志 | 知识定价：越关键的线索越贵——但一次性买断，不订阅 |
| 灯/颜料/纸 | 谜题道具，单价低，制造"出门前查钱包"的实感 |
| 船资 | 快速移动的代价，步行免费——给"走还是坐船"一个真决策 |

**平衡判据**：一园周期（2–3 天）收入应略大于刚需支出（住宿+船资），结余刚好够"一次知识消费或一件道具"——玩家永远处在"想买但还差一点"的微张力里。[PLACEHOLDER：等九园任务量排完算总账]

## 4. 防清单化：古城层的生死线

古城层最大的死法就是变成跑腿清单。三条闸：

1. **顺路原则**：每个功能场所必须落在"去园林的动线"上，不允许"为买一盏灯专程横穿地图"。布局用宋《平江图》的水陆双棋盘——巷子窄、水面通，天然制造"路过"。
2. **一趟多目的**：委托设计成"顺路链"——去耦园的路上，船家托你带一封信给茶馆老板，茶馆老板顺口提了句曲词，曲词正是耦园某诗卡的下半联。**一个委托穿三个场所，玩家走的是一条路，捡到的是三份东西。**
3. **辗转任务的构成要件**（反清单公式）：一条委托 = 一个送因（人情）+ 一条顺路动线（沿途至少一处值得停的景）+ 一份入园线索（挂在终点）。三缺一就删掉这条委托。

**Playtest 失败信号 D（新增）**：玩家在城里打开任务列表说"先把这些跑完再进园"——命中即清单化已发生，重做委托结构。

## 5. 考据锚点与时代设定

- **地图底本：宋《平江图》碑**（现存苏州文庙，中国现存最早城市石刻地图）——游戏古城地图直接以它为底本转译，本身就是一桩可讲的人文故事（书坊里可以买到《平江图》拓片当全图道具，考据和机制互相咬合）。
- **时代设定：清末（光绪年间）——已定稿（v1.1）**。评弹鼎盛、书肆犹存、园林多为私家可访、船行仍是日常交通，所有场所同时成立。
- 真实店名/曲种/剧目全部逐条考据后才进文案（延续"宁缺毋假"纪律），本文表中店名均为功能占位。

玩家角色：**现代年轻人**（身份细化 [PLACEHOLDER]：建议园林/建筑修复专业方向，天然懂"看"，解释玩家的一切观察力）。在旧书摊/祖父遗物中得到《九园图》残卷与师父信札，循信寻至一座漏窗前——穿过，到清末。

**穿越规则只有一条：人过去，只带走眼睛。** 手机、现代知识、现代物件全部留在当代——这解释了取景匣的来历（穿越后在清末所得的师父旧物），也封死了"用现代科技解谜"的所有BUG口。

### 双时空分工

| 层 | 定位 | 内容 | 成本控制 |
|----|------|------|---------|
| **清末层** | 可玩主层 | 游城 + 游园 + 补《九园图》+ 读师父信 | 全部玩法资产 |
| **现代层** | 对照验证层 | **不做全城可玩地图**——只在出园结算时穿回，做"同机位现状闪回"：清末拍到的景，在现存的园里确认还在 | 同视角换时代细节，资产复用约省一半 |

### 双时空机制：照片对照（考据的游戏化）

清末所见 = 题面，现代遗存 = 答案之书。拍下清末的构件/匾额/古树 → 穿回现代对照：还存在的，照片落款盖"存"字印（知识奖励：这棵树/这块匾真的活到了今天）；已毁或改动的，盖"佚"字印并附一句它去了哪里。**"存/佚"二印把考据纪律做成了收集机制**——玩家为了集"存"印会主动记下真实构件，人文知识在对照里自然发生，零考试感。

### 主线缝合

原主线（画师弟子补《九园图》）改为：**现代玩家以"信所等的人"身份，被师父九封信引导补全残卷**——清末的园中人把玩家当作师父嘱托的远方后学，现代层里玩家的真实身份逐步揭开（祖父与师父的关系 = 终章悬念）。终章：回到现代，《九园图》末页补上最后一笔，落玩家自己的名字——"九园图补全"与"两个时代在同一卷纸上相遇"同时闭合。

### 切换纪律（防穿越通勤化）

- 只由**漏窗锚点**触发——穿越 = 漏窗机制的极限形态，机制主题不裂
- 一园限 1–2 次；**出园结算必穿回一次**（对照验证是结算仪式的一部分）
- Playtest 失败信号 E（新增）：玩家把穿越当"快速旅行"用、或主动问"能不能再穿一次"——前者说明穿越太廉价，后者是好事（钩子成立）
