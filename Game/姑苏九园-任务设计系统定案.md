## 1. 一句话原则

> 纹样线索的跨园制作口径另见《姑苏九园-纹样线索与实景图案制作标准》：冰裂、海棠等家族可以跨园，同一扇窗/同一片铺地/同一块匾额的实例不可串园；未核位置与年代的图案不能成为唯一谜底。

**不给苏州园林套上任务，而是把园林本来就能让人做的事，翻译成可玩任务。**

玩家不是为了清空问号而游园，而是因为一个人、一封信、一块碑、一棵树或一个看不懂的空间关系，必须亲自走进去看一眼。

## 2. 任务生成公式

```text
真实锚点
  × 只属于此地的空间动作
  × 一门六艺的理解方式
  × 一个具体人的当下动机
  × 完成后可见的世界变化
= 姑苏九园任务
```

任何一项为空，任务都应返工：

- 没有真实锚点：会变成任意古风场景都能发生的虚构跑腿。
- 没有空间动作：会变成百科问答或对话剧。
- 没有人物动机：会变成导游课程。
- 没有世界变化：完成后不会被记住。

## 3. 任务的六个节拍

| 节拍 | 玩家心中的问题 | 设计要求 |
|---|---|---|
| 1. 遇见 | 这是什么？ | 先看到人、物或异常，不先弹任务说明 |
| 2. 生疑 | 它为什么在这里？ | 给一个值得追的矛盾、缺口或未知 |
| 3. 循迹 | 我应该去哪里看？ | 线索必须指向一条有空间意义的动线 |
| 4. 行动 | 我能对它做什么？ | 使用观位、辨字、循声、行舟等实际动词 |
| 5. 领悟 | 原来如此。 | 知识在动作成立后才出现，不用答题换取 |
| 6. 回响 | 它改变了什么？ | 园谱、地图、场景、NPC 或新动作立即变化 |

一个 2–5 分钟的小任务可以只包含一次“循迹—行动—领悟”；一个 10–15 分钟的庭院段可以把三次小循环组成一次完整回响。

### 3.1 Home 与任务的关系

- 府学 Home 负责“遇见、生疑”与最终的“回响”，但不是所有任务的强制领取点。
- 城中请托和园林自得可在外部直接发生；玩家之后可以把它们带回 Home 整理，而不是先回去“正式接任务”。
- 每个园林章至少有一项成果使 Home 发生肉眼可见的变化。
- 详见《姑苏九园-苏州府学Home设计定案》。

## 4. 玩家看到的任务分类

游戏内不显示“主线/支线/日常”，而使用府学学子的语言：

| 游戏内名称 | 功能 | 是否必做 | 例子 |
|---|---|---:|---|
| **课业** | 章节骨架，教一个新动词 | 是 | 复廊三窗·看对合 |
| **请托** | 将人物、城市与园林串联 | 否 | 巡抚衙门到五百名贤祠的林则徐线 |
| **寻访** | 围绕古树、碑刻、匾额和构件的自主发现 | 否 | 文徵明紫藤 |
| **旧影** | 通过物证重构前代人物与造园瞬间 | 按章节 | 《蒙茸一架》 |
| **回访** | 在新时令、时段或新六艺能力下再看旧地 | 否 | 拙政园四时观景位 |
| **自得** | 无人委托、不入列表的纯观察时刻 | 否 | 在同一扇窗前多站一会儿，听见景外的声音 |

“自得”不显示未完成计数。玩家只在偶然触发后才知道它存在。

## 5. 七类可复用任务结构

### 5.1 移步成景

- 真实来源：漏窗、框景、借景、对景、倒影。
- 核心动作：移动与停步，让多个景物关系成立。
- 六艺：数/射。
- 禁区：只找一个闪光点按 E。

### 5.2 循声寻地

- 真实来源：水声、檐雨、风穿竹林、琴曲、评弹。
- 核心动作：根据方向、遮挡与回声选择路线。
- 六艺：乐。
- 禁区：把地点标在小地图上，声音只当装饰。

### 5.3 文字还原

- 真实来源：匾额、楹联、题跋、园记、石像赞、碑刻。
- 核心动作：比对字形、时代、落款、所处空间，还原文字与地点的关系。
- 六艺：书/礼。
- 禁区：先背文献，再回答一道选择题。

### 5.4 行路与行舟

- 真实来源：水巷、桥洞、园门、码头、沿水建筑。
- 核心动作：读水流、桥高、时辰和水陆连接关系。
- 六艺：御/数。
- 禁区：只把船当作快速旅行菜单。

### 5.5 时令观察

- 真实来源：花木、气味、风雨、日照、水位、题名中的时令。
- 核心动作：同一地点在不同时令或时段重新选择观景位。
- 六艺：数/乐/书。
- 禁区：捡四枚春夏秋冬标志物。

### 5.6 植物照料与生长

- 真实来源：古树、花木配置、藤架、植物与建筑的构图。
- 核心动作：根据日照、水分、支撑与观赏方向做布置决定。
- 六艺：数/礼。
- 禁区：通用农场游戏式点击浇水进度条。

### 5.7 人物遗迹

- 真实来源：官署、故居、碑像、手迹、藏书、工程与人际网络。
- 核心动作：在多个地点之间拼合“一个人做过什么、后人如何记得”。
- 六艺：礼/书，可叠加其他艺。
- 禁区：收集名人卡或听 NPC 一次说完生平。

## 6. “园谱旧影”规则

旧影解决“清末学子如何与前代人物互动”的时间问题。

### 6.1 它是什么

- 由实物、古树、碑刻、园记、画页和口述互相印证后，在园谱中构成的一段文化记忆。
- 它可以让玩家参与一次有据推演的行动，例如与文徵明安置紫藤。
- 它的画面应比现实层更像水墨、木刻或未着色的画稿，不再制作一套完整历史地图。

### 6.2 它不是什么

- 不是现代人穿越到清末；玩家自始至终是苏州府学学子。
- 不是改变历史；玩家的选择只改变对一次历史行动的理解和园谱呈现。
- 不是随时打开的快速旅行或梦境菜单。

### 6.3 进入条件

至少获得两类彼此独立的物证，并在真实地点中触发。物证不足时，园谱只呈现留白，不用虚构补齐。

## 7. 任务状态与界面语言

底层程序可以使用 `locked / clue / active / complete`，但玩家界面不显示工单语言。

| 底层状态 | 玩家看到的表达 | 地图/场景反馈 |
|---|---|---|
| hidden | 无 | 不显示问号或灰色占位 |
| clue | “听说……”“似乎有一条新墨痕” | 只出现模糊方位或人物线索 |
| active | 课页上的当前问题 | 显示已知线索，不显示完整解法 |
| insight | “原来……” | 暂停、题跋或园谱动画 |
| complete | “已记入园谱” | 地图、场景或人物产生永久变化 |

界面不显示“2/4 植物”“剩余 3 个线索”等清单计数，除非数量本身就是谜题中需要推理的信息。

## 8. 奖励只能改变四件事

| 奖励 | 可见变化 | 示例 |
|---|---|---|
| 六艺新动作 | 以前不能做，现在可以做 | 数·观位让玩家看见对位关系 |
| 世界新连接 | 地图显出路线、人物或园林 | 沧浪亭完成后出现网师园线索 |
| 园谱新内容 | 一页图、题跋、拓片或生长的边饰 | 紫藤旧影成为卷首边饰 |
| 人物新关系 | NPC 信任玩家做一件以前不会托付的事 | 拓工允许玩家独立选碑拓印 |

本阶段不使用金钱、通用经验值、道具稀有度和每日任务作为奖励。

## 9. 失败与提示

### 9.1 原则

- 没有不可恢复的任务失败。
- 不因历史知识不足而阻塞玩家；知识是行动后的奖励。
- 错误行动也应返回有用的环境信息，不只显示红叉。
- 时机类挑战可以重来，不扣除任何不可再生资源。

### 9.2 三层提示

| 层级 | 触发 | 方式 |
|---|---|---|
| 环境提示 | 首次偏离 | 风、水纹、树影、声音或视线轻微变化 |
| 学子自语 | 连续两次未成 | 只说判断方向，不说答案 |
| 人物点醒 | 三次未成或主动询问 | 指向一个可观察证据，不直接标出坐标 |

如果 5 人测试中超过 2 人需要第三层提示，应修改场景或谜题，不应继续增加文字说明。

## 10. 任务编写卡

每个任务进入程序与美术生产前，必须填完下表：

| 字段 | 必填内容 |
|---|---|
| ID / 名称 | 稳定英文 ID + 玩家看到的中文题名 |
| 类型 | 课业 / 请托 / 寻访 / 旧影 / 回访 / 自得 |
| 时空与年代 | 清末现实层或某一旧影；明确可见的历史状态 |
| 真实锚点 | 具体到建筑、构件、植物、碑刻或城市地点 |
| 证据等级 | A 实锤 / B 锚定 / C 候选 / 传说 / 虚构 |
| 人物当下动机 | 他为什么今天需要学子去做，不写“为了教玩家” |
| 开始问题 | 一句玩家真正想追查的问题 |
| 主动词 | 本任务唯一最重要的空间或观察动作 |
| 六艺 | 使用/教会哪门艺的什么新动作 |
| 六节拍 | 遇见、生疑、循迹、行动、领悟、回响 |
| 三层提示 | 环境、自语、人物各一条 |
| 奖励 | 四类合法奖励中的一至两项 |
| 可见回响 | 完成后世界中真正改变的画面、路线、文字或人物 |
| 禁区 | 这个任务最容易退化成什么 |
| 验收 | 玩家完成后能用自己的话说出什么 |

## 11. 三个定稿任务原型

### 11.1 拙政园《四时入卷》

- **开始问题**：同一座园子，为什么四张残页看起来像四个地方？
- **主动词**：在同一山池骨架中重新选择观景位。
- **四时线索**：春的花影与粉墙、夏的荷香与风向、秋的“待霜”与柑橘、冬的雪色与梅香。
- **领悟**：园子的骨架没有改变，但时令改变了人与它的关系。
- **奖励**：数·时景；一幅可切换四时的园谱长卷。
- **考据红线**：“一池三山”在所选清末底本中未完成裁决前，对外只称“以水为中心的山池格局”。

### 11.2 沧浪亭《名贤寻像·林则徐》

- **开始问题**：府学一份残卷的署名，是否属于那位曾在书院巷办公的巡抚？
- **主动词**：在巡抚衙门、府学旧档与五百名贤祠之间拼合一个人的城市轨迹。
- **行动**：按年代、官职、印记、像赞和增刻批次，定位林则徐石像。
- **领悟**：办事之地记录他做了什么，名贤之祠记录后人为什么记得。
- **奖励**：书·辨记或礼·景行；《蘇城全圖》出现“办事之地 ↔ 名贤之记”人物路径。
- **禁区**：在 594 名像中无线索找头像，或用一段 NPC 台词说完林则徐生平。

### 11.3 拙政园《蒙茸一架》

- **开始问题**：古藤、题石和后世记载，能否让我们看见它刚被种下的时刻？
- **主动词**：根据日照、水分、支架和观赏缝隙布置紫藤。
- **旧影**：得到至少两类物证后，与文徵明参与一次有据推演；不将选择写成历史事实。
- **领悟**：今天看见的古藤同时包含植物的生长、后人的题记与园林传说。
- **奖励**：书·辨年；园谱卷首出现随章节生长的紫藤边饰。
- **时代红线**：文徵明不是清末现实层 NPC。

## 12. 九园首批任务种子

> 本表只锁定“园性 × 动词”，不代替逐项考据。带时代建筑名、人名、树种、匾额文字的内容一律在生产前复核。

| 园 | 园性 | 候选任务 | 主动词 | 六艺 | 玩家应带走的理解 |
|---|---|---|---|---|---|
| 沧浪亭 | 水界·复廊 | 《复廊三窗》 | 沿水移步、停在景成之处 | 数 | 廊不只连接地点，也在组织看水的方式 |
| 拙政园 | 水面·借景·四时 | 《四时入卷》/《蒙茸一架》 | 在同一骨架中重新选景 | 数/射/书 | 园景由水面、植物、建筑和时令共同完成 |
| 网师园 | 小中见大 | 《一池有多远》 | 用近景遮挡、尺度参照和倒影扩展视觉距离 | 数/射 | 空间感受不等于平面尺寸 |
| 狮子林 | 假山迷宫 | 《山中同路》；**主线《寺与园》**〔2026-09-30 新增，另见《姑苏九园-狮子林章·寺与园》〕 | 在上、中、下层洞道中根据光、声和坐标重建路线；**读两棵银杏的岁数差（500／250）、认公案匾额，读出"寺与园分家"** | 数/御 ＋ **书/数** | 看似绕远的路可能在立体中回到同一处；**同一处出来的东西，可能各归其主** |
| 留园 | 空间收放 | 《暗处借光》；**主线《一支粥的路线》**〔2026-09-30 新增，另见《姑苏九园-留园章主线·送粥寻书线设计》〕 | 穿过窄廊与庭院判断空间节奏；提桶入园 · 辨匾额 · 蕉叶传信 | 乐/数 ＋ 御/书 | 园林的大小感来自先收后放；**准入靠一个社会关系，不靠钥匙** |
| 耦园 | 成双 | 《两园一答》 | 在东西两条动线中找到彼此呼应而不完全相同的景 | 礼/书/数 | “耦”不是简单对称，而是两个人与两座园的应答 |
| 艺圃 | 质朴·留白 | 《少一笔》 | 从过密的画页中移除遮挡，找到让水、墙与山成立的最少元素 | **礼/乐** | 简约不是内容少，而是每一笔都不可替代 |
| 环秀山庄 | 叠山 | 《一山多径》 | 把山涧、石梁、洞壑和高差拼成可通行的立体关系 | 数/御 | 假山不是石头雕塑，而是一座被压缩的可游之山 |
| 退思园 | 贴水·倒影 | 《水上还有一座园》；**植物线《树比园老》**〔2026-09-30 新增，另见《姑苏九园-退思园植物线·树比园老》〕 | 同时读取建筑与倒影，在水位和风动中完成对位；**上天桥看见墙外那棵树** | 御/射 ＋ **书/数** | 贴水建筑使真实空间与水中空间同时存在；**墙外还有一棵树——空间被隔开，也就被读出来了** |

## 13. 反清单化审查

任务通过立项前，逐条审查：

- [ ] 去掉奖励后，行动本身仍然值得做。
- [ ] 去掉地图标点后，玩家仍能从场景证据找到方向。
- [ ] 换到另一座园后，这个任务不再成立。
- [ ] 不读历史说明文，也能通过观察完成。
- [ ] 完成后世界有一项肉眼可见的改变。
- [ ] 不重复给六艺成长或其他可刷奖励。
- [ ] 历史信息标注了史实、有据推演、园林传说或虚构。

任何一项未通过，不进入美术与程序生产。

技术红线：

- `rewards` 必须幂等，同一任务不能重复提升六艺。
- `worldChanges` 与存档绑定，不由某个页面临时显示。
- `knowledgeEntries` 与任务结果关联，不作为启动任务前的考试条件。
- `replayPolicy` 可允许重看、重做、换季节，但不得重复结算成长奖励。
