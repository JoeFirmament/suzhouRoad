# 姑苏九园 · 苏州府学 Home 设计定案

> v1.0（2026-09-29）· 玩家归属地、章节枢纽与长线成长空间定案。  
> 一句话：**玩家是主角，苏州府学（文庙）是 Home，也是整部游戏的第二主角。**

## 1. 产品定位

```text
府学 = Home
《蘇城全圖》 = World
九座园林 = Chapters
构件近景 = Puzzles
《九园图》/园谱 = Memory
```

“Home”是游戏功能而不是对历史住宿制度的断言。玩家在府学修业、与师友建立关系、整理所得并从此出发；在考据明确前，不预设玩家必然住宿在府学内。

## 2. 历史立足点

- 苏州文庙即苏州府学，始修于北宋景祐二年（1035），范仲淹创立将官学与祭孔庙堂结合的格局。
- 初创格局的文献表述为“左为广殿，右为公堂，泮池在前，斋室在旁”；庙与学本来就是一个综合空间。
- 府学在清同治三至七年（1864–1868）经重建，直到光绪三十年（1904）停办。因此在约 1890 年的游戏时点，府学仍是合理的求学与文化场所。
- 《苏州府学志》的整理范围包括府学教师、教法、生员、教学、编书、刻书、藏书与 203 通府学碑刻，支持 Home 同时承担教学、文献和金石功能。
- 沧浪亭与府学文庙毗邻，第一章从 Home 走向沧浪亭具有真实的城市空间关系。

### 考据红线

- 今日苏州碑刻博物馆的建筑保存、广场和展陈不能直接等同于清末府学。
- 游戏正式地图必须以同治、光绪方志、《苏州府学志》与可考图片复原；现阶段只锁定功能分区，不锁定每间房的最终名称和位置。
- 大成殿、泮池等已有可靠证据的构件可进入白模；明伦堂、斋舍、藏书与碑廊在约 1890 年的具体状态需逐项复核。

## 3. Home 承担的五个角色

### 3.1 学业之家

章节开场不是从任务菜单开始，而是从师友正在处理的一件事开始：一页缺失观景位的画、一处读不通的题记、一封需要送达的信，或一场尚未有结论的讨论。

### 3.2 人际之家

同窗、师长、执事和守碑人有自己的兴趣与进度，不围着玩家站桩发任务。玩家外出后，他们也会移动、讨论、编书、拓碑或整理庭院。

### 3.3 园谱之家

九园收获不存在抽象收集菜单里，而是落在一卷可见的《九园图》、书案、拓片架与题跋中。每完成一座园，Home 就多一件可见内容。

### 3.4 金石与城市记忆之家

《平江图》等碑刻在这里被阅读、拓印和比较。它们不取代《蘇城全圖》导航，而是让玩家看见同一条水路、街巷或城门在不同时代的连续与变化。

### 3.5 情感之家

玩家应该因为一盏灯、一个熟悉的人、一页逐渐填满的园谱和一处会随天时变化的庭院而想回来。“回 Home”不只是系统强制结算。

## 4. Home 循环

```text
府学中遇见一个问题
        ↓
与师友讨论，在《蘇城全圖》上确认方向
        ↓
离开 Home，进入城市、园林与近景
        ↓
带回图像、拓片、题记、植物记录或一个新问题
        ↓
亲手把所得放入园谱，与人谈论自己看懂了什么
        ↓
六艺新动作、人物关系与《蘇城全圖》产生回响
```

### 节奏

- 首次到达 Home：10–15 分钟，建立身份、人物与出发仪式。
- 普通庭院段返回：3–7 分钟，只完成一次记录、对话或新线索。
- 园林章结算：8–12 分钟，允许人物与 Home 状态发生较大变化。
- 玩家可以在多数小任务后继续探索，不必每 2–5 分钟被强制送回 Home。

## 5. 空间功能分区

> 本章是白模功能要求，不是对约 1890 年建筑名称和坐标的最终裁决。

### 5.1 不可改动的总骨架：东庙西学

府学 Home 不再采用“一个主院、左右宿舍与书房”的通用书院构图，而以苏州府学可考的庙学双轴为母体：

```text
北
↑
西学（日常、高交互）                 东庙（礼仪、低交互）
藏经/金石 — 敬一 — 明伦堂            后部祠宇 — 大成殿 — 戟门
        │                                  │
   斋舍、书房、池水、花木                    礼仪院落、两庑
        │                                  │
   泮宫/礼门 — 仪门                  洗马池/桥 — 棂星门
        │                                  │
     学宫门序                         黉门及文庙门序
                     ↓ 南 / 苏州城
```

- **东庙轴**：保存祭祀和礼仪的庄重秩序。它可以承载重大章节事件与“礼”艺，但不可摆满日常委托、床铺和收纳箱。
- **西学轴**：是玩家日常 Home 的主体。明伦堂院承担共读与人物关系；藏书、金石和校读在其后部展开；斋舍、书房与小型园林空间贴附在学宫轴外侧。
- **双轴门序，不是双正门**：两轴各有一串不同层级的门、院与桥，不得简化为临街并排、形制相同的两个正门。画面需让玩家看见两轴属于同一府学，又能从开放程度和活动密度上分辨“庙”与“学”。
- **水在院内，不画门前运河**：洗马池/桥、泮池、七星池及园林水系可进入场景；在取得更强证据前，不把府学南界画成一条贯穿两门的城市河道。
- **斋舍属于游戏化推定**：床铺、箱笼和个人书案可以服务 Home 循环，但其 1890 年确切房址在找到同治、光绪底图前不作历史断言。

### 5.2 史实置信度分层

| 层级 | 当前可采用内容 | 用法 |
|---|---|---|
| 高 | 庙学合一、东庙西学、双轴并列；大成殿与明伦堂分别为两轴核心 | 直接决定地图骨架 |
| 中 | 东庙棂星门—戟门—大成殿—后部祠宇；西学入口—仪门—明伦堂—敬一亭—藏经空间的纵向关系 | 用于白模排序，名称与清末状态继续核校 |
| 高（现状） | 现址为苏州碑刻博物馆，保存《平江图》等宋代碑刻 | 支持金石玩法与城市记忆主题，不把现代展陈搬进 1890 年 |
| 待核 | 1890 年斋舍、号房、教官廨宇、藏书和碑刻的具体房址及开放方式 | 只做功能性侧房，不写成“原址复原” |

| 分区 | 玩家动词 | 承担系统 | 空间气质 |
|---|---|---|---|
| 庙前与泮水边 | 抵达、离开、遇人 | Home 与《蘇城全圖》的门槛 | 开阔、有城市声音 |
| 礼仪中轴 | 观礼、参加阶段事件 | 礼艺、大章节转折 | 庄重、留白，不摆任务摊位 |
| 讲学与共读区 | 听、辨、讨论 | 课业起点、同窗关系、六艺理解 | 有人使用，案头会随章节变化 |
| 金石与藏书区 | 读碑、拓印、查卷、辨年 | 《平江图》、文字任务、旧影物证 | 纸、墨、石与低照度光线 |
| 园谱书案 | 放入、排布、题记、收卷 | 结算、存档可见化、九园记忆 | 亲密、可触摸，是玩家最个人的角落 |
| 静院与树下 | 闲坐、听、偶遇 | 自得、时令变化、人物私下对话 | 不承担必做任务，让 Home 有呼吸 |

### P0 白模优先做三条交互链

1. **西学门槛—明伦堂院**：从城中归学，与师友遇见第一个问题。
2. **明伦堂院—斋舍书案**：熟悉床铺、箱笼、个人书案和 Home 的生活节奏。
3. **斋舍书案—园谱回带**：放入沧浪亭三窗记录，触发数艺与网师园回响。

东庙轴在 P0 中必须存在于画面和路径边界中，但只开放观察和少量礼仪反馈，不与西学争夺日常交互重心。

金石区在《名贤寻像·林则徐》或《平江图》拓碑任务制作时再开放；不为了建筑全而先把整座府学做满。

## 6. 六艺在 Home 中的可见化

六艺不是六个训练室，也不是六名头顶图标的导师。它们体现为玩家对同一个 Home 能做的新事：

| 艺 | Home 中的新行动 |
|---|---|
| 礼 | 读懂典礼、称谓和人物的进退，参与更深的讨论 |
| 乐 | 在庭院中分辨城市与庙学的远近声音，找到声音来源 |
| 射 | 在画页、院门与远景之间完成视线对齐 |
| 御 | 从《蘇城全圖》读懂水陆路线，解锁新的出行方式 |
| 书 | 阅读原本模糊的落款、题跋和藏书索引，亲手题记 |
| 数 | 看见园谱和地图中的比例、方位、对位和结构关系 |

## 7. Home 如何成长

| 阶段 | Home 状态 | 玩家感受 |
|---|---|---|
| 入学 | 园谱几乎空白，人物与空间都陌生 | “我刚到这里。” |
| 沧浪亭后 | 书案出现复廊三窗；数艺观位线出现；同窗开始询问玩家所见 | “这里开始记得我的游历。” |
| 三园后 | 不同观察方式在书案和庭院并置；人物形成持续关系 | “我知道遇到问题可以找谁谈。” |
| 六园后 | 旧影、拓片与城市路径交叉；府学出现由玩家发起的课题 | “我不只领课，也能提出问题。” |
| 九园后 | 《九园图》完成；府学举行一次与玩家所学相关的收束事件 | “这不只是学堂，是我理解苏州的地方。” |

### 九园回带物的规则

每一园只选一件主回带物，避免 Home 变成收藏品卖场：

- 必须能代表这座园的核心观察方式，不只是地标缩小模型。
- 必须改变 Home 某处的构图、声音、文字或人物行为。
- 必须由玩家亲手放入园谱，不由系统在过场中自动飞入。

## 8. 首章 Home 垂直切片

### 8.1 出发：府学入学

1. 玩家从庙前进入，通过行走和一次简单搬放书卷学会移动与交互。
2. 一名同窗正在整理《九园图》，发现沧浪亭页只有三个窗框，没有窗外的景。
3. 师长不告诉玩家答案，只说：“府学东顾，草树之外，有一带水。你自己去看。”
4. 玩家在《蘇城全圖》上辨认 Home 与沧浪亭的相邻关系，推门出发。

### 8.2 返回：把水带回来

1. 完成复廊三窗后，玩家带回三个观位记录，而不是三件道具。
2. 在园谱书案上，玩家亲手把三个窗外之景放回正确窗框。
3. 三幅景合成一段沿廊移动的长卷，数艺获得“观位·初识”。
4. 师长不复述标准答案，只问“窗有没有动？”由玩家回答自己理解的是景在动，还是人在动。
5. 《蘇城全圖》东南一带出现网师园的新墨痕，但不立即解锁完整入口。

### 8.3 首章只教三件事

1. 遇到不懂的事，可以离开府学亲自去看。
2. 看懂后要回来整理、讨论和记下。
3. 每次真正看懂一件事，苏州就会向玩家多显现一点。

## 9. 人物架构

> 本表定职能，不定姓名。姓名、身份称谓与清末府学职官结构需考据后再写入剧本。

| 角色 | 功能 | 自身进程 | 禁区 |
|---|---|---|---|
| 一位师长 | 用问题而不是教程引导章节 | 从观察玩家到愿意讨论真正难题 | 万能百科 NPC |
| 一位熟悉城路的同窗 | 将 Home 与《蘇城全圖》连起来 | 从带路者变成与玩家相互请托的朋友 | 移动地图指针 |
| 一位关心花木与时节的同窗 | 承接植物、四时和紫藤线 | 在玩家影响下从记名称转向观察生长 | 图鉴菜单化身 |
| 一位掌文卷/金石者 | 引入拓碑、辨年和人物遗迹 | 从不让新学子动碑到允许共同校读 | 只负责发放收集品 |

关键人物不宜过多。P0 只需师长、城路同窗和一名背景学子，先验证 Home 是否有归属感。

## 10. 存档与界面

- 底层继续自动存档；园谱书案的“收卷”只是存档可见化，不要求玩家手动保存才能离开。
- 不设立覆盖全屏的任务大厅界面。当前课业存在案头课页中，最多显示“当前问题”和已得线索。
- 六艺总览可以在园谱内查看，但不以经验条呈现；每门艺显示玩家已会的动词。
- Home 中的可交互物依靠构图、光线、人物动作和近距离反馈显示，不铺满发光边框。

## 11. 技术状态

Home 至少需要保存：

```text
homeVisitCount
homePhase
currentHomeEvent
nineGardensPages[]
artActionsUnlocked[]
npcStates{}
steleAccess
homeTimeOfDay
homeSeason
```

- Home 中的视觉变化必须来自存档状态，不是仅在单个页面会话中临时出现。
- 每一园的主回带物只结算一次，重玩只改变季节、题记或补充记录。
- NPC 进度与任务进度分开，避免人物永远停留在“等玩家交任务”的动作。

## 12. Home 验收标准

### 空间

- 玩家第二次回来时，无需小地图就知道如何去世界出口和园谱书案。
- P0 三区之间单程不超过 20–30 秒，不让结算变成跑图。
- 礼仪区、共读区和个人书案在构图上一眼可区分。

### 功能

- 玩家不会把 Home 理解为“点 NPC 领任务”的中转站。
- 玩家每次返回至少能指认一处来自本次游历的变化。
- 首章结束后，玩家能说出“我为什么要回府学”。

### 情感

- 5 人测试中至少 3 人主动使用“学里”“回去”或“我们的书案”类归属语言。
- 如果多数人称它为“主菜单”“任务点”或“存档点”，Home 设计失败，必须增强人物生活与空间回响。

## 13. 开发顺序

### P0 · Home 白模

1. 根据可考底图确定约 1890 年府学的入口、庙学主轴与教学区相对关系。
2. 只制作门槛、共读、园谱三区的可走白模。
3. 完成“出发—复廊三窗—归来—放入园谱—网师园现线索”全链路。

**当前实现（2026-09-29）**：Home 已从通用单院落概念改为“东庙西学”的双轴功能母版，并将水体收回院内、将两轴入口处理为不等值的门序；同时加入可跳过、可回看的“府学发问—首次入园—三窗完成—府学归来”短叙事链。现图用于验证双轴识别、功能分配与移动节奏，不作为 1890 年精确建筑复原图；下一轮需用同治、光绪方志与《苏州府学图》校正尺度、房舍数量和名称。

### 视觉实现更正

府学 Home 的程序化纯色白模已经废弃，不作为任何后续美术记忆或质量参照。当前运行版采用完整的西学单屏环境资产、正式玩家与沈砚秋精灵；程序网格只保留在不可见的碰撞层。今后的历史校正应修改环境资产和碰撞层，不允许为了快速验证再次把纯色方块直接暴露给玩家。

### P1 · Home 有人

4. 加入师长与城路同窗的移动、作息和首章对话。
5. 每个人物至少有一个与玩家无关的当下行为。
6. 验证返回 Home 后的 3–7 分钟节奏是否温暖而不拖沓。

### P2 · 金石与长线

7. 在《平江图》拓碑和林则徐任务需要时，扩展金石/藏书区。
8. 完成三园后再制作大型礼仪事件，不在 P0 提前搭建一套空的礼仪场景。
