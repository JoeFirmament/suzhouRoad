> 纪律：每个构件必须能在**刘敦桢实测图或实景照片**中指认；指认不到 → [待考据核]，不入图。

## 0. 通用复用清单（九园共用，沧浪亭定型后冻结）

地：石板主径 / 泥土小径 / 廊内条砖 / 水面×2帧 / 静水潭
墙：粉墙 / 勒脚基座 / 漏窗墙单元 / 门屋
中景：湖石假山体 / 古树大冠 / 竹丛 / 矮灌木
顶：攒尖石亭顶 / 硬山厅堂顶 / 单坡廊顶
物件：漏窗机制单元（按园换纹样贴片，框不动）
