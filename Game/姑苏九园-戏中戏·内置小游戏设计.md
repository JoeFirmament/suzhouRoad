## 1. 一句话定位

> **城里的"玩意儿"：玩家在茶馆、棋摊、书场前坐下来，玩一局与主线无关、随时可走、输了能再来、只有分数没有好处的小游戏。而城里有几个人，是赢不下来的。**

**Fun 校验**（沿用《古城层》那条的写法）：如果把这些玩意儿全删掉，主线照样能通——所以它必须靠**"我下次要再赢一局"**自己站住。**判据只有一条：玩家输完，手会不会自己点"再来一局"。**

**它不是什么**（写在最前，防跑偏）：

- 不是六艺通道——六艺只在主线「玩家自己完成一次该动作」时发（§C3.1）；
- 不是经济来源——本作无货币、无经验（任务定案 §8）；
- 不是主线门槛——**永不拦路**；
- 不是战斗——无血条、无弹幕、无伤害（《游戏形态》§8.1／§12.2）。

## 2. 原型解剖：《三角符文》的小游戏到底是什么（已联网核准）

| 维度 | 《三角符文》的实际做法 |
|---|---|
| 出现时间 | **第三章才引入**，第四章扩容（Mike 小游戏房） |
| 进入方式 | **固定地点**，随剧情解锁，之后可反复回来 |
| 内容 | **一款一机制**，彼此不通用（做菜躲火／跟节奏弹琴／护像应战／投篮／接猫） |
| 目标 | **冲最高分**，配生命值与奖杯（铜／银／金／铂金） |
| 主持人 | **有专门角色解说**——Tenna 主持整场，Mike 们各主持一款，并**按你的最高分给不同台词** |
| 地位 | **多数可选**，少数必须通关才能推进 |
| 官方自述 | 「**它们对任何东西都没有影响，所以只管玩、放松。**」 |

一句话：**有主持人的、可重玩的、独立计分的、与主线并行的消遣通道。**

## 3. 取三条，弃一条

| 元素 | 取／弃 | 在姑苏九园怎么落 |
|---|---|---|
| 固定地点 + 可反复回来 | **取** | 茶馆／棋摊／书场，落在"去园林的动线上"，顺路就能坐一会儿 |
| 一款一机制 | **取** | 每款玩法不通用，且**必须由该地点的真实特性导出**（守 §8.2） |
| 独立计分 + 评级 | **取** | 最高分**只记在册**，不换算任何能力／钱／六艺 |
| 有主持人、按分数换台词 | **取** | 主持人**用已有角色**（掌柜／说书先生／摆棋摊的／乔老叟），复用即省成本 |
| **"少数必须通关才能推进"** | **弃** | 本作**永不拦路**——沿用已归档《古城层》那条现成口径：「**不做强制关，玩不完可以走**」 |
| 战斗式敌人／血条 | **弃** | 《游戏形态》§12.2 不做战斗；紧张感只来自**时机、路线、声音、视线**（§8.2） |

## 4. 双轨结构（大 Q 裁："两者并存"）

| | **A 轨 · 戏 · 茶馆玩意儿** | **B 轨 · 课 · 章内机制** |
|---|---|---|
| 位置 | **城里**的固定场所 | **园内**，属于该园 |
| 时机 | 常驻，任何时候 | 章内一次，与主线咬合 |
| 可重玩 | **可**（记最高分） | 一次性（进剧情节奏） |
| 六艺 | **不发** | **发**（走 §C3.3 课业通道） |
| 产出 | 只有分数与评级 | 园谱／knowledge／六艺 |
| 与主线关系 | 无关，删掉不影响通关 | 相关，是章的一拍 |
| 对应《三角符文》 | 小游戏本体 | 「每章独立机制」（§2.2 已定） |

**判据（一句话）：A 轨是"消遣"，B 轨是"课业"。** 两者共用 UI 骨架，但**名字、计分、可重玩性、发不发六艺，全都不许混**。

⚠️ **别把 A 轨做成 B 轨的皮**——一旦 A 轨开始给 knowledge 或给线索，它就变成了"另一种课业"，且会踩"任务不应退化成知识点捡物"（《游戏形态》§17.2）。

## 5. 载体：城市场所表（顺手补上归档留下的空缺）

⚠️ **现状（必须先说清）**：城市场所表原来在《姑苏九园-古城层与功能场所设计》里，该文已归档，**现役文档中没有任何城市活动场所表**。A 轨要落地，先得有这张表。

**落位分两批**（按 §11-6 定案：**第一批只开茶馆**）：

| 批次 | 场所 | 主持人 | 可玩 | 与主线的关系 |
|---|---|---|---|---|
| **第一批（唯一）** | **茶馆** | 掌柜 / 说书先生 | **灯谜条（M1）** | 听过路人说闲话的地方，顺路 |
| 后续·未排期 | 棋摊 / 棋社 | 摆棋摊的老人 | 残局一局（M2） | 常在巷口，路过即见 |
| 后续·未排期 | 书场 | 说书先生 | 益智图（M3）／九连环（M4） | 等场次时的消遣 |

**为什么先只开一处**：本作**永不拦路、不设日程**，场所开得多只会摊薄 §1 那条唯一判据的验证力度——「**输了会不会自动点再来一局**」只要一间茶馆就能测出来（与 §9「首批只做 M1」绑定）。**未排期 ≠ 取消**，二批随城市层动线扩展再开。

**三条纪律**（沿用《古城层》§4 反清单化，它在归档前是对的，方法可继承）：

1. **顺路原则**：每个场所都必须落在"去园林的动线上"，不许为玩一局横穿城。
2. **不设"今天必须玩"**：没有日程、没有提示点。
3. **场所名一律功能占位**——真实店名待考据回来再补（守"宁缺毋假"）。

## 6. 对手局：本作的"boss"（大 Q 裁："或者类似 boss"）

本作没有战斗（《游戏形态》§8.1），所以"boss"必须**重新定义**：

> **对手局 ＝ 一个人坐在你对面，一局定胜负，可无限重来，赢了只拿"名分"。**

**四条规格**：

| # | 规格 | 说明 |
|---|---|---|
| 1 | **可选** | 不在主线上，删掉不影响通关 |
| 2 | **藏着** | **必须先做一件事才会出现**（照《三角符文》：Jevil 要先跟囚犯"玩个游戏"；Mike 们要先把假 Mike 打完）——**不许在菜单里列出来** |
| 3 | **极难** | 全作最难的几局，允许玩家卡住、放弃、过很久再来 |
| 4 | **赢只给名分** | 落在**人物关系**或**园谱**（任务定案 §8 的四类可见变化），**永不落在六艺／钱** |

**输不惩罚**：不扣任何资源，可以立刻"再来一局"。**被记住的只有你赢了没有。**

**三个候选对手局**：

| 名 | 地点 | 对手 | 玩法 | 赢的产出 | 解锁动作 |
|---|---|---|---|---|---|
| 《灯下那一擂》 | 茶馆夜场 | 说书先生 | 连答灯谜条，题目由易到难 | 他从此认得你；园谱留一条谜 | 先在他那儿白听三场 |
| 《残局》 | 棋摊 | 摆棋的老人 | 一局极难的排局，限步取胜 | 他把棋盘留给你收（人物关系） | 先替他把棋子捡回去一次 |
| 《一壶之间》 | 茶馆后间 | 乔老叟 | 投壶式时机挑战，比准头 | 关系变化（**不再多给任何东西**） | 序章后与他有过一面 |

⚠️ **对手局与暗线的关系（§11-2 定案）**：**纯消遣，暗线一字不碰**（与《狮子林章》红线三同调）。**这是定案、不是建议**；若要挂钩，须另案重开，**不得默认**。

## 7. 挑战性：三层难度 + 品第评级

- **同一机制，三段难度**（初局／中局／难局）——**只换局面参数，不换机制**。三款小游戏 = 九种局面。
- **评级借用画论品第**：**能品 → 妙品 → 神品 → 逸品**（§11-3 定案，不用「初记／得法／精熟／入神」那套）。
  - 【考据标签：**有据推演**】朱景玄《唐朝名画录》分神、妙、能、逸四品（逸品置于格外）。**本作只借"品第"这套说法做游戏内计数，不作任何历史断言**；四档与分数的对应关系属**虚构**。
- **逸品只属于对手局**（对应《三角符文》的铂金杯／隐藏 boss）。
- **不设全球排行、不联网**——只有"你自己上次多少分"。

## 8. 红线十条（隔离条款）

1. **不发六艺**（守 §C3.1：六艺只由主线自证动作发）。
2. **不给钱、不给经验、不给道具**（任务定案 §8）。
3. **不弹"获得／升级／+1"横幅**——分数只在场所里能查。
4. **永不拦路**：任何"必须打通才继续"都要删。
5. **无血条、无弹幕、无伤害**（§12.2）。
6. **不进 `StoryFlag` 主表**——另开独立存档命名空间（见 §10）。
7. **不接管城市 UI**：分数不上《蘇城全圖》界面。
8. **主持人可以按最高分换台词，但不许透露任何主线答案**。
9. **不做限时强制**：随时可暂停、可退出，退出不判负。
10. **美术守《统一像素视觉系统》**——用具内 UI 帧，**禁止高饱和街机风**。

## 10. 工程接口

| 项 | 结论 | 理由 |
|---|---|---|
| **界面态** | 小游戏是**离开行走的独立界面**（棋盘屏／谜题屏），**不新增行走世界动词** | 守"不新增交互动词"（《取景匣》§），避免污染核心动词链 |
| **存档** | **不进 `StoryFlag`**（现仅 11 个、已欠账 40+），另开命名空间 `minigames`，键形如 `mg-teahouse-riddle::best` | 它不参与任何进度判定，混进主表会污染幂等逻辑 |
| **AI 对弈** | **不做**。对手局也用固定局面／固定题序 | 成本与工期 |
| **美术** | **第一批只需场所内景 1 张（茶馆）**＋小游戏 UI 帧；棋摊等后续批次再算。**不占场景几何** | 控制资产量（与 §5「先只开茶馆」绑定） |
| **文件类型** | **已办**：《剧本文件规范》**v1.1** 追加 **§2.5「玩法卡」**（比「分场卡」多四栏：局面参数／评级阈值／可重玩性／主持人） | 原三层文件只覆盖叙事场次 |
| **园谱的一格（§11-4 定案）** | 园谱里**留一格「玩意儿记」**——只记**场所 + 最高品第 + 最高分**，三列封顶，**不上《蘇城全圖》界面**（守 §8 红线 7）。**它是"进度要可见"的最小兑现**，也是 A 轨唯一被允许留下的痕迹 | 世界的可见变化（对齐任务定案 §8 四类之一） |
| **白模现状** | ⚠️ 城里**还没有任何可进入的室内场所** → A 轨落地要等两件：① **城市场所表**（§5 第一批已给，仅茶馆）② **第一间茶馆的场景几何**（照 `gusu-whitebox/SCENE_GEOMETRY.md`） | 前置依赖 |

## 12. 它与主线的接口（一句话）

戏中戏**不生产任何主线资源**，它只生产两样东西：**玩家在城里的停留理由**，和**"下次还想来"**。前者救古城层的空（那是《古城层》归档后留下的最大空缺），后者是暗线之外**唯一能自发产生回访动机**的东西。

**定案后仅剩两条前置依赖**（都不是文案问题，是工程与场所问题）：

1. **城市场所表**——§5 第一批已给（**仅茶馆**），但它是本文件内的一张小表，**尚未成为独立的上位文档**（原表随《古城层》归档）；
2. **白模第一间茶馆的场景几何**——城里目前**没有一间能进的屋**（照 `gusu-whitebox/SCENE_GEOMETRY.md` 做）。

**在这两件完成之前，A 轨无法落地起测**；**B 轨不受影响**（它随各园章走，不需要城市场所）。
