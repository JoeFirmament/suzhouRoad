# 留园构图小局：三石小稿

更新：2026-10-15。入口仍是[花木作业院](../liuyuan-flower.html) → [三石小稿](../liuyuan-composition-study.html)。这是独立美学练习，不改章节旗标、六艺、实际园林场景或统一编辑器草稿。

## 本次重做

旧版把潘天寿图四七（兰叶线条交叉）和原创盆兰背景拼在一起，又让玩家切换裁切范围。这两件事没有可观察的因果关系，已从本关移除。新关不再以兰叶、盆景或取景框为解题动作。

玩家先看潘天寿《关于构图问题》图六一至六三的完整例图，再在画稿上拖动三枚不同形状的石样。小委托明示为：石形仍可分辨，近处有应、远处稍舒展。程序只反馈轮廓过度并合、间距齐整或彼此过散；满足后收稿，但不评“最美”，也不称其为原书唯一答案。鼠标拖动与方向键均可操作，撤销、重来、本地草稿续接保留。

纸上石样以留园石林为题材，不是园内固定名石的编辑器。它们不可替代、不可挪动冠云峰或其他真实石景。

## 依据

- 潘天寿：《关于构图问题》，“虚实与疏密”部分，图六一、图六二、图六三，书内第57–58页（PDF第58–59页）。原书图像从用户提供 PDF 完整提取，可点击查看；不重绘或裁切成游戏判定框。
- 本次在本地 `garden_knowledge` 文字向量库检索留园石林空间及石景，检索模式为 `local_vector_retrieval_only`，未调用外部模型。召回《园林有境》有关冠云峰与观石审美的段落，以及《图说苏州园林·门窗》有关鹤所、石林小院及相邻廊窗关系的段落。召回仅用于题材和场景方向，未把检索文字当作石头具体坐标或清末原位证明。
- 研究关没有挪用现实山石，也不声称潘书中的石组就是留园石林的实景写生。人物委托、石样与交互反馈均为原创。

完成三石小稿后进入[构图小游戏方案比较页](../liuyuan-composition-atlas.html)，而非已完成的折枝小游戏。上一版“一枝有来去”仅拖动枝条和读自动评语，缺乏游戏决策、风险与行动反馈，已退役。当前提供四种玩法方向供选择，等待用户决定后再细化和制作；共同观察图为潘天寿《关于构图问题》图二五完整例图。谢子静文章 PDF 只有文字扫描，无配图，不能把潘书图二五混作谢文原图。
