# 留园 CH3-05～06 空间与年代复核（2026-10-02）

结论：**不能把“花房”直接画在绿荫轩池边，也不能把剧本中的“南花房”理解为“中池南岸的花房”。** 盛氏确有南、北花房的回顾性记载，但它们与现有临池切片、东部四处书房之间的旧路坐标尚未核定。制作上先以“从临池区域转往北部花木作业区，再折回东部院落”的**镜头剪接**表达章节路线，禁止把剪接冒充 1890 年实测门洞。

## 对 CH3 剧本的生产约束

1. CH3-05 的“南花房”暂作为**南、北花房中的相对称谓**，不能据字面贴到中池南岸。游戏场景可是一处工作花院，但地图证据栏须标“位置概念演绎”，美术不画今天 1999 年扩建后的北花房作晚清原貌。
2. 花匠、乔老叟、乔禾及送粥关系属于叙事创作；花工与兰花作业有盛氏回顾性依据，但**没有这位花匠和这条送粥路线的史料**。
3. 未开花玉兰的尖苞可作玩家触发线索，但**玉兰必须作为地植乔木，而非盆苗**；花匠换土的盆栽是兰，二者不能混淆。墙脚单株方案也已否决。工作花院只留盆兰；玉兰视觉线索移至宅院厅堂前，以《长物志》“宜种厅事前，对列数株”的造园通则设计成对乔木，园的游赏区则用非对称植栽。此为设计语法，不等于已证留园 1890 年该厅前确有这两株。
4. CH3-06 的四个真实名称作为剧本候选可保留，但现有资料尚未证明它们在 1890 年都具相应匾额、也未证明四门可在一张院图中相邻比较。正式谜题需先补园志/历史平面，或在游戏里通过相邻院落逐次辨认，避免虚构“四门并排”。
5. 场景图与碰撞层按当前可玩的视觉候选独立校准；只记录“北部花木作业／东部厅堂”拓扑，不声称旧门位/尺寸。玩家草稿不迁移、不覆盖。
6. CH3-05 原稿“花匠脚边立玉兰／回头见它在厅堂前”与现阶段已核的花房—东部厅堂空间关系冲突，改为花匠先给“笔树”土话，CH3-06 在宅院厅前由玩家亲见成对乔木与花苞；须同步修订分场卡，不以一幅图把两区强行拼接。

## 待核资料

- 盛氏花房建成年份、南北两房在晚清平面的对应位置与残存照片。
- 从绿荫轩到北部花木区、再到还读我书斋的晚清可通路径。
- 还读我书斋、汲古得修绠、五峰仙馆、揖峰轩各匾在 1890 的存佚及方位；尤其不能仅凭现状游览图作判定。
- 玉兰、芭蕉于 1890 年留园的植位与品种。现阶段只能作为**合理演绎的线索物**。
