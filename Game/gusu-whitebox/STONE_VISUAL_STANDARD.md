# 园林石形：审美与游戏场景制作准则

石是可观看的个体，也参与构成路径、借景和遮挡；不能把所有湖石画成同一根有孔立柱。常说的“瘦、皱、漏、透”是观察湖石的一组视觉线索，不是给每块石头平均打四种特征的流水线。瘦要有挺拔或偏斜的骨势，皱要沿石理变化，漏与透须让视线真的穿过孔洞；根脚仍要稳，不画悬空的奇幻尖塔。

黄石土山、湖石叠山和单置赏石不可混成一种形制：前者可显浑厚，湖石可见空灵，独立峰石的轮廓与摆位又服务特定观赏方向。一个场景至少拉开主次、疏密、高低、正侧与虚实；小石可以扁、斜、伏、片状，不必都缩小成主峰的复制品。

## 留园石林小院 v2 的依据与边界

- 本轮实际从离线 `garden_knowledge` 文字向量检索“留园 石林小院 五峰二石 晚翠峰 段锦峰 独秀峰 太湖石 形态 方位 漏透 皱瘦 实景照片 图版”，命中曹林娣《苏州园林匾额楹联鉴赏》转引刘恕对大小石姿态的描述，以及《园林有境》对单峰和湖石山的区分；相似度仅作召回。
- [苏州市园林局《揖峰轩》](https://ylj.suzhou.gov.cn/szsylj/ylwh/201604/f5d094ab93ef489896d01e7252578d4b.shtml)转述《石林小院说》：小石有如圭、如璧、如垂英、如败蕉叶等姿态，并散在窗前砌畔、墙根坡角。这支持“不同石形与疏密关系”，不支持把当前生成图中某一石直接命名为独秀、段锦等。
- [《透园观石》研究](https://www.geores.com.cn/la/CN/abstract/article/1673-1530/78696)梳理晚翠峰与揖峰轩、洞天一碧的观石轴线及多院落空间；本游戏切片把多处压成一张可走图，**不是**原院测绘或逐块石的实景复刻。
- v2 图保持旧图的建筑、铺地与主石床位置，重新区分高而弯的主峰、较宽的屏帆石、斜立片石、低伏石和小块石。图片由内置 imagegen 基于 v1 编辑生成；作为可编辑**研究底图**，不将生成外形宣称为文物原貌。旧 `v1.png` 留存，不覆盖玩家浏览器草稿。

## 接入检查

1. 先按具体园林与院落查实景、图版、时期及观赏方向；跨园只能复用“观石方法”，不能复用具体石峰形貌。
2. 场景图面先保证人从不同角度能辨认轮廓，再校鞋底、石根、可走铺地；不要为了美术变化缩断通路。
3. 碰撞只取落地根部；高于人物的石体用单独前景遮挡轮廓和落地深度线。孔洞是图面可见空间，不等于人物可穿行的门洞。
4. 每次换图在统一编辑器核图面与 Tile、碰撞、遮挡，保留原草稿；运行 TypeScript、路线可达和石根禁行检查，再做键盘/触屏实走截图。静态检查通过不等于图像与几何逐像素吻合。
