## 为什么撤回刚才的近景候选

未入库的生成图把小门之后画成一座绿树、假山密布的多院迷宫，并在门后直接摆出大池。它只复用了「苏州园林」表面元素，没有服从留园入口的真实空间层次，也提前暴露剧本中应逐步获得的池景。生成图只留在生成记录中，不进入 `Game/assets` 或编辑器。

已有的 `liuyuan-whole-garden-study-v2.png` 现列为**旧全园误稿**：除了南侧夹弄屋顶遮住脚点，它还把西山误画成多片湖沼、把中池切碎、在北部摆出规整花圃。实景、年代与碰撞均不得据此制作。逐项对照见 [《留园场景依据核对》](LIUYUAN_REFERENCE_AUDIT.md)。

## 先定空间关系，再画像素

```text
城图／花步里街面（CH3-01～03）
  → 小门、门房与桶的检查（门位和 1890 具体形制待核）
  → 门厅及窄暗转折夹弄（CH3-04，玩家必须亲走）
  → 小天井／古木交柯、华步小筑一带的小景（相邻关系，先不钉精确门序）
  → 隔漏窗只窥园景，不给大池全景
  → 绿荫轩附近再临中部大池（独立试走切片已有；场景接口未核）
```

这里的**现状空间依据**是：[苏州市园林局《留园》](https://ylj.suzhou.gov.cn/szsylj/sjyc/201905/b7c0f2058c75498c9ecbacf234e25b08.shtml)所述中部广池、东南建筑群与曲廊；[《古木交柯》](https://ylj.suzhou.gov.cn/szsylj/ylwh/201704/350382cc43e248ad8f87243ecd5a8edb.shtml)所述粉墙与树石小景；[《绿荫轩》](https://ylj.suzhou.gov.cn/szsylj/ylwh/201808/befc4b49080d44989ca9b79439db3840.shtml)所述临水敞轩及华步小筑南庭。入口门厅、漏窗和小庭的更细次序见[《中国园林鉴赏辞典》的留园条](https://s.zhangyue.com/read?anchorId=&appId=&bid=13141115&cid=10&rentId=105712)，只作现状研究线索，不能自动推成 1890 测绘。

[留园入口空间层次教学示意](https://www.huijujiaoyu.com/sys-nd/14.html)可辨认「入口→前厅→天井→狭长曲廊→小天井→古木交柯／华步小筑→绿荫」这一条逐渐向北、最后向西折的**主通道**，不是多分叉的庭院迷宫。古木交柯前廊北墙有六扇漏窗，窗只取景、不通行；绿荫轩在西折之后。教学图**只核拓扑和收放，不核比例、年代或实际门槛尺寸**。修正后的原创简图见 [liuyuan-entrance-topology-v2.svg](../assets/scene25d/liuyuan-entrance-topology-v2.svg)；v1 保留供误差对照。

1890 年**待核**：门厅/夹弄具体转折数、宽度、每扇门位、修缮后的构件状态，以及今天补植树木对应的当年植株。[园林局《古木交柯》](https://ylj.suzhou.gov.cn/szsylj/ylwh/201704/350382cc43e248ad8f87243ecd5a8edb.shtml)说明原古柏、女贞已死、现有补植，不得把今日树形照搬到晚清。门房、送粥、验桶、花房关系是剧本演绎。

## 图像拆分与验收

1. **不再用一张鸟瞰图同时展示小门、所有转弯和完整大池。**入口做可衔接的近景切片：门外/门厅，窄廊/采光小庭，隔窗/临池。全园图只负责总体定位。
2. 每张近景先画黑白可走地面与墙、门洞；标出入口脚点、出口脚点、摄像机可见范围。按实际可用平面/照片逐点核门路；未知转折不画成史实。
3. 没到小庭时池面不出镜；漏窗阶段只给局部暗示；临池才给完整水面。玩家的空间感必须来自自己走过的距离与光/声变化，而非一张全知缩略图。
4. 墙体碰撞、门洞通行、前景屋檐遮挡、水面禁行分物件制作。主路径全程留出符合书生脚底盒的连续地面；屋顶若遮脚点，就须独立成前景层或重画底图，不能直接把该处标可走。
5. 风格沿府学与全园图的低饱和像素体系；不要高密度「万物皆景」式装饰。CH3-04 的任务道具只留玩家手中粥桶与门房演出相关物件，不添加旅游牌、收费设施或无关 NPC。
6. 新图进入编辑器前，必须附参考平面/照片的来源、取景方向、与全园图的入口/出口对应关系、哪些是 1890 可核事实、哪些是玩法化连接。没有这些就只标为视觉试稿。
