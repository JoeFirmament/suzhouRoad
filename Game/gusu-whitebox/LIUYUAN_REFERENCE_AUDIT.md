## 入口白模 v2 与美术画面门槛

白模 v2 只把**已查清的现状顺序**编码为 Tile：南入 → 前厅和采光小庭 → 暗曲廊 → 第二小庭 → 短廊 → 古木交柯 → 在北侧实墙的六扇漏窗前看 → 向西折至绿荫轩方向。漏窗已设为不可走墙面；池园仍封闭。它不宣称具体转弯数、实际宽度或 1890 游客路径。

真正画近景前，至少补齐三组同向参照：①入口外向内的门/墙/地照片及方位；②第一小庭、曲廊、第二小庭逐段的正反向照片；③古木交柯北墙六窗、向西到绿荫轩的照片与俯视平面能互相对上。每张还需标出哪些材质/匾额属于修复或补植。完成这些之后，才做低饱和 2.5D 像素切片与前景檐层，不生成一幅“万景齐集”的整园图。
