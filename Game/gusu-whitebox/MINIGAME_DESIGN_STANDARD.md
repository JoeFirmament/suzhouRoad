# 《姑苏九园》短玩法设计准则

> 2026-10-12 用户确认：[六艺操作与奖励定案](../姑苏九园-六艺操作与奖励定案.md) 为当前奖励口径：按实际操作增加六艺属性，首次达标结算、防重复刷取；NPC 服务故事，可选游戏不作为主线通行检查。以下旧稿若与此冲突，以新定案为准。

目标不是复制《三角符文》的战斗、美术或弹幕，而是借鉴其短回合、读规则、即时反馈、失手可再来的节奏，把“观察园林”变成玩家亲手完成的动作。

## 放置位置

- 先有人物、差事或物件提出问题，再进入 20～60 秒的短玩法；不能用小游戏取代人物推动的 RPG 行走与对话。
- 题目必须依赖该园林这一处的可核元素，例如某窗后的植物、某段铺地纹样或匾额的字形；跨园常见纹样不能冒称该园独有。
- 园林外观、方位、年代各写证据；纸条、暗号、节奏与挑战目标明确标为游戏创作。缺少旧图/门位时只作独立研究小样，不发六艺、不改章节存档。
- 每章至少有“看懂规则→执行→应用线索”三步，不能把认花窗做成一次选择题；但并非每次观察都强塞计时关。

## 难度与可玩性

**已认可的留园基准（2026-10-14）**：玩家认可v36“檐下抢画”的捡画→雨缝走位/猫影侧移、3HP、18秒三段、五次固定扑向、.6秒受击保护与现有四向手感。声画精修、音效或界面整理不附带偷偷调整速度、判定、预告和奖励；用户明确提出新的玩法/难度修改时，再单列参数变更并重测。音效可选、默认静音，由玩家手势开启，暂停/失焦/退出停声；视觉提示必须独立完整，不能靠声音才能通关。声音观察与绘制只读模拟，失败降级不能打断RAF或输入。[当前规则与测试](LIUYUAN_FLOWER_DRAWING_EVENT.md)。下方六折入口描述保留为历史，不是当前正式章接入。

1. 第一遍让玩家从场景或 NPC 的话里学到规则，不弹导游式说明卡。错误反馈指出遗漏的观察，而非只说“错了”。
2. 难度主要来自辨识、空间记忆、顺序与短时操作的组合；单次操作节奏不超过几秒。失败只重试当前小回合，已发现的史实线索与场景进度不回滚。
3. 键盘与触屏等价；提供慢速／宽判定或无时限替代。操作中可退出再进，重复结算不得刷六艺。若某谜题阻断主线，必须允许经过观察再试，而非靠毫无提示的反应速度。
4. 每个小游戏交付时检查：图面/人物比例、交互可达性、判定边界、错误重试、辅助模式、读档幂等和证据标注；静态测试不替代实际画面与触屏验收。
5. **压力须渐进且可读**：先给宽裕预告和清楚来向，之后改变观察轴、收窄操作余地，最后才组合已教过的规则。参数集中在阶段/波次表，HUD 和画面同步显示变化；不能只缩短时间、增扣血，或靠隐形判定制造难度。至少验证一条观察后能走通的路线与“原地等/长按防护”的反例；慢速档保留学习顺序，不偷偷取消后段。留园 v33 的[辨雨—换向—交雨](LIUYUAN_FLOWER_DRAWING_EVENT.md)为当前样例，各园不机械复制它的动作。

## 第一件可玩样本：留园三窗辨影

2026-10-12 增补：**按园林特征选择不同动作，不把静态拼装或同一计时条到处换皮。**网师园射鸭廊登记为动态瞄准候选；留园入口撤下扶灯骨，接可跳过的[穿廊借影](LIUYUAN_RAIN_SHADOW_GAME.md)：猫拨落练习画稿→走近自动捡画→独立计时的雨缝走位／短时护画，六折，失败只重试当前折，缓雨档保留前折。目标必须有动作动机与阶段反馈；金色画稿代表可拾道具，青色虚线及标字代表下一阵雨的有效缺口，明确“亮处不挡雨”。不能把到达／拾物误称为记忆题。风元素另留其他园林的不同动作候选，不在留园同时叠两套拨画缘由。猫与画稿均标游戏创作，不增六艺，不把练习当章通关。以下三窗辨影仍为独立研究，不因新入口玩法而自动晋级。

独立研究页 [三窗辨影](liuyuan-window-study.html) 先让玩家走到三扇窗前，比较中扁八角／两侧六角及东竹西蕉；在西侧选择正确的阔叶后，进入原创“纸角对影”三拍短挑战。游标进入目标带时按空格或触屏“记在纸上”；失手只重试三拍，不重走三窗。慢速／宽判定默认响应系统的减少动态效果设置，Esc 或触屏“放下纸角”可退出，重进仍保留三窗观察。该节奏装置与纸角线索是虚构，不对应清末留园的真实机关。研究页不写 CH3 旗标。

之后的章节避免机械复用“三拍条”：铺地可做步序／回看式空间记忆，昆曲可做听句与入场时机，匾额可做字义与场景行动的关联。各题仍要先过本园的图案和年代证据关，再接正式场景。

## 构图型短玩法：摆放、框景、修枝

参考[章节可玩性验收标准](CHAPTER_PLAYABILITY_STANDARD.md)中的《**关于构图问题**》转译：先由人物提出具体差事，再让玩家试摆可移动小品、改变自己的观景脚点，或在花房研究用植株上选择有限的修枝方案。关卡反馈说清“遮住了什么、显出了什么、枝叶是否仍健康”，而不是宣布一个神秘的构图分数。不同审美方案可有不同风味，成功条件应来自可观察的视线、通行与植物约束，并允许撤销、比较、重试。

**直接教学书中具体构图的规则**：若目标是教玩家理解《**关于构图问题**》中的某个具体例法，必须展示书中完整例图，并标明作者、图号／页码、书名及来源；让玩家先观察例图，再在游戏场景里尝试相应的组织关系。生成的园林场景、裁切图或程序阈值不能冒充书中范例，也不能把“本关判定通过”说成中国画构图的普遍标准。原创园中构图委托应先讲清实际目的和可见约束；除非明确要求临摹某个已标注范例，否则应允许多个能完成委托的构图，并说明它们在主次、开合、虚实上的不同效果。唯一解只能来自玩家看得见、能复核的具体任务条件，不能由隐藏比例替审美作裁决。

真实园林的固定门窗、名石、古树及既有布局不作为任意摆放棋子；修枝关在树种、季节和可修剪部位未经园艺资料核准前仅作观察/摆放研究，不进入正式剧情结算。此类关卡也须提供键盘与触屏等价操作、慢速或无时限替代，并在统一场景编辑器里验证人物脚点、遮挡与操作前后的取景。

当前[一盆兰 · 兰谱留题](liuyuan-composition-study.html)从花木作业院进入。玩家先看潘天寿《关于构图问题》图四七的完整例图及出处，可展开图四八、四九对照；再为花匠选一页兰谱。玩法明确是“切换左右与远近取景→至少比较两幅→选当前画幅交画”，不是搬动兰盆或让角色行走；界面解释“题识”就是题名、落款。委托要求兰叶与花盆完整、右侧留得下题字空处；借门作框、放宽全景与收近小景均可交成，反馈解释各自取舍，不设唯一美学答案。练习图里的盆兰是正常、合理的园林小品，不要求证明某个历史原位；同图裁切也明确不是实际走位或视差。不改编辑器几何草稿，也不写 CH3 旗标。

> 维护状态：已按“完整书例先行—标明出处—玩家观察—原创委托多解”的规则更新。程序只核验委托明示的主体完整和题识留白，不替潘书设标准答案；旧版未看过书例的完成存档会先提示玩家查看原图。

[花匠画谱](liuyuan-composition-atlas.html)原先承载了完整图例辨认与拖枝看评语；该页构图子游戏已退役，现用于比较四种新玩法，待用户选择后再进入原型制作。潘天寿图二五完整例图与谢子静折枝画文字文章分开标注，不以游戏结果代替构图知识。

**场景接入规则**：此类练习要由园中人物与眼前物件提出，不把独立研究页当成任务入口。留园样例的主线可为“交粥→与花匠相识→获空白兰谱→比较并交画→花匠翻开画谱→构图互动（玩法待用户选择）→回花木院”；玩家可在研究模式独立试玩，但主线不靠研究关自动推进。未满足某一步的条件时，不展示下一步的剧情按钮；直接打开研究页不等于获得章旗标或六艺奖励。

**中断与续玩**：多页研究关至少保存已答页和当前操作参数，重载时重新用本题规则校验“已完成”，不能只信浏览器里的布尔值；给玩家明确的重新练习入口。练习记录与正式章节存档、编辑器草稿分开，章节／独立研究也分开，防止研究小样替正式任务通关。存储被禁时仍应允许当前页试玩，并明示离开后可能失去进度。

旧折枝拖动页已撤下，不作为当前制作目标。下一版须先选定玩法类型，再把构图选择落实为玩家能亲自感受到的危险形状、通路、视线遮挡、可用行动或运笔操作；更多方案见[留园构图小游戏玩法提案](LIUYUAN_COMPOSITION_GAME_OPTIONS.md)。
