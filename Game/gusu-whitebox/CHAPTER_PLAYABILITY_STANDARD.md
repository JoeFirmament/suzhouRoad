# 《姑苏九园》章节可玩性验收标准

> 2026-10-09 留园进度说明：CH3-09 题叶与 CH3-10 空桶返程已接成明确标注的当代拓扑游戏章流；下方旧“尚未结算”的逐幕表是早期检查记录。新增书斋院/内景中途刷新恢复已提交的叩门与人物事件。**仍须从空白进度按键盘和触屏各完整实走一次，并在书斋处刷新，才能验收本章。**静态状态链与几何通过不能替代图面、美术、历史位置和操作体验。

> 2026-10-08 起用于每一幕；“走得通”只是底线，不能代替“想继续玩”。与 [短玩法准则](MINIGAME_DESIGN_STANDARD.md)、[统一场景编辑器交接](SCENE_EDITOR_HANDOFF.md) 并行。

## 一幕必须有的玩家回路

1. **牵引**：一个人物有眼前的需求，或一件物有可见的异常。玩家应能用自己的话说出“我想弄明白／帮他做什么”，而不是复述任务卡。
2. **亲手做**：至少一个与此地有关的主动词——走到、绕过、看两次、试写、辨纹、送物、记路。不能只连续按“下一句”便过关；也不把每幕都做成同型小测验。
3. **可读反馈**：操作之后，画面、道具、人物姿态、声音或一句短对白发生可察觉的变化。错误反馈要指出遗漏的观察；失败只重试本地小回合，不清除已经理解的线索。
4. **留下后果**：本幕发现的物件、话或路线能在下一幕被使用或重新理解；同一发现和六艺奖励不可重复刷。
5. **收束与钩子**：离开时保留一个具体问题或行动方向，不用全知箭头替玩家解释故事。
6. **审美发现**：玩家因亲自走动、停留或取景，发现一个起初未察觉的空间关系，并能说出它带来的感受；文化知识随这一发现生长，不以背术语、答常识题代替体验。

美术与文字共同承担上述回路：像素尺度、人物脚点、可走地面、触碰反馈、对白停顿和场景音乐均应服务动作。花窗、铺地、匾额、植物只在查明该园实例、部位与年代后承担“唯一正确答案”；剧情虚构道具另作标注。短玩法可以借鉴《三角符文》式的读规则、短回合、失手可再来，但不照搬战斗或弹幕。

## 中华文化与中式美学的验收

这款游戏的文化升华，不是把园林改成知识展板，而是让学子从“认得物”走到“看见关系”，再形成自己的审美判断：为什么此处要隔窗看、绕水走、在匾额下停步？玩家可以先感到美，之后才知道它与诗、书、画、园及人物处境有什么联系。每章至少完成一次这样的递进，不规定所有人得出同一句感想。

### 构图参考与边界

- 直接参考用户提供的潘天寿著《**关于构图问题**》（浙江出版集团数字传媒有限公司 2017 年电子版；版权页所列纸本：浙江人民美术出版社 2015 年 10 月，ISBN 9787534045707）。本书“开合”章从画面的起、承、转、结及大开合中的小起结讨论布局（书内第 12—13 页）；“虚实与疏密”章明确区分**画材与空白的关系**和**画材、线条之间的排列距离与交叉**（第 40—43 页），并讨论节奏要有规律也有变化（第 49 页）。据此观察场景的取舍、主次、开合、虚实和疏密，而非把名词写在 UI 上要求玩家点选。这里的页码按电子书页脚，PDF 查看器页码比它多 1。
- **项目转译，不是原书原话**：将“大开合中有小起结”用于章节与行走节奏——一章有进入、发现、转折、收束，一段回廊或窗前也可以有自己的短暂开合；将“虚实”和“疏密”分别用于空白与主体的对照、花窗或植物等要素的间距变化。不能把两者合并成“画面空处越多越疏”的一条公式，更不能让所有园林套同一构图模板。
- 借的是**观看与组织画面的思路**，不是把潘天寿个人画风照搬成晚清苏州园林的史实，也不把中国画构图法误说成某一园林的原始设计图。园林可进入、可回望，画幅相对固定；游戏须让玩家在“平江图 → 园林图 → 近景图”间移动，经历藏与露、收与放，而不是只看一张正视插画。
- “气韵”是本项目进一步的美育目标，不冒称《**关于构图问题**》为它给出了可量化定义。它不设单一数值或标准答案；用步速、人物停顿、风与水声、近远景层次、留白和转场连续性，使一段路有可感的呼吸。精致不等于不断填满画面或提高饱和度。镜头和美术若只在静帧里好看、行走时节奏破碎，不能通过验收。

### 把构图用于场景，而不只用于讲解

| 用途 | 玩家实际看到或做什么 | 制作与验收重点 |
|---|---|---|
| 园林小品设置 | 在已核实的建筑、山水、树木关系中，安排可移动的盆景、几案、供花等小品；换位置后，主体与陪衬、空处与密处随之变化。 | 先确认该园、该处、所选时期的固定格局与植物习性；固定古迹、名石和古树不能因“构图更好”而任意挪动。记录小品从主要行走视角及次要视角的效果，也要检查通行、遮挡和人物比例。 |
| 框景构图 | 玩家沿廊或窗前移动脚点：一处树枝遮住远景，退半步露出水面或题额；前、中、后景重新组合。 | 窗形、纹样及朝向须有该园证据；不可挪窗迁景来凑题。验收同一真实窗洞的多个可走脚点、视线和前景遮挡，不只验收一张宣传式静帧。 |
| 构图益智 | 人物提出眼前差事，玩家试摆**可移动**的小品，或在花房的研究用植株上选择有限的修枝方案；看景、操作、回望，理解为何此方案让重点显出、空间有呼吸。 | 选择有撤销和比较，反馈指出可观察的原因；不设仅凭审美口味猜出的唯一答案。植物关必须同时检查树种、季节、健康及可修剪部位，不能以“露出谜底”为由乱剪真实古树。 |

第一步的[留园三石小稿](liuyuan-composition-study.html)是独立研究关，替换了此前与图四七无关的盆兰裁切题。玩家先看潘天寿《关于构图问题》图六一至六三完整例图，再在纸上拖动三枚不同石样；本关明示条件是石形可辨且疏密有变化。代码只反馈过度并合、间距齐整或过散，不判断“最美答案”。真实留园名石完全不参与操作。跨园关卡的内容、来源、实际动作和待核边界列于[构图小游戏系列设计](COMPOSITION_GAME_SERIES_DESIGN.md)。

另有谢子静《宋代折枝花鸟画的构图程式》（《新美术》2007年第5期，页93–98）可为枝势小游戏提供另一套来源：文章讲解一波三折、三线相辅、V字、对角线、边角及四周凌空等程式。用户提供的 PDF 是正文扫描，未附画作图版；须把文章观点和潘书完整画例分开引用。“一波三折”转成枝势观察，不可让屏幕节点数、角度阈值冒充画论标准。折枝关应让玩家实际调整枝势、花簇与空处，允许玩家保留不同方案，并由具体文字反馈帮助比较，不用取景框加程序阈值冒充美学结论。

### 每章必须留下的可验证体验

1. **地方性事实**：至少一个真实、定位明确的园林元素进入任务或取景；记录来源、部位、可适用年代、现状与剧情虚构部分。花窗、铺地、匾额的通用纹样不能冒充该园独有证据。先查本地向量库原文和图版，再作实景、平面及年代复核。
2. **玩家亲自发现的构图关系**：至少一处从不同脚点、窗洞或回廊看去确有变化的画面；可涉及主次、虚实、疏密、借景、框景或前后遮挡，但需用实际可走的空间、镜头与碰撞层实现。站定与移动后的两张截图、脚点及遮挡结果一起验收。
   若本章设置摆放或修枝关，还须记录操作前后及撤销后的画面、植株/物件约束、至少一种可解释的成功方案和失败反馈；不能只用隐藏的像素坐标判“好看”。
3. **由看见到会用**：玩家观察所得须帮助其作一次行动判断、辨认线索、理解人物或重看旧景，而非只弹出百科词条。先允许直觉与误读，再由物证、对白或再访使理解加深；错误不会惩罚好奇心。
4. **有余味的表达**：章末可让玩家选一处愿意再看的景、给园谱留一句题记或保存一幅亲自取的景。提示开放，不以“说出正确审美术语”评分；题记应回应本章人物和经历，而非空泛抒情。
5. **试玩复述**：不先教“虚实”“气韵”等词，询问试玩者“你在哪里停了一下？换个位置后看见了什么？为何还想往前走？”如果只能复述知识卡、无法说出一次亲身观察与其情绪/行动后果，本章文化与美育验收未通过。

留园章可先以小庭隔窗所见、临池后的回望作为“藏—露”候选；只有视线、门位与历史材料核实后，才可把它定为该园的真实构图事实。故事设计亦应区分“玩家从场景中感受的美学关系”和“角色在时代内可能说出的话”，不要让晚清人物突然讲现代美术教材。

## 可玩性验收，不以静态检查冒充实走

- 键盘、触屏各从**空白进度**走一次：人物/物件靠近、对白选项、错误重试、转场、返回均可完成；所有可见选项有键盘等价操作。
- 至少在一处中途刷新：角色可以从当前章状态重新接续，不必重做已结算奖励；复走不得重复给六艺。
- 对话、字幕、状态文字出现与消失时，触屏方向键**不能移到别的按钮下**，尤其不能误点重置；390×844 窄屏也须让关键字幕与当下操作同屏或可自然滚动。
- 以统一编辑器草稿预览时只读取、绝不覆盖玩家草稿；研究剪接和正式章流在界面与存档上分开。
- 验收记录要列真实浏览器脚点/操作、画面问题和历史未决项。`tsc`、状态机和几何测试通过仍不是“完整可玩”。

下一个内容制作优先级不是再多画一张孤立园景，而是让花匠的“笔树”线索在**有证据支持的东园玉兰观察点**变成玩家亲手完成的判断，再把寒士的处境引向题叶；史证未到位时先做明确标注的研究试验。
