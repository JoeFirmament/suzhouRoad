# 留园 CH3 入口：正式镜头边界与玩法作用

> 2026-10-10。服务于 `liuyuan-entry.html` 的下一轮换装，**不是**新关卡，也不是 1890 年入口复原图。独立 `liuyuan-alley-misty-study.html` 只留作脚点、色板和遮挡研究；不能因已进统一编辑器就插入章流。玩家现有浏览器几何草稿不迁移、不覆盖。

## 为什么要有这一段

入口不是为增加一段可走距离，而是把城中学子带入留园：在门外因为乔老叟的粥桶接下一件具体的差事；经乔禾提示，向门房说明来意；从街上的人声、较亮的门厅，亲脚走进逼仄而有采光变化的廊道；到古木交柯小庭才第一次窥见园中层次，再往绿荫轩见水。返程时玩家拿着已经轻了的桶逆行，经同一门房应答，走到街面才算真正出园。缺少这条因果链，夹弄图就没有独立游戏意义。

## 2026-10-11 增量：入口先要好玩

**2026-10-12 替换说明**：下述扶灯骨是已撤下的历史迭代。现由门房引出可跳过的动态“穿廊借影”，三折移动/读预警/护笺，失败只重试本折。正常送粥放行和验桶因果不变，练习入口不写进度。当前实现、检索和实玩证据以[新玩法记录](LIUYUAN_RAIN_SHADOW_GAME.md)为准，不再扩建旧拼装。

玩家明确允许适度游戏化，不要求每件小道具都可证明为旧时原物。**让虚构发生在人物、可移动物件和短小行为中；不能反过来伪造园林门位、建筑、古树或标志纹样。**门房修灯笼本来已在 CH3 人物对白里。可跳过的“扶灯骨”现为短小空间操作：说明送粥来意后，先在三根不同弧度的竹篾中选形；玩家看两端接头，用方向键／触屏按钮平移与转角，也可在灯上左右拖动；试扶稳时根据形状、左右错位或转角得到不同反馈，真正两端接住才完成。跳过仍照常入园，错误可重试。扶灯不是通行许可的史实、不是新六艺奖励或新的硬门槛，只让门房在放行和返程时记住这位书生。对白、原门槛触发、夹弄路点和出园结算未变。已有存档可单独回看；回看不会给存档添旗标或重置章节。它是游戏中的可移动手持灯，不是留园原位悬挂物。

本次再以本地 `garden_knowledge` 离线检索“留园清末入口门房灯笼提梁竹篾修灯”及原位反证。召回《园林有境》关于园林张灯多为临时悬挂、张后移藏的论述，但没有留园此侧门、此门房或竹篾灯骨的同期图版；《图说苏州园林·门窗》的“灯笼纹窗棂”是另一种构件，不能充作手持灯史料。因此只保留人物虚构行为，不在底图增加固定灯饰，也不把选形答案解释成留园独有知识。

入口下一轮美术可给玩家三个可观察而非讲解的点：门外乔老叟的担子与乔禾、门房手上半成的灯、门内第一口天光。纸灯和粥桶分别随人物/物件层绘制，不烘焙到场景底图；不能在图上又画出第二只灯或第二个桶。画面从街面留一块干净地给角色及对白，到门檐变窄，再在内庭放开。植物只用**一株有形态差异的主树剪影＋一处低矮阔叶/墙隅次景**作为游戏化构图候选，保留空墙、可行走石地和门洞负形；不以桂、玉兰、竹等物种堆砌“园林感”，没有本院证据就不实名、不标原位。若章节季节尚未定，不能以桂香、玉兰花、黄叶同时作为必经线索。

当前正式入口仍是 1008×688 可走白模。新 1536×1024 [斜俯视入口 v2](../research-art/liuyuan-entry-oblique-artstyle-candidate-v2.png)和 [v3](../research-art/liuyuan-entry-oblique-artstyle-candidate-v3.png)只是**未获画风批准的研究候选**：v3 去掉额外右门，但仍屋顶占比过大、墙后泛化灌木和同形树冠过多、石路像无差别网格，书生脚点、门槛与旧研究图路线未重新标定。后续[低机位研究页](liuyuan-entry-lower-camera-study.html?draft=1)在独立 ID 下接了首镜 Tile、门柱碰撞与人物比例样片，静态路线检查通过；但细碎绘画纹理、植栽和邻镜接口仍待核，浏览器对当前 `file://` 页限制访问，尚不能算目视实走通过。因此以上图均不替换 `liuyuan-entry.html`、不载入原编辑器 ID、不固定通用提示词，也不把它们算作已完成的入口美术。过程与检索见[斜俯视记录](../research-art/liuyuan-entry-oblique-artstyle-candidates.md)和[低机位记录](../research-art/liuyuan-entry-lower-camera-gameplay-candidate-v1.prompt.md)。

## 证据账与边界

- 本轮离线查询：`garden_knowledge`，问题“留园入口 门厅小院 曲廊 天井 古木交柯 绿荫轩 现状空间顺序及反证”。前五条均为《园林有境》的园林空间泛论／局部照片文本，没有旧入口门位、转角尺寸或具体铺地原位；不能凭 0.68 左右的相似度定地图。
- [苏州市园林局《留园》](https://ylj.suzhou.gov.cn/szsylj/sjyc/201905/b7c0f2058c75498c9ecbacf234e25b08.shtml)只支持园内院落通过门洞、长廊沟通，以及中部池园的大关系，不证明小门、乔禾、门房或 1890 年夹弄。
- [张钰《批判性地域主义视角下的中西方景观地域文化》2024，52–53 页](https://pdf.hanspub.org/Design20240100000_40977282.pdf)的现状入口文字分析描述“小院放—狭长曲廊收—天井再放—窄直通道再收—古木交柯—绿荫轩”的感受顺序。其图 1 是现状入口研究平面，**本轮只读到 PDF 正文，图版截图接口报错，未视觉核图**；不得据此判定转角左右、门洞数量、比例或旧貌。文中提到的现状砖额亦不得直接放到清末游戏镜头。
- [孙旻恺等《基于视觉感知的留园入口空间序列研究》](https://www.gardenmagazine.cn/ylzz/article/html/20250810001)核到期刊全文和图 1：2023 年现状实验路线从门厅口经古木交柯、连续漏窗、华步小筑至绿荫轩，约 50 m；28 组有效的 VR 观看数据支持入口对主景视觉注意和序列感知的影响，但主观游览体验/情绪差异无显著性。这是镜头假设的依据，**不是**游戏乐趣实测、1890 门位或 Tile 比例。其他三篇用户提供的空间/石林论文、年代分歧与转化见[专项核读](LIUYUAN_NEW_PAPERS_2026-10-10.md)。
- 入口小门送粥、乔禾、门房和桶是 CH3 故事演绎；六扇漏窗是现状可查的取景关系，具体纹样和清末存貌未核。现有 `liuyuan-entry-study.ts` 的 63×43 Tile 坐标是可走白模，不是测绘。

## 按正式章流制作，不新增匿名走廊关

| 镜头/现有区域 | 必须让玩家做的事及下一幕后果 | 画面必须承担的体验 | 制作和禁区 |
|---|---|---|---|
| 门外与小门（`street-approach` → `front-hall`） | 乔老叟交桶；乔禾指门；门房先挡，玩家借已听到的“花房老主顾”应答后才得入内。 | 城街亮、门内暗；人物、担子和门槛在同一角色比例下看得清。 | 只表现游戏小门，不标作已核清末侧门；禁对称现代景观花池、旅游牌和外河。门柱前景只遮住躯干，不吞脚点。 |
| 前厅与采光小庭（`first-light-well`） | 玩家亲走，桶随角色；无说明卡、无额外 NPC 或“问答门槛”。 | 从阴影入一口天光，有树影/粉墙的浅变化，给首次“放”一息空间。 | 不把研究图单独切成关卡；庭内植物和铺地须另核原位，未核时只用克制灰石候选。 |
| 曲廊、折角和第二天井（`long-south-corridor` → `north-narrow-corridor`） | 通过行走、转向和环境声记住路；返程原路再走，形成玩家自己的方向记忆。 | 墙压近、视野缩窄，转弯的采光让方向可读；背后城声减弱，前方园声渐近。 | 只保留服务节奏和真实拓扑的折角；不以重复墙面/栏杆填时长，不凭现有 Tile 像素数宣称真实长度。复杂前景遮挡须在统一编辑器调脚点、柱脚和落地线。 |
| 古木交柯小庭与西折出口（`ancient-tree-court` → `green-shade-threshold`） | 玩家歇一下桶，再提起、进小庭；先隔窗感到园内层次，随后继续走到绿荫轩临池，不能在窗前直接跳到全池。 | 从“收”转“放”，树、石、粉墙、漏窗组成近景；池水直到下一幕才完整出现。临池停步时以可亭/连廊、植物、倒影组织第一次主景视线，供玩家试玩检验。 | 当代补植树形不冒充旧树；窗是北墙的取景孔，不是门。西折出口要与小庭/临池实际可走接口逐像素校对。论文的 ~50 m 不换算现有 Tile。 |

## 换装验收

1. 先给以上四段画同一逻辑像素密度、同一斜俯视机位、同一书生脚点比例的**无烘焙角色**分层底图；连续并排看“粉墙黛瓦、灰石、克制植物色、烟雨空气感”，不允许首段精细绘画、第二段粗像素、第三段白模。
2. 将分层底图对应到现有 `liuyuan-entrance-topology-study` 的统一编辑器；不改 ID、不覆盖用户草稿。相机裁切需要新 ID 时，先写清楚进出接口和草稿迁移方案，再晋级。
3. 铺地按入口、天井、廊道不同空间审视石板／弹石／花街的可能性；目前没有入口花街原位证据，不能借全园图版强行满铺或做唯一谜底。
4. 在 `?debug=geometry&draft=1` 检查每个门槛、廊柱、墙角、漏窗禁行、天井边界、桶的层级；键盘连续行走和实体触屏各往返一次，旧草稿与空草稿各一次。玩家能从门外走到小庭，题叶后反向走到街面，门房应答前不能结算。
5. 美术、几何、叙事三项均通过才替换正式入口底图；独立研究图若只提供色板/脚点参考，就停在研究目录，不将“能走”计为章节完成。
