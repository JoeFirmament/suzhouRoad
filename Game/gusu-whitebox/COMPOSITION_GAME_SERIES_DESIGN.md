# 园林构图小游戏系列：从看画到亲手组织

状态：2026-10-16。目标不是把画论变成术语问答，而是让玩家做出一件事，立即看见空间关系如何改变。小游戏可借不同园林的叙事、场景和物件切入；每关有自己的操作与约束，不把同一种“找最佳构图”套给九园。跨园主线中，各园提供不可替代的分段线索，回到府学后才合读；不能让任何一个园林独自包办全部发现与结论。

## 制作规矩

1. **原例与练习分层。** 先展示完整图例、图号和书页来源；玩家随后操作自己的练习稿。程序生成或园林像素画不能冒充原书图例，更不能说成书里的标准答案。
2. **动作必须对应所学。** 学疏密就移动石样、看石形和间隔；学开合就走过有起伏的路线、体会视线如何承接和转折；学折枝就组织枝势与花簇。若例图与玩法之间需要一段长解释才能建立联系，说明玩法还没选对。
3. **观察具体，审美判断开放。** 可提示“石形是否并合”“枝势是否过直”“花意聚散如何”，不可把隐藏角度、节点数或距离包装成美学标准。审阅只提供观察意见，不拦截玩家收稿；是否满意由玩家自己决定。
4. **园林实物不当棋子。** 玩家挪动的应是稿纸上的石样、枝叶、印蜕或可移动园艺小品；不得挪动冠云峰、古树、建筑、原位铺地。真实场景只在资料定位、时期和碰撞均核过之后开放行走互动。
5. **从游戏中长出知识。** 操作前先让玩家自己看；反馈先说“哪两石并成一团”“哪一段路转得太直”，再附上“疏密／转折”名称。不给惩罚好奇心的倒计时，也不以背术语过关。
6. **来源并排，不混用。** 潘天寿《关于构图问题》与谢子静《宋代折枝花鸟画的构图程式》各自标注。第二篇用户提供的扫描 PDF 只有六页正文（《新美术》2007年第5期，总第28卷，页93–98），没有附画作图版；文章中提到的作品不能用程序图代替并冒称“原例”。若展示潘书图二五，要标为另一来源的比较例。

## 折枝与构图玩法的设计边界（独立于潘书）

谢子静文章不是一本配有原作插图的画册，而是对宋代折枝花鸟画程式的文字归纳。可转化的练习条件有：

- **一波三折**：主枝的势先起后转，再向旁展开；花叶顺着主次枝分布，避免只剩一根平直棍子。
- **三线相辅**：主枝与两组辅助枝有长短、轻重、疏密之分，不平均切分画面。
- **V字形**：两向枝势打开，利用枝势夹出的空间；让花簇、禽鸟与空处彼此照应。
- **对角线／边角**：画面重心偏置但要有呼应；边角入画不是把物件随便裁断，而是要让枝势接入画外、在画内有所承接。
- **四周凌空**：画面主体可从枝叶中独立显出，疏朗不等于孤零零地散落。

上面的文字仅是潜在的观察素材，不能据此沿用上一版的拖枝看评语玩法——该版本已退役，原因是操作只是摆点与读评语，没有足够的游戏决策、风险和行动反馈。当前样机把“玩法变化”与“故事连续”同时保留：A 单独测试躲避；B/C/D 分别发生在不同园林，可任意顺序游历，且各自只给主线一段必要残记；进入章节和取得线索时，旁批会把已知拓片与新发现并置；E 回到府学后，玩家须亲手依次点选三张拓片，能撤回、清空，错序时读到反证再重排。这里校验的是虚构手记的阅读次序，不是园林审美的唯一答案。这样既不是同一园林里搜完即结案，也不是三个互不相关的小故事。不同节点仍有不同核心动词；多个审美方案都可以成立，不能让程序阈值充当画论标准。详见[玩法提案](LIUYUAN_COMPOSITION_GAME_OPTIONS.md)和[跨园林可试玩样机](liuyuan-composition-playtest.html)。

## 验收

- 玩家不看教程，能通过“拖哪一个、想看什么变化、怎样才算本次委托完成”开始玩；桌面鼠标与键盘、触屏均可操作。
- 每种错法都有不同、具体的反馈；撤销可恢复；刷新不丢本机练习进度。
- 原书例图完整、来源清楚；小屏不压缩到看不清；研究关不污染地图编辑器草稿或章节奖励。
- 玩家试玩后能用自己的话说出“哪两块石靠近后仍然分得开”或“枝怎样转势”，而不是只会复述术语。
- `tsc`/打包通过只证明工程可构建；真实浏览器、触控、可读性和游戏节奏必须另行试玩验收。
