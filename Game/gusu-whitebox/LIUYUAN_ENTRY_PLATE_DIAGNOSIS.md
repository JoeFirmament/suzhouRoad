# 留园入口 · 可走底图重制：诊断与开工规格

> **v0.1（2026-10-20）** · 状态：**底图尚未重制完成**。本轮交付＝对位工具 ＋ 灰模 ＋ 路线判断；正式美术待一次独立绘制／生图。
> 结论一句话：**入口不是"画得不够细"，是"投影方向与游线轴"打架。**

---

## 0. 先说结论

现行 `liuyuan-entrance-walkable-study-v2.svg` 读起来像"平面图上贴了几张立面"，原因不在细节量，而在三件事叠在一起：

1. **入口主脊是南北向的**（12 个脚点里 8 个在 x≈520／430 的纵向轴上）。
2. **本作已被验证的 2.5D 语言是东西向的**（沧浪亭复廊：屋顶—白墙—漏窗—柱列，全部朝南）。
3. **正俯视相机**下，南北向的墙只能看到屋顶和一条窄边；硬把朝南立面贴上去，就必然与地面脱节。

所以本轮没有继续"加细节"，而是先把**画什么、画在哪**变成可交付的坐标稿。

## 2. 为什么 v2 读起来是"平面图"

| 症状 | 成因 |
|---|---|
| 大面积空白 | 四块巨形 `url(#wall)` 平铺，无高度、无投影、无材质变化 |
| 立面像贴纸 | 朝南立面被画在南北向的墙体上，与地面无共同灭点 |
| 屋顶像色带 | 屋顶是水平矩形带，没有坡面、檐口厚度和落影 |
| 路径不像路 | 铺地与墙身明度、纹理太接近；墙脚无影，脚踩不实 |
| 尺度感丢失 | 窗、门、人的比例各自成立，但缺少同一套高度基准 |

> 这不是"像素密度不够"，是**空间语法不统一**。继续在 v2 上加窗、加砖、加纹理，只会让贴纸更精致。

## 3. 三条路线（含代价）

### A. 鸟瞰剖切（本轮建议）

**做法**：整张画布先铺黛瓦屋顶 → 把可走区"切"出来 → 可走区边缘加**粉墙压顶**（22px 墙带 + 4px 压顶 + 10px 墙脚影）→ 只在真正朝南的墙面画立面（六窗墙、门屋、南端街屋）→ 天井加光、夹弄压暗。

- **优点**：不改任何坐标、Tile、相机、剧情与回归；灰模已证明脚点全部落在铺地上（构造保证）。
- **代价**：需要一次真正的美术 pass（屋顶坡面、墙体材质、植栽、光）。
- **风险**：四向侧视精灵在鸟瞰下仍可用（Stardew 惯例），但需要人眼确认"脚踩实、身不飘"。

### B. 把入口改成东西向游线

**做法**：重排 12 脚点为横向主轴，直接复用沧浪亭复廊的"屋顶—白墙—漏窗—柱列"语言。

- **优点**：与全作 2.5D 语言完全一致，一次到位。
- **代价**：12 脚点、Tile、相机关键帧、剧本触发、15 个旗标路径、键盘／触屏整链回归**全部重写**；`LIUYUAN_ENTRY_SHOT_COORDINATES.md` 与现有截图作废。

### C. 为入口单独换 3/4 斜视投影

- **代价**：碰撞、角色、遮挡、所有场景坐标都要跟着换；且会与沧浪亭现有画面产生两种投影。
- **判断**：不建议。

> **建议（v0.3 修订）**：保留 12 脚点，把底图改为**委托绘制／生图的 3/4 底图**（与其余 31 张同类），见 §5.5。**B 线不再必要**——问题不是游线轴向，是图种。

## 4. 本轮实际交付

### 4.1 `?debug=plate` 对位层（已接入正式页）

`liuyuan-entry.html?debug=plate` 在真实美术上叠加：

- 12 个脚点（黄点 + 编号 + 所属落镜段）；
- 三段落镜框 504×344（红＝gate／橙＝bend／绿＝windows）；
- 蓝色游线；
- 可走 Tile 面（15% 绿）。

**用途**：任何候选底图接进来，10 秒内能看出脚点是否踩在石地上、落镜框是否框住该框的东西。这是过去六张候选被拒时缺的那把尺。

### 4.2 灰模生成器（未接入游戏）

- 生成器：[`scripts/build-entry-plate.ts`](scripts/build-entry-plate.ts)（读真实 Tile 数据）
- 产物：`assets/scene25d/liuyuan-entrance-walkable-study-v3.svg`（**灰模／坐标稿，不是正式美术**）
- 它回答的是"画在哪"：屋顶分区、32 段墙脚、可走面、六窗墙、门屋、植栽位置，全部与碰撞同坐标。
- 它**没有**回答"画成什么样"：灰模的屋顶只是平铺纹理，缺少坡面、檐口、材质与光，**不得当正式底图接入**。

### 4.3 v4 美术 pass 结果（2026-10-20 第二轮）

在 v3 灰模上做了 A 段首轮绘制：门屋立面（门洞、门框、瓦檐、门枕石、门槛）、前厅压暗与横梁、第一天井的亮面与水光、街面弹石与车辙、墙外树冠、门内一盏暖灯。

**做到了**：门屋读得出来；街→门→厅→井的明暗节奏成立；脚点仍全部落在铺地上（构造保证）。

**没做到**（且不是再加纹理能解决的）：

1. **3 格宽（48px）的南北夹弄，在正俯视下就是一条缝**。两侧是屋顶，没有可画的垂直面；画得越细，越像"精密的平面图"。
2. **合法的朝南墙面只有两处**（门屋、六窗墙）。其余墙都是南北向，硬贴立面就是 v2 的老毛病。
3. 屋顶占了画面 70% 以上，形成大片深色块；它需要的是真正的绘画（瓦垄走向、苔痕、天窗、披檐），不是程序纹理。

> **结论：A 路线（保留坐标、正俯视鸟瞰）的天花板已经摸到了。** 它可以是"干净的平面设计图"，但很难成为与复廊同级的 2.5D 场景。

### 4.4 明确未做

- v3 未接入 `liuyuan-entry.html`（默认仍是 v2）；
- 未做路线 B／C；
- 未做实体触屏与玩家草稿验收；
- 美术质量**未达**《GAME_ART_DIRECTION_STANDARD》的正式换装标准。

## 5. 下一版美术规格（可直接交给画师／生图）

### 5.1 画布与坐标

- **1008×688**，tile **16px**，北向上，正俯视（与现有一致）。
- 只缩放一次；人物脚点、碰撞、遮挡、特效共用这一套坐标。
- 三段落镜框（必须框住的内容）：

| 段 | 镜头左上角 | 必须看见 | 必须看不见 |
|---|---|---|---|
| A gate | (268,344) | 街面、门洞、门内一线天 | 六窗、中部池园 |
| B bend | (185,236) | 西折转角、第二小庭的收 | 六窗全貌 |
| C windows | (150,160) | 北墙六窗、古木交柯前缘 | 园林主景 |

### 5.2 分层与顺序

1. **地面**：街面（弹石）／廊（石板）／天井（大石板）／庭院（土 + 石）。
2. **屋顶**：坡面（脊亮、檐暗）、瓦垄、滴水；不同建筑换 2–3 档明度。
3. **粉墙压顶**：沿可走区边缘 **22px** 墙带，外缘 **4px** 黛瓦压顶。
4. **朝南立面**：**只允许三处**——六窗墙（y=224，x 368–480）、门屋（y=624，x 464–496／544–576）、南端街屋。
5. **檐口前景**：门屋檐、廊檐，可越过脚点上方，但**不得压住脚点 ±10px**。
6. **植栽**：树冠可越屋顶；竹丛、花台只在墙外；树干不得进入可走面。

### 5.3 硬约束

- **12 脚点 ±10px 内**：必须是清晰可辨的铺地，不得有前景、杂物、深影。
- **不得**在南北向墙上画朝南立面（这是 v2 的病根）。
- **不得**把未核构件画成实景：六窗纹样只作低分辨率原创剪影；门位、树位、铺地不称复原。
- 色板只用 `config.ts → PALETTE`；不新增颜色。
- 人、门、窗、墙要用**同一高度基准**：门高 ≈ 2.2 人，窗台 ≈ 0.9 人。

### 5.4 验收

1. `?debug=plate` 三段落镜各截一张：脚点全在铺地上、框内无未核构件。
2. 书生（近 126px／远 120px）、乔禾、老叟、门房、桶同屏，校门高、廊宽、树冠尺度与接地。
3. `npm run verify:scenes` 与留园整章输入回归通过。
4. 逐像素遮挡：檐口、树冠、墙根在人物前后的层级正确。

## 5.5 根因修正（2026-10-20 晚）：入口是全项目唯一的平面 SVG

玩家指出：做序篇时完成的场景编辑器，其内容（府学西学等）已符合美术标准。核对后确认：

- 统一编辑器 **32 张场景板里 31 张是绘制 PNG**（府学、沧浪亭、留园各幕…），**只有留园入口是 SVG 平面稿**。
- 所以入口"不像"不是调色、也不是像素密度，而是**图种不同**：别人是 3/4 绘制的可玩底图，它是俯视示意图。
- 之前那套按序章全景／小飞虹拟合的"三锚"阈值**对府学场景不成立**（府学 V 0.29、亮部 0%、彩部 1.2% 仍被认可），已从标准中撤回。

**结论：入口要补的是一张与其余 31 张同类的绘制底图**，不是继续调 SVG。现有 v3/v4/v5 只保留为坐标稿，不再往"正式底图"方向推进。

### 5.5.1 新底图规格（按府学语法）

| 项 | 规格 |
|---|---|
| 画布 | 1008×688 世界坐标（或 1672×941 等比，与府学一致） |
| 视角 | 3/4 俯视，南高北低；门楼在南、夹弄向北收 |
| 光 | 黄昏／阴天：暗场 + 门内灯笼暖光 + 湿石反光 |
| 色 | 瓦 #3b3d3c／粉墙亮部 #86807b／深绿 #3e4431／暖木灯 #69553f（自府学实测） |
| 纵深 | 前景瓦檐或树冠 → 门楼/院墙 → 北廊与六窗 → 雾 |
| 必须留空 | 12 脚点 ±10px 为可见铺地；三段落镜框内不出现未核构件 |
| 尺度 | 门高 ≈ 3.5 人；墙高 ≈ 2.2 人；灯笼 ≈ 0.35 人 |
| 禁止 | 烘焙人物、平面贴立面、把未核门位/窗纹画成实景 |

## 6. 本轮查询方式与边界

- **未调用** RAG 或外部检索：本轮是**投影与坐标问题**，不是史实问题。
- 引用的事实仅限项目内既有结论：入口为**艺术化游戏空间**，门位、树位、六窗纹样与铺地均未核，不得称"清末原貌"。
- 灰模与截图均为**制作稿**，不进入公开美术资源目录的"已完成"清单。
