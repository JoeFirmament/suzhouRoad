# 留园入口 · 分场表（v1.0）

> 2026-10-20 · 原则：**一场一景一底图。**
> 一个场景＝一个场所、一个镜头、一张 3/4 绘制底图；不是把一条路线压进一张图。
> 上位：`姑苏九园-剧本-CH3留园.md` CH3-01～04；对照：府学 Home 与小庭/临池/花木院各页。

---

## 0. 为什么拆

现 `liuyuan-entry.html` 用一张 1008×688 连续大图，同时装下：街面、门屋、门厅、夹弄、第一天井、西折、北廊、六窗、小庭口。每个空间只分到几十像素，所以它只能读成**示意图**——加多少瓦、多少灯都救不回来。

对照：

| 场景 | 结构 | 结果 |
|---|---|---|
| 府学 Home | 一个院子，一张图 | 是一张"场景" |
| 小庭 / 临池 / 花木院 / 石林 / 书斋院 | 各一页、各一张图 | 都是"场景" |
| **留园入口** | **一条路线，一张图** | **是路线图，不是场景** |

入口是例外。拆开之后，它才和其余七幕同构。

## 2. 逐场规格

### S1 · 巷口（CH3-01）

| 项 | 规格 |
|---|---|
| 画布 | 1008×688，3/4 俯视，南低北高 |
| 镜头 | 固定。担子在左前景，墙根在右，街向画面深处收 |
| 必须画 | 墙根、担子（**竹梆必须可辨**）、两只粥桶、新蒙布、街面弹石、对面的墙与门洞远景 |
| 必须没有 | 留园门、夹弄、园内任何景物；不出现"价目牌""门票" |
| 人物 | 乔老叟靠墙揉腿、乔禾蹲着数碗；玩家从画面下方进入 |
| 光 | 白天阴，无戏剧光；竹梆不响（哑的） |
| 脚点 | 2–3：街心、担子前、墙根侧 |
| 验收 | 玩家能说出"**他进不去，所以我提**" |
| 失败信号 | 玩家以为"我接到一个跑腿任务" |

### S2 · 花埠街（CH3-02）

| 项 | 规格 |
|---|---|
| 画布 | 1008×688，横向街景；侧门在画面一端 |
| 镜头 | 固定；街从画面一侧向另一侧走 |
| 必须画 | 花担群、花埠的湿石与花叶、**小得不像名园正门的侧门**、门里一段暗 |
| 必须没有 | 园内景物；不写门名、不挂匾 |
| 人物 | 乔禾在前半步、玩家在后；乔禾只报数，不发光、不指箭头 |
| 光 | 阴天，门外亮、门里暗（收放的第一下） |
| 脚点 | 2：街中、侧门前 |
| 验收 | 玩家能说出"**担子进不去，所以停在外面**" |
| 失败信号 | 玩家把乔禾当导航 |

### S3 · 侧门门洞（CH3-03）

| 项 | 规格 |
|---|---|
| 画布 | 1008×688，门洞占画面中心偏左，门内一线暗 |

| 项 | 规格 |
|---|---|
| 画布 | 1008×688，竖构图；两侧高墙夹出一线天 |

| 必须画 | 高墙、湿石、两个转折、弄口的一小块亮（小庭/树/半面廊的暗示） |

## 4. 底图通用规格（每场都适用）

1. **图种**：3/4 绘制的可玩底图，与府学、小庭同一语法；不是俯视示意图。
2. **画幅**：1008×688（或 1672×941 等比），一比一映射到世界坐标。
3. **光**：阴天为主；S3/S4 用"外亮内暗"；灯笼只在 S3 出现。
4. **材质**：粉墙、黛瓦、湿石、木作、低饱和深绿；地面必须有湿反光与苔痕。
5. **纵深**：前景墙根或檐口 → 中景主体 → 远景墙/树/雾。
6. **人物不烘焙**；脚点 ±10px 内必须是清晰铺地。
7. **不宣称复原**：门位、花担、灯、竹梆的具体形制只作游戏演绎。

## 5. 制作顺序

| 顺序 | 场景 | 理由 |
|---:|---|---|
| 1 | **S1 巷口** | 一场同时定下人物比例、街面材质、门屋/墙根形象三个基准 |
| 2 | **S4 夹弄** | 定义全章的"窄"与光；也最容易验证"先收后放" |
| 3 | **S3 侧门** | 门房与验桶动作，需要人物近景 |
| 4 | **S2 花埠街** | 横向街景与花担群，可复用 S1 的街面材质 |

---

## 6. 验收（每场通用）

1. 与相邻场、同一角色并排：像素密度、色阶、光向、人物身高连续。
2. 无调试层时，玩家能辨认行走面、门洞、门槛、实墙与前景遮挡。
3. `?debug=plate` 叠脚点：全部落在可见铺地。
4. 键盘/触屏各走一遍；刷新续接不丢位置。
5. 该场的"验收点"能被玩家用自己的话说出来；失败信号不出现。
