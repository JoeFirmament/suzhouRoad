# 留园 CH3 西—中—东游线：历史图源闸门

2026-10-09。此卡原本只决定**何时可以把研究切片接成历史复原通路**，不是留园平面的复原图。用户现已明确允许：历史门路图源找不到时，以**当代游线**推进游戏，并显式标注。因此旧图不再是标记为“当代参考 + 游戏剪接”的可玩章流的前置闸门；它仍是声称清末门位/道路原貌的闸门。当前接法与偏离见 [当代游线改编记录](LIUYUAN_MODERN_ROUTE_ADAPTATION.md)。

## 本轮实际查询

- 离线 `garden_knowledge` 文字向量：查询“苏州留园全图 郑恩照 郑思照 又一村 林泉耆硕之馆 西廊 四面厅 花房 1910 旧图”。最高命中《园林有境》的现状入口、池园与游廊概述；没有旧图、旧门洞或可定位的花房—东园路段。另一问“留园 花木院 太湖石 三石 布置 疏密 留白 构图 有没有具体原位与清末证据”亦只得一般园林论述，不能为画谱研究小景指定真实石位。
- [东洋文库馆藏目录第 3571 号《苏州留园全图》](https://www.toyo-bunko.org/chinacat/ChinaQueryResultNDC.php?ndc=18.25&prevcatname=%E5%85%83%E4%BD%8D%E7%BD%AE&prevcaturl=C200_index.html)：确认有此馆藏条目，目录**未提供可读图像**。馆藏号是索取线索，不是门位证据。
- [《中国园林》原刊摘要，程嘉敬、王昕、步梦云，2022 年第 6 期](https://jchla.ijournals.cn/ch/reader/view_abstract.aspx?file_no=20220624&flag=1)：明确园界变迁会改变游线；本轮“在线阅读全文”返回 404，“PDF 全文”无法取得，**未核文内各时期复原图**。[参考网可见的论文开头](https://www.fx361.com/page/2022/0712/13841536.shtml)称 1910 年有《苏州留园全图》，并说明作者借 1953 年修复后图、童寯修复前图及文献反推。这是一篇研究，不可把其反推图默认为 1890 实测。
- [《透过文本与图像，重新阅读留园》检索页](https://www.sohu.com/a/859970444_121124384)提及盛氏增筑住宅/祠堂与今日入口避弄的形成；网页正文、所称图 3 在本轮未能打开核图，故只保留文献候选。图片搜索只返回现代导览图、1953 后测绘图与无出处转载，未发现可辨读的 1910 原图。
- [澎湃新闻转述“古木交柯”砖匾题跋](https://m.thepaper.cn/newsDetail_forward_22474671)把 1917 年补题者写作**郑思照**；上述论文可见文字及另两篇二手文章写测绘者**郑恩照**。两种署名可能涉及不同人物、误抄或排印，**本轮不能判定**，更不能据名称推门位。小庭仍遵守已有红线：不把 1917 补题匾或今日补植树形画成 1890 原貌。

## 正式游线所需的最小证据包

| 待连边 | 已可声称的关系 | 仍缺的决定性材料 |
|---|---|---|
| 入口夹弄—古木交柯—绿荫轩 | 现状建筑/池园拓扑及前四幕试走可用；小庭到临池仍为镜头剪接 | 有方位的旧图或同一路段早期照片，证明具体廊口与门槛；不能用现代导览图定 1890 坐标 |
| 绿荫轩—小蓬莱花房—旧“又一村” | 剧本先后和研究切片可试；花房交粥、花匠可玩 | 旧花房与厅西廊段的相对位置、道路/门洞；尤其须区分旧“又一村”与今天北部盆景园同名处 |
| 厅西廊—四面厅/林泉耆硕之馆—石林/东园 | 来源提示相邻的大区域顺序，现有石林和冠云峰图是独立研究场 | 可读年代平面，标明厅侧廊、石林入口与东园之间实际可走接口；核 1909 改造前后差异 |
| 石林—书斋院—出园 | 书斋院及内景人物节拍、入口逆行均可独立试；没有正式接门 | 当时书斋名、入口院落及通路，蕉株/门额部位；回程门房通道的时代依据 |

若要宣称历史复原，仍需把旧图和 1953 前/后平面**分别**配准到同一方位，逐边标“原图可见 / 文献推断 / 游戏剪接”。游戏转场则可依据当代资料与用户授权接通，并在场景内说明非实门；剧情旗标只表示玩家完成了对应虚构任务，不表示史实已获证。

## 可以立即继续与不能越过的线

不依赖上述旧门位的工作可继续：前四幕与画谱键盘/触屏复验、人物比例/脚点校准、书斋独立人物节拍、出园逆行测试，以及有证据的原图/照片搜集。留园构图画谱中的兰、竹、石和折枝来自潘天寿原书图例，但眼前小景与花匠对话是游戏创作；不可把其摆石、植兰或落印位置倒推成留园史实。

**若未来制作清末复原版，最有帮助的材料**：东洋文库第 3571 号《苏州留园全图》的可辨读整图（含图名、图例、方位和原件出处），或有出处的 1909 前后留园改造图、童寯修复前平面高清扫描。只需研究用途副本；进入公开游戏包的图片权利另核。缺旧图不再阻止已标注时代/演绎边界的游戏章流。
