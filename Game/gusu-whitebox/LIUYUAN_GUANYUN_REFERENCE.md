# 留园冠云峰 · 实景制作核查（非场景验收）

本页只约束 CH3-06 东园候选画面的实景依据，不把现状照片等同于光绪十六年实测。冠云峰与前一幕“石林小院／揖峰轩”的晚翠峰不是同一块石，也不是同一张可走场景。

## 可用来源与画面证据

- [苏州市园林局《留园》](https://ylj.suzhou.gov.cn/szsylj/sjyc/201905/b7c0f2058c75498c9ecbacf234e25b08.shtml)附有标为“冠云峰”的[现状照片](https://ylj.suzhou.gov.cn/szsylj/sjyc/201905/b7c0f2058c75498c9ecbacf234e25b08/images/fdbfe283e6c64e4c8481c62e15762aa3.jpg)：从水面朝主峰看，峰体为高耸、瘦长、多孔的太湖石，水在前，瓦顶建筑在后。它能约束主峰剪影和一幅正向镜头，不能独自推出背面可走路、全园门洞、1890 植栽。
- 同页文字记东部以厅堂庭院为主、冠云峰前有浣云沼，周边有冠云楼、冠云亭、冠云台等赏石建筑；不能据“周边”二字自行排出左右顺序。
- [园林局转录的民国朱揖文《游苏备览·留园》](https://ylj.suzhou.gov.cn/szsylj/ylwh/201807/37222ea7f68c4ddd9cc08c9e769f39d7.shtml)从石林小院、揖峰轩记入东园，描述冠云峰、浣云沼、四面厅和东园玉兰；其游览顺序可作分幕依据，不是 1890 平面。
- [园林局《长留天地间——俞樾与留园》](https://ylj.suzhou.gov.cn/szsylj/ylwh/201712/ece35ea49f6e4a4eb42a3a21efced163.shtml)记盛康扩建东部并围入冠云峰，也记瑞云峰在乾隆年间被移往织造府行宫（今苏州十中）。这与上述现状概览和民国游记称冠云峰旁有“瑞云峰”的说法冲突；两侧峰石的历史名称与身份暂不定稿。
- 园林局《留园》还明确记林泉耆硕之馆北侧有冠云峰。刘海燕等《留园冠云峰庭院空间造园要素的量化特征及其意境研究》（《安徽农业科学》2013, 41(21):8992–8996）的[在线转录](https://www.wendangwang.com/doc/ca9f8060008319449905174d)记南侧主厅与北侧冠云楼对景，亭廊围合庭院；转录有 OCR 错，图 1 尚待原版核对。故构图必须保留“南厅—沼—峰—北楼”顺序，不可画成南侧无建筑的大广场。
- [关西学院大学机构库：绪方贤一《留園試論——档案に基づく中国庭園経営の実態》](https://kwansei.repo.nii.ac.jp/record/29225/files/%E7%B7%92%E6%96%B9%E8%B3%A2%E4%B8%80.pdf)的可检索片段称，1909 年《蘇州留園全圖》及同年改造工程图显示冠云峰旁廊与峰石曾改动，今日可见的部分亭石当时尚未画出。原 PDF 本轮响应 429，**尚未完整核读原图与引文**；这只构成年代预警，不据片段判断 1890 年每一物件的有无。

## 给可走 2.5D 场景的约束

1. 主峰保留照片中不规则上端孔洞和纵向瘦长剪影，站在池岸可望见全峰；不得画成圆形假山岛或大片可爬的石山。
2. 浣云沼是峰前较小的观石水面，不是中部主池；水面、岸石、池边路与主峰基座须分为不同几何。没有证据便不加跨沼廊桥。
3. 玩家必须能沿真实可推断的岸路和廊下绕行、停步赏石，不能横穿峰石根部或水。入口/出口只作候选语义接点，待有平面与多角度照片后再落像素坐标。
4. 前景屋檐、柱子和植栽各自有落地线、碰撞及遮挡轮廓；主峰本体也是独立物件。人物比例以 6.5 米主峰和现有书生精灵交叉检查，但照片透视不能直接换算游戏比例。
5. 画面走低饱和、可辨像素簇的统一风格；官方照片用于识别形态和空间，不直接作为游戏底图。不要出现现代游客、现代设施、未核的匾额、盆栽玉兰。

## 当前缺口

- 缺有北箭头/尺度、能区分冠云峰—浣云沼—冠云楼/亭/台—四面厅门路的可靠平面与多角度照片；不能仅凭这张单角度照片给全景碰撞。
- 两侧峰石名称与来源矛盾，待核原始园志或保护测绘。
- 1890 年玉兰的株数和位置未核。民国游记只能证明后出叙述中的“东园有玉兰”，不能画成书斋门口双树标识。
- 1909 前后东园改造的具体范围和 1890 年冠云峰院完成状态仍需档案及原图交叉核对。不可把现今冠云亭、侧廊、附峰石、馆内屏风或匾额直接回填到光绪十六年。
