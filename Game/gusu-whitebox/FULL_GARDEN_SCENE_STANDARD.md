# 全园可游走场景标准（从沧浪亭开始）

游戏目的不是在一张漂亮背景上做任务：玩家应能从真实入口走入园中，沿真实的水、山、廊、院、厅关系自由游走；停步、回望、隔窗看景，逐渐喜欢上苏州园林。全园图是可漫游的世界层，近景图和正视照片只用于剧情镜头、室内或局部交互。

## 资料先行

每园至少收集并并排核对：一张带方位的全园平面/导览图、入口与主要动线的实景照、厅堂与假山的实景照、可判定晚清状态的文字或图档。今日照片只能说明仍存构件的形态，不能自动证明 1890 年的陈设、通道和住用状态。参考图不直接收入发行资产；外部图像的使用权限另行核查。

## 每张全园图的验收闸门

1. **空间**：入口、外水/内水、山体、厅堂、宅院、廊道的位置和连通关系先以资料描成语义地图，再像素化。不得增加资料里没有的大水面或把方位颠倒。
2. **时代**：1890 年不存在、或仅今日可见的附加建筑和陈设不得冒充晚清原貌。宅院只在有根据时标为住宅；没有证据则标「用途待核」。
3. **游走**：至少一条从入口到主山、环山、复廊、主厅堂、出口的连续路线；分支能回环，主要建筑入口可达；游戏中的慢走、停留、回望有空间。
4. **视觉**：统一斜俯视投影与像素尺度；屋面和树冠可遮挡，但人物脚下路面清楚。正视照片只能做过场或对话镜头。
5. **几何**：同一世界坐标中编辑 Tile、物件碰撞、遮挡轮廓、落地线、水面特效；逐个门口和桥头实走，不能因为图好看就直接上线。

## 耦园路线骨架 · 第一轮

耦园已在编辑器新增“通路骨架 / 门洞”层：14 个路线节点、14 条候选连线，从巷口经中宅四进分别抵达西园井与鲽砚庐、东园池与石凳；节点与 CH7 剧本行动点关联。节点可拖动，连线可设“候选 / 已核 / 禁行”；禁行边不参与从入口的连通性检查，门一旦被判封闭，相关剧情点会显示不可达。新的节点/连线可以在编辑器中增删。路线骨架只验证**拓扑**，不自动宣布直线段避开了墙、水或屋檐。

目前全部连线保持“候选”，不能据此生成角色移动。下一轮须依据平面和实景逐门定位，确认中宅到两园的门洞、廊道和鲽砚庐入口。确认后沿路线绘可行走 Tile，再用独立物件碰撞封住墙基、池岸、黄石与井沿，并做玩家脚点实走。编辑器草稿可以在骨架未完成时保存；结构提示不会锁死“确认保存为最新”。

艺圃 v3 有 15 节点、15 条候选路线：保留从东巷公所门、前院、东廊、碑、池东坐点、池南土山、西月门、池西路回北部堂屋的环线，并从东廊增接延光阁东端门、阁内临水地面。编辑器另预置延光阁局部物件几何：东端和阁内可走、池心禁行；屋檐、前栏、六根柱与门框分别管理遮挡和落地线，门洞留空。池水作为独立物件，保守水纹内缘加石簇与西南石阶扣除区，不与阁内通行 Tile 混用。自动测试从东端沿阁内走 35 步不被空气墙卡住，前栏止步、池心封闭，屋檐前后深度顺序、门洞不遮及水纹不扫阁面/石簇均通过。**这不是整园可走地形或视觉实走验收**；浅水和池南剩余水面仍须在编辑器贴图补标，轮廓须逐点微调。v2 仍保留原 ID 与浏览器草稿；若 v3 已有旧草稿，编辑器只补缺失的新物件，不动原有 Tile 或同名物件，保存前会提示检查。

通路编辑新增几何门槛：每条平层连线按玩家脚底碰撞盒每 4px 采样 Tile 与物件碰撞；候选边只报告首个受阻点，已确认边受阻则不能「确认保存为最新版本」。曲折路要增加路点，不能用一条直线跨墙；跨层路须另行实走，平面测试不替代楼梯验证。艺圃 v3 的阁东门→阁内一段通过，碑位→阁东门仍因图上建筑/庭墙和未开放 Tile 受阻，所以该边继续为候选。**碰撞通过也不等于实景门位正确、遮挡正确或可发布**。
