# 环秀山庄 · 场景图交接（给 Codex）

> 目标：按 **960×600 / 2.5D 像素 / 清末 1890** 口径，重做 CH6 环秀山庄的场景底图。
> **不要一次做 10 张。** 先 P1–P3，过一关再做下一关。

## 0. 动手前先确认

1. **你能查看图片内容吗？** 不能看就停下报告，不要靠文件名/文字猜。
2. 能看，就先对每张参考回答**五问**（见 `REVIEW.md` §1）；答不出 = 没看见。
3. 再读 `SCENES.md`、`STYLE.md`、`ASSETS.md`。

## 1. 目录

```
handoff-codex/
├─ HANDOFF.md        ← 本文件
├─ SCENES.md         ← 场景清单 + 每张 must/avoid
├─ STYLE.md          ← 画幅/色板/光/像素/1890
├─ REVIEW.md         ← 五问 + 打分 + 停手规则
├─ ASSETS.md         ← 参考图/控制图索引
├─ assets/           ← 参考图与控制图
├─ plates/           ← 产出的 960×600 底图（HX-xx.png）
└─ scripts/          ← pixelate.py / quantize_plate.py
```

## 2. 每张图的工序

1. 读对应 scene card（`SCENES.md`）。
2. 选参考：结构图 + 风格图 + 色板（`ASSETS.md`）。
3. 出 **4–6 张**，同一 prompt / 固定 seed。
4. 按 `REVIEW.md` 打分；**先看构图，再看细节**。
5. 选中 → 局部重绘（洞口/石面/墙），不要整张重画。
6. 后处理：
   ```bash
   python3 scripts/pixelate.py raw.png plates/HX-03.png --size 960x600 --scale 3
   ```
7. 更新 `plates/README.md`：seed / 参考 / 分数 / 备注。

## 3. 全局硬约束

- **960×600**，像素 1:1；玩家 **126px**；16px tile 语法。
- 2.5D 侧视/微俯；**光从左上**；阴天、湿石；**不要蓝天**。
- **无文字、无人物、无水印、无现代栏杆、无导览牌。**
- 人物由引擎加 sprite，底图不画人。
- 1890：俞平伯匾不可用；走马楼待核；照片只作研究，成图是游戏化再现。

- 960×600；`REVIEW.md` **≥20/25**，构图项 ≥3；
- 无文字/人物/水印；能进引擎（脚点/遮挡对得上）；

- 未过 20 分的图，不进入下一关。
