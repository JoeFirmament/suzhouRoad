# 审图：五问 + 打分 + 停手

## 1. 先问五问（每张参考/候选）

1. 山是**横**的还是**竖**的？宽约是高的几倍？
2. 洞在哪？洞里有**台阶/路**吗？
3. 左边是什么建筑？几层？山高约是它的几倍？
4. 前景是**桥、平台，还是水**？
5. 有没有**文字/人/现代栏杆/水印**？

答不出 = 没看见；不能进入下一关。

## 2. 打分（每项 0–5）

| 项 | 5 | 3 | 1 |
|---|---|---|---|
| 构图 | 所有 must 在位 | 缺一样 | 全乱 |
| 比例 | 山≈廊亭 2 倍；人 126px 参照 | 偏大/偏小 | 像土坡/巨峰 |
| 纵深 | 前景/中景/远景三层清楚 | 缺一层 | 全平 |
| 色 | 接近 24 色族 | 偏亮/偏蓝 | 旅游照 |
| 干净 | 无字/人/水印/现代 | 少量 | 明显 |

**通过线：≥20/25，且构图 ≥3。**

## 3. 停手规则

- 同一张图 **6 张候选、两轮**仍不过构图 → 停。
  说明参考/提示词压不住，换 ControlNet 平台或手绘，不要继续烧图。
- 先用 P1 跑通全流程，再开 P2；不要 10 张并行。

## 4. 常见翻车与修法

| 现象 | 修 |
|---|---|
| 竖峰/石林 | 结构参考换成横向照片；负向加“竖石/孤峰/石林”；提示词写“宽≈高2倍” |
| 洞像门洞/有台阶 | 压暗洞内、去台阶；局部重绘；负向“台阶/门洞” |
| 屋檐/洞/桥不同框 | 重排构图到 960×600；不要裁 1008×688 |
| 水墨/黑白 | 加彩色、灰绿、像素风；负向“水墨/素描/单色” |
| 墙太新 | 负向“现代水泥/瓷砖”；加“粉墙、水痕、苔” |
| 出现文字/人 | 负向；控制图里不要有人；出图后裁/重绘 |
