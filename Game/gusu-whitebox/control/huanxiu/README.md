# 环秀山庄 · 山脚看山 · 构图稿 v0

> **这不是美术。** 是填色之前的骨架：分层、机位、尺度、光位、每一框必须看见什么。
> 用途：给画师／生图当版式约束；给程序当相机与脚点参考；给评审当"能不能用"的第一道闸。

## 0. 一句话

**一座不能登的山，用三个（未来八个）看山点看它。玩家学会的是看，不是爬。**

## 2. 坐标与分层

- 画布 **1008×688**，脚点 **y=688**；山脚 **y=648**；墙顶 **y=196**；路面 **y=652–688**。
- 由后到前：

```
天 → 墙/瓦 → 树冠 → 山体 → 石根 → 栏杆 → 路 → 人
```

- 光：**左上、阴天**。山体只给三档明度 + 一档高光；不靠颜色，靠明度读体积。
- 人：**126px**（与留园入口同一基准），只作比例尺，**不烘焙进底图**。

## 4. 长卷（下一版）

- 3 段 × 3 机位 = **9 个看山点**（或 4 段 × 2 = 8）。
- 每段 1008 宽，总 **3024**；相机在段内横移，段间无缝。
- 每段的峰、洞、树位置**错开**，保证"移步换景"；不能复制粘贴。
- 天气：**一张底 + 雨后／黄昏两个光色变体**，不重画。

## 5. 画什么（给画师／生图）

| 部位 | 要求 |
|---|---|
| 山体 | 湖石；三档明度；石面细碎褶皱（皴感），**不要等大石块排排坐** |
| 洞 | 黑洞 + 里面一点远光；**不画可进入的台阶** |
| 裂 | 一道深缝，把主峰与次峰分开；缝里暗 |
| 钩带 | 5–6 块咬合石；缝深 2px；受光边亮 2px；**放大后可辨** |
| 石根 | 一排矮石压住山脚，与路面衔接 |
| 栏杆 | 木/石栏杆，明确"不可登"；不是装饰 |
| 树 | 墙后，只露冠；三种绿；不遮主峰 |
| 墙 | 粉墙黛瓦；瓦当/滴水一条；不做景区说明牌 |
| 人 | 126px，脚在 688；只作比例尺 |

## 6. 硬约束

1. 三个机位的主峰、洞、树**不能同形**。
2. 山高 ≈ **3.0–3.8 人**（378–480px）；墙高 ≈ 2.2 人。
3. 脚点与路面**不被前景遮**。
4. **洞不可进入**；不画登顶台阶。
5. 钩带接缝在**放大后**可辨。
6. 不写"天下第一"石碑、不做导览牌。

## 7. 验收

- 三机位截图：剪影不重复，主宾/留白成立。
- 放大 `closeup`：洞与接缝可辨。
- 与府学并排：色阶、光向、像素密度连续。
- 玩家能指着一框说：**"这一框，像山。"**

## 8. 未核与边界

- 山体是 **massing（体块）**，不是 1890 测绘；具体峰位、洞位、石形待照片／平面核。
- 不称原址复原；它是游戏化空间。
- 长卷用"移步换景"的散点透视，与单点透视不同；**先做一段试片再铺全长卷**。

## 9. 取景原型（可走一遍）

**[`../../huanxiu-view-lab.html`](../../huanxiu-view-lab.html)**

- A / B / C 三个机位，**不同焦距**：A 广角看山形（zoom 1.0）、B 长焦看洞（1.45）、C 中景看钩带（1.2）。
- 可自由平移、缩放、开关辅助线；左下角红条 = 126px 人。
- 三张缩略图并排，直接比"三框是不是同一张"。
- 不写存档、不接章流，只是构图台。

### 这一步暴露的问题（重要）

三框之所以能分开，**靠的是不同焦距**。如果游戏相机是固定视角（同一 zoom），A/B/C 只是左右平移，三框会**明显趋同**——这说明：

- 要么允许**按机位变焦**（A 广、B 长、C 中），像电影分镜；
- 要么把场景做成**更宽的长卷**（3 段），让平移本身产生足够差异；
- 要么重新排布山体，让三个位置各有独立主景。

**这是场景规格的第一道决策，不是美术问题。**

## 10. 三段长卷 · 固定 zoom 试跑

**[`../../huanxiu-scroll-lab.html`](../../huanxiu-scroll-lab.html)**

- **一张 3024×688 的长卷**，三段各 1008；相机**固定 1×**，只平移。
- A 东：主峰 + 裂；B 中：次峰 + 洞；C 西：西脸 + 钩带 + 树。
- 三张缩略图并排，**不改变焦**，只看平移能不能把三框分开。

### 结论（可用的第一条）

**固定 zoom 能成立，但前提是长卷本身按三幅构图来画**，不是把一座山平铺 3 倍：

1. 每段有自己的主景（峰／洞／西脸），**不能复制粘贴**；
2. 段与段之间要有**山坳、树、墙**把"换景"藏起来；
3. 玩家在段内平移时，山形是连续变化的；跨段时允许一次"换景"。

截图：`lab-scroll.png`；长卷底图：`scroll.svg` / `scroll.png`；带段框：`scroll-overlay.svg` / `scroll-overlay.png`。

> 下一步要定的是：**跨段是连续平移，还是切一页**。连续平移更顺，但段缝要画得天衣无缝；切一页更省，但会打断"走山"的感觉。

## 11. A→B 段缝试段（连续平移）

**[`../../huanxiu-seam-lab.html`](../../huanxiu-seam-lab.html)** · 底图 `seam.svg` / `seam.png`（2016×688）

- 相机固定 1×，从 A（x=0）连续平移到 B（x=1008）。
- **缝上长了一棵树**：树干挡缝、树冠挡天、山坳挡地；墙、栏杆、路一根线到底。
- 可按“播放”慢速走一遍，也可按“缝”直接停在正中。

### 结论

**慢速平移时，缝不跳。** 三件事同时成立：

1. **树干正好压在 1008 上**（不是“附近”，是正中）；
2. **两侧山形都向缝收成一个山坳**，缝落在坳底；
3. **背后的墙、脚下的栏杆与路连续**，没有断线。

### 风险

- 树是**很强的竖向切分**；如果每个缝都用树，会变成套路。
- 下一道缝（B→C）建议换一种遮挡：**墙垛、石笋、门洞**，不要重复同一棵树。
- 树冠会挡掉一部分天空与墙顶，画的时候要让瓦线在树后仍然可读。

截图：`seam-lab-A.png` / `seam-lab-S.png` / `seam-lab-B.png`。

## 12. B→C 段缝试段（墙垛）

**[`../../huanxiu-seam-lab.html?seg=bc`](../../huanxiu-seam-lab.html?seg=bc)** · 底图 `seam-bc.svg` / `seam-bc.png`（2016×688）

- 同一套相机：固定 1×，从 B（x=0）连续平移到 C（x=1008），缝在正中。
- 这次**不种树**：缝上是一段**白墙垛**（压住缝）+ 两块**矮石**（接住山脚）。
- 墙、栏杆、路仍然一根线到底。

### 结论

**墙垛也能藏缝，但气质和树完全不同。**

- 树是**有机的**：它把缝“长”没了，玩家不会追问；
- 墙垛是**建筑的**：它把缝“砌”住了，玩家会看见“这里有一道墙”，但不觉得是接缝。

### 风险

- 墙垛是一块**很白的竖条**，在深色山体前非常抢眼；真画的时候必须加**墙面质感、藤痕、门洞或砖缝**，否则像贴上去的。
- 它会把长卷切成“两进院子”；如果不想强调院落感，第二次还是用石/树。

截图：`seam-bc-lab-S.png`。

### 两道缝的对照

| 缝 | 遮挡 | 读感 | 适合 |
|---|---|---|---|
| A→B | 树（干/冠/坳） | 长出来的，消失 | 山体连续、想让玩家不觉 |
| B→C | 墙垛 + 矮石 | 砌出来的，可见 | 院落转折、想让玩家知道“换了一进” |

## 13. 实景取景对照（照片定构图，不画 SVG 假山）

**[`../../huanxiu-photo-lab.html`](../../huanxiu-photo-lab.html)** · 参考图 `ref/panorama-7-1.jpg` / `ref/doorway.jpg`

> 参考照片只作研究，**不进游戏资源**。

### 照片纠正了三件事

1. **山是连续的岩壁，不是居中的主峰。** 它从左到右横着铺开，洞在脚下，不是一个三角峰。
2. **楼是比例尺。** 左边一栋两层楼，山把楼压住——“第一”的证据是**楼与山的比例**，不是山有多高。
3. **院子是一个紧凑的单景，不是 3 段 3024 的长卷。** 人沿池栏走几步，变化来自**取景与站位**，不是走 3000px。

### 因此，场景规格改成

| 资产 | 尺寸 | 内容 |
|---|---|---|
| 宽景底图 | **1205×688**（或 1512×688） | 楼在左、岩壁在中右、池栏与路在前、树冠压山顶 |
| 门框景 | **1008×688** | 人站在屋里，门洞框住山；门洞就是取景匣 |
| 细节（可选） | 320×240 | 洞口/钩带，放大用 |

**不做 3 段长卷了。** 那是按“一座虚构的山”排的；真实的环秀是一眼能看全的小院。

### 这一步证明的事

- 用真实照片可以直接排机位、量比例、定洞口，**不需要 SVG 假山**。
- 山像不像，照片说了算；画得好不好，画师说了算。
- SVG 的阶段到此结束：它只证明过“固定 zoom 下三框会趋同”，这句结论还有效；它的山形作废。

截图：`photo-pano.png` / `photo-door.png`。

## 14. 实景描线底稿（给画师）

> **描，不是编。** 所有线按照片 `ref/panorama-7-1-clean.jpg`（1219×688）描；没有一条是凭空的体块。

| 文件 | 用途 |
|---|---|
| `trace-underlay.png` | 照片淡化 62% + 彩色描线 + 标注：对位置用 |
| `trace-underlay-blank.png` | 米色纸 + 彩色描线 + 标注：画师直接覆画 |
| `trace-underlay.svg` | 矢量线稿（照片 38% 作底，可编辑） |
| `build_trace.py` | 所有坐标都在这里，改点重跑 |

### 线色

| 色 | 内容 |
|---|---|
| 蓝 | 楼：屋顶、墙线、月洞门、二层栏板 |
| 红 | 岩壁外轮廓：**左段**（x≈362–520）、**右段**（x≈850–1219） |
| 橙 | 洞口（**待考**）：中央、右、左三个暗腔 |
| 绿 | 石栏顶 / 石凳 / 路沿 / 栏柱 |
| 青 | 池岸 |
| 深绿 | 树干与主枝 |

### 哪些没描

- **岩壁中段（x≈520–850）被树冠遮住**：留空，画师按照片补；不要凭空造一条平滑的顶线。
- **松（前景，x≈250–420）**：只标了位置，没描枝叶。
- 石面的皱、透、孔、苔：描不出来，必须画。

### 坐标与比例

- 画布 **1219×688**，原点左上；游戏宽景目标 **1205×688**（缩 0.988）。
- 楼是比例尺：两层，檐口约在 y≈200；山脚在 y≈620；人站在路上约 126px。
- 洞口下沿不要越过石凳（y≈600）；现在橙框到 550/560，是“口”的位置，不是可进入的洞。

### 1890 边界

- 门框照片上的匾是**俞平伯**所题（1900 年生），1890 年不存在；**匾不能照搬**。
- 今天的石栏、石凳、铺地可能经修缮；描线只定**构图与位置**，不作原状复原。
- 照片只作研究参考，**不进游戏资源**；最终底图是画的。

### 用法

1. 画师把 `trace-underlay-blank.png` 以 1219×688 导入，覆画；
2. 同时打开 `trace-underlay.png` 对照照片边缘；
3. 岩壁中段按照片补，不要顺着红线的两端“拉直”；
4. 画完导出 1205×688（或 1008×688 门框版另画）。

> 这批线是**示意**，不是测绘。真正准的轮廓，要靠画师对着照片再描一遍；我给的是位置、比例、遮挡关系。

## 15. 主面修正：南面是背面（2026-10-20）

> 资料：方惠（扬派叠山匠师）「再识环秀山庄假山主大面」；对照刘敦桢《苏州古典园林》记录的原始游序。
> **口径**：刘敦桢的游序是文献；「南面是背面、主面在问泉亭—补秋山房」是**当代匠师的再解读**，游戏采用它作体验设计，但标注为「匠师观点／合理演绎」，不写成定论。

### 15.1 结论

- **南侧厅堂平台看到的是山的背面**，不是主大面。
- **真正的主大面，是问泉亭至补秋山房的入山游览线**（东南向谷壑）。
- 南面为何不是主面：① 山势尽头的收尾；② 顶部碎石拼叠是工程收尾，好石不在这里；③ 前平台太宽，主峰显低。
- 南面原本是**游山的收尾回望点**，不是开场观赏点。今天把路线走反了。

### 15.2 原始游序（刘敦桢）

```
廊下近山 → 问泉亭入山 → 补秋山房处山中
→ 半潭秋水一房山亭入山腹 → 自南侧主峰绝壁出山
```

游戏应恢复这个顺序；**南平台是最后一站**，不是第一眼。

### 15.3 主面的三层空间（问泉亭视线）

| 层 | 物 | 作用 |
|---|---|---|
| ① 谷底 | 水坝 | 暗示水源自深山 |
| ② 近处 | 厚重石头发券的石桥 | 近重 |
| ③ 远处 | 轻薄石板桥 | 远轻；如「远山无皴」 |

**近重远轻**的透视错觉，拉深山体纵深；洞口在补秋山房转化为有层次的“山头”。

### 15.4 造园逻辑

- **「山在园中」vs「园在山中」**：环秀属后者——截取真山一角入园，再现谷壑、山根、陵阜。
- **「深厚法」**：重在**山之深**，不在石之巧。
- 主山大势向**东北高墙**延伸，借围墙、土坡、林木造「墙外千岩万壑」；这是张南垣「缭以短垣，翳以密篠」的思路。

### 15.5 对场景设计的后果

1. **场景从“一张宽景”改成“一条游线 + 五个站点”**：南平台只是第六站（回望）。
2. **主面视角在问泉亭**：看东南谷壑，不是看南侧岩壁。
3. **玩家走在山谷里，不是站在平台上看山**；“不能登”反而成立——人进入的是山的**腹部与谷底**，不是山顶。
4. **对读内容现成**：厚石桥 vs 薄石板桥（近重远轻）、水坝 vs 洞口（源与口）、南面碎石顶 vs 主面好石（背面 vs 主面）。
5. **比例尺换成问泉亭/补秋山房/半潭秋水一房山亭**，不是南侧厅堂。

### 15.6 还缺什么

- 主面沿线的**实景照片**：问泉亭内看东南谷壑、补秋山房看洞口、半潭秋水一房山看山腹。
- 一张可用的**平面图**（刘敦桢图或测绘图）用来定五个站点的坐标；现有海报里的平面图太糊。
- 照片到位后，重做 `trace-overlay` 的主面版；南面版保留，作“回望”用。

> 现有的 `photo-pano.png` / `trace-underlay.png` 是**背面**，不作废，改作第六站“出山回望”。

### 16.3 游线示意

`route-plan.png`（**v2，据图 2-114《苏州环秀山庄平面图》重绘**）：

- 布局：补秋山房在北、问泉亭在西、半潭秋水一房山在东、廊沿西墙、平台在南。
- 游线：0 廊下近山 → 1 问泉亭 → 2 补秋山房 → 3 半潭秋水 → **4 山腹** → 5 平台回望。
- 主面在 1→2 的东南谷壑；5 是收尾，不是开场。

**两条路线要分开：**

| 线 | 平面图上的线 | 游戏里 |
|---|---|---|
| **假山路线** | 虚线，越山脊 | **不作玩家路径**（不能登） |
| **山洞路线** | 点划线，穿山腹 | 可作 **4 山腹** 的入山段；标“游戏化再现”，不等于今日开放 |

> 这样“不能登”与“进山”同时成立：**人从洞里进山，不从山上踩山。**
