# 环秀山庄 · 主面试段绘制 brief（v1）

> 给画师。先画 **672×459** 的左段试片，验石面/洞口/人/栏；过了再铺 **1008×688** 整张。
> 参考：图 2-116 西南透视（构图）、2-115 西立面（比例）、1:5 模型（体量）、`mainface-line-v1.png`、`mainface-color-v1.png`、`mainface-cave-2x.png`。

## 1. 试片范围

- 画布：**672×459**（整张主面的**下半段**，x0–672 / y229–688）。
- 必须出现：**廊/问泉亭（左）＋ 岩壁下半 ＋ 洞口 ＋ 石栏/三曲桥 ＋ 人 126px**。
- 不画：峰顶（在整张 1008×688 里）、右段高墙、竹、走马楼上半。
- 试片只验“石面/洞口/人/栏”，不验山形。

## 2. 光与值

- 阴天、侧逆光，**光从左上**；石面湿。
- 值域：天 80% → 墙 60% → 石 35–55% → 洞 5% → 水 25%。
- **除洞口外不用纯黑；除天光外不用纯白。**
- 石面三档明度：亮 `#7a7f73` / 中 `#6b7066` / 暗 `#4a4f47`；洞 `#141714`。

## 4. 层（后 → 前）

```
天 → 墙/瓦 → 树冠 → 岩壁 → 洞口 → 石栏/水 → 路 → 人
```

## 5. 像素规则

- 逻辑密度与府学一致；**16px tile**；人 **126px**。
- 不用平滑笔刷/照片纹理；用 2–3px 色簇；只在明暗过渡处少量抖色。
- 石棱 1px 亮边；苔 2–3px 簇；洞内只留一个 2–3px 远光点。
- 墙、石、人**同一像素密度**，并排看不能一个细一个粗。

## 6. 细节优先级

1. **洞口**：黑洞 + 一点远光；读得出“深”，不是一块黑。
2. **钩带接缝**：3–5 块咬合石，缝 2px；放大可辨。
3. **石面皱**：三档明度 + 碎簇；不要等大石块排排坐。
4. **苔/草**：只点缀在石根、洞口、栏脚。
5. **人**：剪影即可，不要画脸；站在桥头，脚在 688。

## 7. 不要

- 蓝天、旅游照光；
- “天下第一”牌、现代匾额；
- 登顶台阶；
- 平滑渐变/照片贴图；
- 植物园式配植（只用桂/松/竹/芭蕉/山茶中的 3–4 种）。

## 8. 验收

- 2× 放大：洞口有纵深，不是黑块；
- 人高 ≈ 岩壁高的 1/4；
- 水/栏（近）→ 洞/谷（中）→ 峰/墙（远）三层可读；
- 与府学并排：色阶、光向、像素密度连续；
- 不出现现代构件。
