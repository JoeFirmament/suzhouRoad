# 环秀山庄 · 主面出图任务（交给出图执行者）

## 任务

基于参考图，生成 **6 张** 2.5D 像素风游戏背景，尺寸 **1024×704**（或 1008×688）。
主题：清末苏州环秀山庄假山主面（不是南平台背面）。

## 文件

| 文件 | 角色 |
|---|---|
| `01-composition.png` | **主参考**：构图 + 色块 + 线边（无人物、无文字） |
| `02-style.jpg` | **风格参考**：府学 2.5D 像素（屋顶/墙/石/植物密度） |
| `03-color.png` | 纯色块（平台只吃色块时用） |
| `04-cave-detail.png` | 洞口/石面细部（局部重绘参考） |
| `05-fuxue-palette.png` | 府学 24 色板（后处理用，可不用） |
| `PROMPT.txt` | 中/英提示词与负向 |
| `quantize_plate.py` | 可选后处理：缩 1008×688 + 24 色 |

## 步骤

1. 选 **图生图 / 参考生图**（能调参考强度的模式）。
2. 主参考：`01-composition.png`，强度 **0.55–0.7**。
3. 若支持第二张参考：`02-style.jpg`，权重 **0.35–0.5**。
4. 提示词：`PROMPT.txt` 的中文段；负向不支持就把“无文字/无人物/无蓝天”写进正向。
5. 尺寸 **1024×704**；一次出 **6 张**。
6. 命名 `candidate-01…06`，原图返回，不要裁切/加字。

## 必须

- 构图：**廊/亭在左、岩壁在中、洞口在中下、高墙在右、石栏/水在前**。
- 洞口要**深**（有暗部与一点远光），不是一块黑。
- 山约占画面 **2/3 高**；石栏低矮。
- 阴天、湿石、灰绿低饱和、左上柔光。
- 像素：16-bit、2–3px 色簇、无抗锯齿。

## 禁止

- 文字、匾额、落款、水印；
- 人物（人物由游戏引擎加）；
- 蓝天、强阳光、旅游照；
- 现代金属栏杆、水泥墙；
- 动漫粗描边、照片、3D 渲染。

## 返回

6 张原图 + 一句话说明：用的哪个参考、强度多少、是否加了风格参考。

## 1890 边界

- 走马楼（二层）1890 待核；若生成，保留即可，不当作史实。
- 俞平伯匾（1900 年生）不能出现。
- 参考图是现代复原/研究派生；成图是游戏化再现。

## 可选后处理

```bash
python3 quantize_plate.py candidate-01.png final-01.png
# 输出 1008×688，府学 24 色
```
