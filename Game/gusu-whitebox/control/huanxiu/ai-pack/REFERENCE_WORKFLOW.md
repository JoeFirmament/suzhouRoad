# 环秀山庄 · 参考图版（MiniMax / GLM / CogView）

> 没有 ControlNet 时用这版：**弱化线稿、加重色块与府学参考**。
> 目标不是“一次画准”，是“6 选 1，再局部重绘”。

## 1. 文件

| 文件 | 用途 |
|---|---|
| `ref-combo.png` | **主参考**：色块 + 线稿压边（构图/色/边都在一张里） |
| `palette.png` | 纯色块（如果平台只吃“色块参考”） |
| `style-fuxue.png` | **风格参考**：府学 2.5D 像素（屋顶/墙/石/植物密度） |
| `cave-2x.png` | 洞口/石面细部（局部重绘参考） |
| `fuxue-palette.png` | 府学 24 色板（后处理量化用） |

## 2. MiniMax 步骤

1. 选 **图生图 / 参考生图**（能调“参考强度/相似度”的那个）。
2. 主参考：`ref-combo.png`；强度 **0.55–0.7**（太高会糊成色块，太低会变另一座山）。
3. 若支持第二张参考：`style-fuxue.png`，权重 **0.35–0.5**。
4. 尺寸：**1024×704**（比例 1.465）；能 1008×688 更好。
5. 提示词见 §4；**负向可能不支持，把“无文字/无人物/无蓝天”写进正向**。
6. **出 6 张**；按 §5 打分，选 1 张。
7. 局部重绘：洞口、石面、墙（见 §6）。
8. 后处理：`python3 ../quantize_plate.py in.png final.png` → 1008×688、府学 24 色。

## 3. GLM / CogView 步骤

- 若支持参考图：同 MiniMax，主参考 `ref-combo.png`，强度 0.55–0.7。
- 若只有文生图：用 §4 提示词 + 6 张，选构图最接近的；**接受“不像环秀、但气氛对”**，后面靠裁切/引擎补。
- 后处理同 §2.8。

## 4. 提示词（中文，直接粘）

```
以参考图的构图与色块为准，重绘为 2.5D 像素风游戏背景：
清末苏州环秀山庄假山主面，左侧廊与亭，中间湖石假山与深洞，
前方低石栏、水池、三曲石桥，右侧粉墙黛瓦高墙，
山上有松，廊前有桂，墙边有竹，洞口有芭蕉；
阴天湿润，石面湿，灰绿低饱和，左上柔光，层次分明；
16-bit 像素，2-3px 色簇，无抗锯齿；
画面无文字、无人物、无蓝天、无现代金属栏杆、无匾额。
```

## 5. 6 选 1 打分表

| 维度 | 5 | 3 | 1 |
|---|---|---|---|
| 构图 | 洞中下、廊左、墙右 | 缺一样 | 全乱 |
| 洞深 | 有纵深/远光 | 半黑 | 一块黑 |
| 比例 | 山约占画面 2/3 高 | 偏小/偏大 | 像土坡 |
| 三层 | 栏/洞/墙清楚 | 缺一层 | 全平 |
| 色 | 接近府学 | 偏亮/偏蓝 | 旅游照 |
| 干净 | 无字无人无蓝天 | 少量 | 明显 |

**先选构图分最高的；构图对了，细节都能修；构图错了，修不回来。**

## 6. 局部重绘

- **洞口**：刷洞内 + 洞壁；提示“深洞，洞内有微弱远光，湖石洞壁，阴天”。参考 `cave-2x.png`。
- **石面**：刷 1–2 处接缝；提示“湖石咬合，缝深，苔痕”。
- **墙**：刷墙脚；提示“粉墙、水痕、苔，旧墙”。
- 没有局部重绘：裁出该区域 → 图生图 → 贴回；或先接受，在引擎里用暗部/光点 sprite 补。

## 7. 后处理

```bash
python3 quantize_plate.py raw.png final.png
# 输出 1008×688，府学 24 色，Floyd–Steinberg 抖动
```

然后在引擎里加 **126px 人物 sprite**，与府学并排校色阶/光向/像素密度。

## 8. 期望管理

参考图模式**守不住精确构图**。你能得到的最好结果是：

- 同一类场景（廊左、山右、水前）；
- 洞口位置大致对；
- 气氛/颜色对。

**70% 对就用**，剩下 30% 靠裁切、局部重绘、引擎遮罩补。不要为了 100% 连出 50 张。
